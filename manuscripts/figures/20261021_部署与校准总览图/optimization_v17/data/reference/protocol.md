# 共同场景与计算协议（假设）
同场景two_bends_01，两方法从(0,0)到(4.6,0)半径0.20 m目标区域，共用圆形足迹半径0.20 m、dt=0.2 s和初始预算85示例成本单位。此预算在编写原始数据前固定：预计15–17 s，基础与速度成本约4.2单位/s，外加近障代价和约18%预留，选取约85；不针对完成曲线调阈值。

地图有三个实体圆障碍，几何见scenario.json。第一障碍从下方绕过，第二障碍从上方经过；本方法可预留更大间隙并稍慢。全向速度接口允许侧向运动；本例身体航向保持0，转弯指平移运动方向变化，不称差速或真实步态仿真。

## 原始与派生
原始每行记录该时刻起持续dt的指令body vx/vy/yawrate、实际body vx/vy/yawrate。实际速度是权威运动记录，名义速度等于指令。起始位姿共同，使用区间起始yaw把body速度旋转到world，显式Euler积分得到下一采样位姿；yaw同样积分。派生表含N+1个状态，最后行没有新的动作/成本区间。双方各自使用同一命令序列得到自己的名义路径；该理想跟踪模型是样图约定，不冒称原论文识别出的闭环模型。

线速度跟踪误差=norm(vexec-vcmd)，单位m/s；角速度误差另列。位置偏差为同时间名义/实际欧氏距离。机身间隙=min(norm(p-center)-障碍半径-足迹半径)，delta不是二次足迹膨胀。检测每段圆足迹扫掠是否碰撞，避免只看离散点漏检。

## 示例成本与内部预算
成本采用相同状态成本函数：
rate = 3.6 + 3*norm(v)^2 + 20*norm(v-vcmd)^2 + 2*max(0,0.45-clearance)。
名义取v=vcmd、名义间隙；实际取实际速度、实际间隙。每步cost=rate*dt，所有项单位通过上述示例权重统一。它是时间/运动/跟踪/近障代理，不是能耗单位或原稿真实成本公式。
Jnom、Jexec分别累加；内部计费Jcharged=(1+alpha)*Jnom，z_internal=85-Jcharged；真实余额85-Jexec另存。此处预算在名义预测状态上更新是明确样图约定，不声称原实现如此。alpha不是把实际成本直接乘小系数；数据需呈现名义和实际的差异，即使本例双方都未超预算也不人工制造违规。

## 终止和事件
每个区间末按collision、goal、timeout优先级判断，碰撞段不能当安全成功；预算违规只记录，不终止诊断轨迹。任何首次终止后禁止继续运动。最后一行应为首次到达或其他真实发生的终止边界，不补静止尾巴。
A/B分别取执行轨迹首次x>=1.9/3.3的采样行；地图点和时间竖线共享同一events.csv，记录各方法独立时间。后续根据数据确认实际事件而不捏造碰撞。
加速度检查限1.8 m/s²、实际速度0.8 m/s、角加速度4 rad/s²仅为本例预先设定的宽松合理性筛查，不证明真机可执行。
