## 对照复核的重点

| 论证/条件 | 复核结果 |
| --- | --- |
| 目标与动机 | 短路线/障碍接近和安全路线/时间成本的条件性权衡保留；没有将代理成本改称测得电能。 |
| 分层控制动机 | 联合关节学习需要平衡/步态/导航；只避开跌倒和倾斜不足以学得平滑协调运动；早期失稳可能中断探索，均保留。 |
| 控制器时序 | PPO与域随机化预训练→冻结→配对校准→高层学习/预算选择→同一冻结接口部署。扰动衰减仍受已训练命令域限定。 |
| 配对协议 | 相同初态、地图、目标、命令、测量时窗；时间对齐的位置最大偏差；正的名义成本分母，均保留。 |
| 两个裕度 | 经验分位数分别校准成本和几何误差；一个进入成本/预算，一个进入障碍几何；高层学习前冻结，覆盖仍依赖校准分布。 |
| RC-PPO与双critic | 安全历史、预算增广、目标函数、成本归一化、两个critic职责与相同停止时域保留；优化目标写成“优化以减小”，没有写成必然减小。 |
| 两阶段学习 | actor均值形成确定部署策略；固定actor再重拟合critic；仅选满足标准的最小已测预算，不宣称连续全局最优。 |
| 部署记账 | 真实执行和同命令的并行名义轨迹区分保留；名义校准成本用于剩余预算更新。 |
| 数据与统计 | 校准、训练、预算选择、最终评估分开；三训练种子、各场景/各策略次数和总分母保持；区间以已训策略为条件。 |
| 指标定义 | 成功不附带预算合规条件；碰撞/间隙同物理足迹；Cost/MC包含全部试验；超预算后继续评估直到既定终止。 |
| 基线定义 | 零裕度RC-PPO、无预算/成本最小化的RA、两类PPO惩罚权重和CPPO期望成本约束保留。 |
| 主结果 | 所有SR/Cost/CR/BVR数字及方向不变；RA/低惩罚CPPO更低碰撞/更大间隙但更低成功和更高成本/BVR仍报告。 |
| 单例诊断 | 只在该配对例子中描述路径/成本/间隙；双方满足同预算、使用相同代理成本、排除主结果表的限定保留。 |
| 校准覆盖 | 800/400样本、单项/联合覆盖、覆盖不等于导航成功概率等原段落未改。 |
| 消融 | 对应裕度在训练与评估均移除、单裕度独立重训、全/零裕度复用主结果；非可加及失败/短路径可拉低成本均保留。 |
| 扫描、预算曲线 | 裕度扫描16组合、900试验、校准不追着结果重调；RA同轨迹只改BVR；预算选择集和最终响应曲线区别保留。 |
| 扰动检验 | 扰动幅度、900次/每条件分母、策略及裕度不重拟合及“在所测扰动下”的限定原段落未改。 |
| 硬件结果与失败 | 35/50与32/50成功、定位中止/超时/接触分类、BVR与成本的有利/不利对比、尾部成本限定、全终止分母均保留。 |
| 适用范围 | 经验稳健性只面向校准执行分布，不宣称一般随机系统严格安全保证或扩展RC-PPO确定性理论。 |
| 结论和未来工作 | 没有把未来随机形式化保证写成当前已取得的结果；语义任务和随机理论仍为后续探索。 |
