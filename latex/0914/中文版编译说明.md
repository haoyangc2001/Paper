# 中文版本LaTeX编译说明

## 文件位置

中文版本 LaTeX 文件：`latex/0914/main_cn.tex`

## 编译方法

### 方法1：使用 VS Code 编译（推荐）

在 VS Code 中打开 `latex/0914/main_cn.tex`，使用 LaTeX Workshop 的编译命令即可。文件头已指定 `latexmk (xelatex)` 配方，产物写入 `output/0914`。

### 方法2：手动命令行编译

```bash
cd C:\Users\smile\Desktop\paper\CORL\latex\0914
latexmk -xelatex -interaction=nonstopmode -file-line-error -outdir=../../output/0914 main_cn.tex
```

## 中文支持

文档使用 `ctex` 宏包支持中文：
- 编译器：**xelatex**（必须使用 xelatex，不能用 pdflatex）
- 字体：系统自动选择中文字体
- 编码：UTF-8

## 内容说明

中文版本完全对应英文版 `main.tex`，包括：
- 相同的论文结构（引言、工程挑战、系统设计、实验验证）
- 相同的表格和公式
- 相同的参考文献（引用标记保持一致）
- 所有技术术语翻译为中文，但保留英文缩写（如 MCRA、RC-PPO、HD-MCRA）

## 编译要求

确保系统已安装：
- **TeX Live**（推荐）或 **MiKTeX**
- 包含 xelatex 编译器
- ctex 宏包（通常随 TeX Live 自动安装）

## 输出文件

编译成功后在 output/0914 生成：
- `main_cn.pdf` - 中文版论文PDF
- `main_cn.aux`, `main_cn.log` 等辅助文件

## 与英文版的关系

- 英文版：`C:\Users\smile\Desktop\paper\CORL\latex\0914\main.tex`
- 中文版：`C:\Users\smile\Desktop\paper\CORL\latex\0914\main_cn.tex`
- 两个版本内容完全对应，便于对照阅读和投稿准备

## 故障排除

如果编译失败：
1. 确认已安装 TeX Live 或 MiKTeX
2. 确认 xelatex 在系统 PATH 中
3. 检查是否缺少 ctex 宏包：`tlmgr install ctex`（TeX Live）
4. 查看 `main_cn.log` 文件了解详细错误信息
