# LaTeX 编译配置说明

## 输出目录配置

已将编译输出目录配置为：`C:\Users\smile\Desktop\paper\CORL\output\0914`

编译产生的所有文件（PDF、辅助文件等）将存放在该目录，而不是源文件目录。

## 编译方法

### 方法1：使用 latexmk（推荐）

如果系统安装了 latexmk：

```bash
cd C:\Users\smile\Desktop\paper\CORL\latex\0914
latexmk -pdf main.tex
```

配置文件 `latexmkrc` 已自动设置输出目录。

### 方法2：使用编译脚本（Windows）

双击运行 `compile.bat` 脚本，该脚本会：
1. 创建输出目录（如不存在）
2. 运行 pdflatex 编译
3. 运行 bibtex 处理参考文献
4. 再次运行 pdflatex（两次）以确保交叉引用正确

### 方法3：手动命令行编译

```bash
cd C:\Users\smile\Desktop\paper\CORL\latex\0914
pdflatex -output-directory=../../output/0914 -interaction=nonstopmode main.tex
cd ../../output/0914
bibtex main
cd ../../latex/0914
pdflatex -output-directory=../../output/0914 -interaction=nonstopmode main.tex
pdflatex -output-directory=../../output/0914 -interaction=nonstopmode main.tex
```

## 编译要求

确保系统已安装 LaTeX 发行版：
- **Windows**: TeX Live 或 MiKTeX
- **macOS**: MacTeX
- **Linux**: TeX Live

## 输出文件

编译成功后，在 `C:\Users\smile\Desktop\paper\CORL\output\0914` 目录下会生成：
- `main.pdf` - 最终论文PDF
- `main.aux`, `main.log`, `main.out` - 辅助文件
- `main.bbl`, `main.blg` - 参考文献相关文件
- `main.synctex.gz` - SyncTeX同步文件

## 清理辅助文件

如果需要清理辅助文件（保留PDF），可以删除 output/0914 目录下的 .aux, .log, .bbl, .blg, .out, .synctex.gz 等文件。

## 注意事项

- 源文件目录（latex/0914）将保持干净，不会产生编译文件
- 每次编译都会将输出文件放在 output/0914 目录
- 图片路径引用保持不变，LaTeX会自动从源文件目录查找
