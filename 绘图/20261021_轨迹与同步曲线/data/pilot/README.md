# 小段假设数据

两组20个显式样本、4 s，共同初态(0.9,-0.1,0)，只用于检查近第一障碍的转弯与恢复，不是全程的重复试验。前半段向下绕行，越过危险的接近区后逐步恢复向上速度；实际速度存在滞后、局部超调和方向不同的波动。两组独立编写。yaw=0，路径方向改变来自全向平移。

首版向上修正过早导致碰撞，被终止检查拦截；首版保留在data/pilot_attempt1，失败报告为output/pilot_validation_attempt1.json。逐点加大前期向下位移并推迟向上恢复后，完整重算通过；没有移动障碍、修改足迹、放宽阈值或调整预算。两组RMSE约0.024/0.023 m/s，说明共享接口不要求本方法的误差更低。
