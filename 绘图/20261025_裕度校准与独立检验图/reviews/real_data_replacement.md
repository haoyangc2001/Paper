# 替换为真实实验数据

当前图的视觉形式和计算流程可以复用；假设数值、假设控制器、假设命令标识和预设锚点不能冒充真实实验。真实版使用新数据/协议/输出版本，保留本次示例工程用于比较。

## 先补齐什么日志

每组至少需要名义/执行的统一时间基准、初始位姿/地图或场景ID、同一高层命令序列、固定控制器版本、执行周期、成本定义及累计成本、名义和执行平面位置序列。记录摩擦/时延/噪声设置或实际测量，以及终止原因、失败或异常。控制器版本应由真实权重/配置哈希支持，不沿用假设ID。

J_nom与J_exec必须使用同一种成本定义、单位和公共窗口。最大偏差需根据时间对齐后的配对位置求最大值；只给两张路线截图不能证明这个数值。明确采样频率、插值/同步误差及缺测处理；不能把1200帧当成1200次独立运行。

真实窗口如果会提前终止，先定义并统一处理。不能只保留成功轨迹或因成本/偏差超界而删除记录。异常排除需有预先规则和排除清单；若J_nom=0，应事先定义处理方法，不把分母偷偷加小量后继续沿用本版含义。

## 分组和冻结顺序

1. 采样前固定适用场景、扰动范围、观察窗口和组间划分；重复同一路径/命令或强相关重复试验不能被当成新的独立证据。必要时按场景/命令族/采集批次分组，避免泄漏。
2. 保持待部署的低层控制器冻结。明确真实数据是仿真、实机还是两者，不能混用来源标签。
3. 从真实校准组计算两项误差分布，确定所用分位数算法及90%目标。若改变目标或增加统计保证，需要新的协议和论证。
4. 冻结真实校准数据、协议、控制器哈希、阈值及时间记录，再分析真实留出组。留出差于目标时如实报告，不反向调阈值。
5. 如确需重新校准，建立新版本，并为最终评估留出新的未参与选择的数据；不能将原检验组同时作为调参集和最终独立证据。

## 哪些旧约束应取消

本版四个锚点0.09、0.18、0.06m、0.12m只是论文的假设占位值，不能强制真实数据匹配。新α/δ由真实校准重新计算；真实留出覆盖率按实际计数保留。真实样本量如不是800/400，必须更新分组设计、清单和相关表述，图例本身会随组计数变化。

如成本单位、碰撞几何/机器人足迹、名义模型、命令范围或控制器改变，先审查是否仍属原适用条件。单张ECDF和90%经验分位数本身不提供形式安全保证，也不提供分布变化后的覆盖保证。

## 脚本需要同步改哪里

当前程序特意限制为假设数据，避免换标签后被误认为已验证实测。真实替换不是本轮执行范围，届时应新建显式模式并完成相应验证：

| 位置 | 必须的真实版变化 |
| --- | --- |
| `data/protocol.json`及manifest | 改为真实协议/样本清单，关联原始日志和排除记录，不伪造采集来源 |
| `compute_statistics.py::validate_rows` | 增加真实来源模式，仍保留ID、有限值、正成本、几何和成本定义检查 |
| `summarize`及统计元数据 | `data_status`从经核验来源读取；不能继续固定写hypothetical或直接全局替换成measured |
| `validate_data.py` | 支持显式新manifest/冻结/审查路径，核对真实来源及控制器版本，取消本版800/400硬限制时需按新协议验证 |
| `plot_margin_calibration.py::caption`和导出元数据 | 如实区分实测/仿真/混合来源，更新说明；保留阈值只由校准确定的关系 |
| `verify_outputs.py` | 当前交付验收写有本版88.25/86.50与固定尺寸；真实版改为与新统计JSON比较，不能继续检查旧假设百分比 |
| 新README/论文图注 | 同步新样本数、算法、α/δ、覆盖计数、适用条件及限制 |

绘图入口已经从CSV重算阈值和覆盖数字，并自动扩展横轴覆盖尾部；但新分布若量级变化很大，仍需检查刻度密度和注释位置。不要用缩小字体、裁掉尾部或平滑数据解决视觉问题。

## 替换后的验收

逐行对应原始日志重算两项误差；核对单位、时间窗、失败轨迹、同一控制器与分组隔离；只用校准数据重算阈值并检查等号规则；将图中每个阶梯/标记/数字对照新统计；按单栏真实尺寸渲染PDF；新目录独立重绘，核对数值和像素。

最后再决定论文中相关文本、主表、轨迹图、总览、消融和预算结果哪些需要同步。不能把本图边际覆盖率替换为SR/CR/BVR，也不能声称α/δ本身降低低层跟踪误差。
