# 总览图：最终数据与配置

整理日期：2026-10-25。此目录将最终工程 `../optimization_v17/` 中的数据与配置原样复制到项目级 `data/`，便于统一查找。复制文件已核对SHA256一致。

- `cost_pairs/`：R1、R2、R3三组示意路线的原始记录、派生曲线、成本汇总和来源说明；对应成本裕度子图。
- `reference/`：名义/执行轨迹、事件、场景定义、假设说明及汇总；对应轨迹偏差与安全裕度子图。
- `config/`：最终工程中的场景参数、布局和配色配置。原工程中它们位于独立的 `config/`，这里一并归档。

当前成图：`../optimization_v17/output/final/deployment_calibration_overview.pdf`。

现有重绘脚本仍读取 `../optimization_v17/data/` 和 `../optimization_v17/config/`；本目录是其当前数据副本。机器人渲染图、场景XML、网络绘图脚本仍保留在 `optimization_v17/assets/` 和 `optimization_v17/scripts/`，不重复放入数值数据目录。

若后续修改本目录并重绘，需要显式适配旧脚本输入路径；不能只改这里却继续让脚本读取旧副本。历史manifest保留原内容，其相对路径约定以原工程为准。本轮没有移动或删除原文件，也没有修改现有图片。

数据性质：假设示意记录与静态场景渲染；没有新增执行测量。网络结构图也属于结构示意。
