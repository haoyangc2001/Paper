Minimum-Cost Reach-Avoid
VLA模块设计
模型架构
VLA 导航决策模块接收历史 RGB 观测、当前 RGB 观测和自然语言导航指令，通过视觉编码、特征投影和语言模型推理生成下一步中层导航动作。模型输出的是包含动作类型、距离或角度参数的导航意图，不直接输出机器人关节位置、关节力矩或其他低层控制量。
历史 RGB 帧 + 当前 RGB 帧 + 自然语言导航指令
                         ↓
                  Vision Encoder
                         ↓
                     视觉 Token
                         ↓
                      Projector
                         ↓
       视觉 Token + 文本 Token + 导航 Prompt
                         ↓
                         LLM
                         ↓
                  中层导航动作文本
                         ↓
                   动作解析与目标生成
模型由三个核心部分组成：

模型配置
VLA 采用 VILA 风格的视觉语言模型结构。
视觉编码器使用 SigLIP，将多帧 RGB 图像编码为视觉 Token；
Projector 使用 MLP 结构，将视觉特征映射到语言模型的特征空间；
基础语言模型使用 Llama 3 8B，负责融合视觉 Token 与文本 Token，并自回归生成中层导航动作。
Move forward 75 cm.
Turn right 30 degrees.
Stop.
动作可以抽象为：
中层动作 = 动作类型 + 距离或角度参数
其中动作类型包括前进、左转、右转和停止。解析后的动作将转换为局部位置目标或航向目标，交给下层运动控制模块执行。
时序输入
VLA 使用多帧 RGB 观测，而不是仅根据单张当前图像进行导航决策。最新图像作为当前观测，之前的观测帧作为历史记忆输入模型。
历史帧和当前帧承担不同功能：
历史帧用于判断已经经过的区域、当前任务阶段和整体导航进度；
当前帧用于判断当前是否需要前进、转向或停止；
初始观测帧尽量保留，用于提供起始场景和任务上下文；
历史帧从此前观测中进行均匀采样，以控制输入长度和推理延迟。
输入帧可以表示为：
历史观测：[I_1, I_k, I_2k, ..., I_(t-1)]
当前观测：[I_t]
模型通过 Prompt 中的文本提示区分历史观测和当前观测，使语言模型能够同时利用长期场景记忆和当前视觉信息。
视觉编码
每一帧 RGB 图像经过 SigLIP 视觉编码器，转换为视觉特征或视觉 Token：
I_i → Vision Encoder → V_i
多帧图像的视觉特征形成后续语言模型使用的视觉 Token 序列。视觉编码器主要提供以下信息：
场景和区域类型，例如房间、走廊、楼梯和室外道路；
导航地标和目标物体，例如门、桌子、垃圾桶和消防栓；
物体之间的空间关系；
当前可通行方向和局部场景结构。
SigLIP 视觉编码器负责视觉表征，不直接产生导航动作。导航动作由后续语言模型结合视觉信息和自然语言指令生成。
多模态融合
视觉编码器输出的特征维度通常与 Llama 3 8B 的隐藏层维度不同，因此需要通过 MLP Projector 进行映射：
V_i → Projector(V_i) → Z_i
经过映射后的视觉 Token 与导航指令的文本 Token 共同组成语言模型输入序列：
输入序列 = 历史视觉 Token
         + 当前视觉 Token
         + 导航指令文本 Token
         + 导航 Prompt Token
该模块主要完成视觉特征和语言模型特征空间的对齐。VLA 沿用视觉编码器、Projector 和 LLM 的标准视觉语言模型连接方式，没有额外引入独立的复杂跨模态交互网络。
导航决策
语言模型根据多帧视觉信息、自然语言导航指令和导航 Prompt 生成下一步中层动作。其决策过程包括：
视觉观测 + 导航指令
        ↓
场景和地标识别
        ↓
空间关系与任务进度判断
        ↓
下一步方向、距离或角度决策
        ↓
中层动作文本生成
LLM 主要负责：
理解自然语言导航任务；
将当前视觉场景与指令中的地标对应起来；
根据历史帧判断任务进度；
判断是否需要继续前进、转向或停止；
生成包含距离或角度参数的中层导航动作。
基础语言模型采用 Llama 3 8B。其推理输出仍保持为语言形式，以利用语言模型已有的空间推理和指令理解能力。
动作生成
LLM 输出动作文本后，动作解析模块提取动作类型及其参数：
“Move forward 75 cm.”
        ↓
动作类型：forward
距离参数：0.75 m
        ↓
局部位移目标
“Turn right 30 degrees.”
        ↓
动作类型：turn_right
角度参数：30°
        ↓
局部航向目标
结构化动作可表示为：
{
  "type": "forward",
  "distance": 0.75
}
在实际系统中，动作解析结果应转换为下层控制器可以直接使用的局部目标，包括：
目标相对位移；
目标相对航向；
位置和航向容差；
局部任务完成条件。
因此，上层与下层之间的接口为：
VLA 动作文本
    ↓
结构化动作参数
    ↓
局部导航目标
    ↓
下层安全运动控制器
VLA 负责生成导航意图，下层控制器负责在安全和成本约束下完成该局部目标。
训练方法
VLA 从预训练视觉语言模型开始，采用监督微调学习：
历史 RGB 帧 + 当前 RGB 帧 + 导航指令
                         ↓
                  中层导航动作文本
训练数据主要包括模拟导航轨迹、人类第一视角导览视频、空间场景问答和通用视觉问答数据，用于覆盖连续导航、真实场景理解、空间推理和通用视觉语言能力。不同数据统一转换为“多模态输入—文本输出”的监督样本，具体数据配比不是训练函数的核心内容。
训练函数设计
单条训练样本由多模态输入 x 和目标动作序列 y = (y_1, ..., y_T) 构成：
x = 历史帧 + 当前帧 + 导航 Prompt + 导航指令
y = 中层动作文本
例如：
输入：图像序列 + “走到红门前”
标签：Move forward 75 cm.
视觉编码器提取图像特征，MLP Projector 将视觉特征映射到 Llama 3 8B 的输入空间，再与文本 Token 拼接形成多模态输入。训练时采用自回归监督微调，使用 Teacher Forcing 逐 Token 预测目标动作序列：
p(y_t | y_<t, x)
工程实现中通过 Token-level Cross-Entropy 优化目标动作序列的预测概
L = -Σ_t log p(y_t | y_<t, x)
其中，y_<t 表示当前 Token 之前的真实目标 Token，损失只计算目标动作文本部分，不要求模型重构视觉输入或导航指令。该训练函数直接优化“视觉场景、语言任务和历史上下文 → 中层导航动作文本”的映射，不涉及关节控制损失或低层强化学习损失。
训练阶段更新视觉编码器、MLP Projector 和 Llama 3 8B，使视觉表征、跨模态对齐和动作文本生成能力共同适应导航任务。
底层问题定义
问题介绍
解决问题
现实任务是让机器人从起点安全到达目标，并在所有安全到达的策略中选择累计执行成本最低的方案；
形式上，将其写成带有动力学、目标到达和全程安全硬约束的最低成本 Reach-Avoid 优化问题。

现实问题
四足机器人在室内巡检、搜索救援或复杂障碍环境中，需要从起点自主运动到目标位置。
机器人不能只追求直线距离最短，还必须在运动全过程中避开碰撞、不可通行区域和其他安全风险。
任务要求保证机器人安全到达目标，再在所有满足安全到达的策略中选择累计执行成本最低的策略。
优化模型 
将机器人在第 t 个决策时刻的状态记为 x_t，控制动作记为 u_t，策略记为 \pi。
对于基础的确定性离散动力学，最低成本可达规避问题直接写成
\begin{aligned}\min_{\pi,\,T}\quad &J_T^\pi(x_0)=\sum_{t=0}^{T-1}c\!\left(x_t,\pi(x_t)\right)\\\text{s.t.}\quad &x_{t+1}=f\!\left(x_t,\pi(x_t)\right),\quad t=0,\ldots,T-1,\\&x_T\in G,\\&x_t\notin F,\quad \forall t=0,\ldots,T.\end{aligned}
终止时刻 T 表示机器人首次进入目标集的时刻，可写为
T=\inf\{t\ge0\mid x_t\in G\}.
累计成本 单步成本 c(x_t,u_t) 描述第 t 步控制行为带来的执行代价，可以对应控制能量、运动距离、动作平滑性、时间消耗或这些因素的组合。从初始状态到首次到达目标的累计成本为
J_T^\pi(x_0)=\sum_{t=0}^{T-1}c\!\left(x_t,\pi(x_t)\right).
动力学函数 f 描述执行动作后状态如何变化：
x_{t+1}=f(x_t,u_t).
目标集与危险集 用目标函数 g 和危险函数 h 定义两个关键区域：
G=\{x\in\mathcal X\mid g(x)\le0\},\qquad F=\{x\in\mathcal X\mid h(x)>0\}.
g(x)\le0 表示机器人已经进入目标区域；
h(x)>0 表示机器人进入危险区域，例如发生碰撞、越过安全边界或进入不可通行区域。


核心难点
核心难点：
更短的路线通常意味着更低的执行成本，但可能更接近障碍物；
更保守的绕行路线通常更安全，却会增加运动距离、控制能量和时间成本。

核心矛盾
问题不能被简化为“找到一条最短路径”，也不能同时把安全和成本“平均优化”
如果只最小化累计成本，策略可能主动选择贴着障碍物通过的路线；
如果一味扩大安全裕量，又可能付出不必要的绕行代价。
真正要寻找的是：在所有安全到达的路线中，成本最小的那一条。
直观例子
假设机器人从起点前往目标，中间有一处障碍物。
路线 A 直接穿过障碍物附近，距离较短，但安全余量很小，容易因过于接近障碍物而发生碰撞;
路线 B 绕开障碍物，采用过度保守的绕行方式，但距离和控制消耗更大，容易在到达目标前耗尽能耗;
路线 C 在安全边界外保持适度距离，既避免碰撞，又控制了绕行成本，最终实现安全到达。
相关工作
Reward Shaping 将到达、安全和成本组合成加权目标；CMDP 在预设阈值下优化策略；Reach-Avoid 直接判断能否安全到达。
判断它们能否解决最低成本 Reach-Avoid 问题，关键要看是否保留相同的安全可行策略集合，并继续按照累计执行成本选择最优策略。三类方案分别软化了硬约束、依赖外部阈值或缺少成本比较，因此都不能保证与原问题等价。

Reward Shaping
奖励塑形为目标区域设置奖励、为危险区域设置惩罚，并对每一步执行成本施加惩罚，从而形成可直接交给 PPO、SAC 等标准强化学习算法优化的标量回报：
\max_\pi\;\mathbb E_\pi\!\left[R_{\mathrm{goal}}\mathbf 1_{\{x_T\in G\}}-\lambda_f\sum_{t=0}^{T}\mathbf 1_{\{x_t\in F\}}-\lambda_c\sum_{t=0}^{T-1}c(x_t,u_t)\right].
其中，R_{\mathrm{goal}} 是到达目标的奖励，\lambda_f 和 \lambda_c 分别控制安全惩罚与成本惩罚，c(x_t,u_t) 是单步成本。
优势。 目标、安全和成本被压缩为单一训练信号，能够直接复用成熟的强化学习算法。
局限。 权重实际决定三项目标的优先级。权重过小，策略可能用安全或成本换取目标奖励；权重过大，策略可能为了规避惩罚而拒绝到达。更根本地说，奖励塑形改变了原始优化问题，无法保证“先满足到达与安全硬约束，再在可行策略中最小化成本”的字典序语义。
CMDP
约束马尔可夫决策过程保留一个主要优化目标，例如最大化到达奖励，同时要求期望成本与期望危险指标不超过预设阈值：
\begin{aligned}\max_\pi\quad &V_r^\pi(x_0)\\\text{s.t.}\quad &V_c^\pi(x_0)\le X_{\mathrm{threshold}},\\&V_f^\pi(x_0)\le d_f.\end{aligned}
常见定义为
V_r^\pi=\mathbb E_\pi\!\left[\sum_{t\ge0}\gamma^t r_t\right],\quad V_c^\pi=\mathbb E_\pi\!\left[\sum_{t\ge0}\gamma^t c_t\right],\quad V_f^\pi=\mathbb E_\pi\!\left[\sum_{t\ge0}\gamma^t\mathbf 1_{\{x_t\in F\}}\right].
其中，X_{\mathrm{threshold}} 是预先指定的成本上限，d_f 是安全约束阈值；训练时通常使用拉格朗日乘子把约束转化为可优化项。
优势。 成本和安全从奖励权重中分离出来，约束含义比单纯奖励塑形更明确。
局限。 X_{\mathrm{threshold}} 是外部输入，而不是算法要求解的最优成本：阈值过小会使问题不可行，阈值过大又不能筛出最低成本策略。一个全局阈值也无法表达不同初始状态各自不同的最小可行成本。此外，CMDP 通常约束轨迹分布上的期望值，而原问题要求执行轨迹在到达前始终安全，两者并不等价。
Reach-Avoid
经典 Reach-Avoid 不把到达和安全折算为奖励，而是直接判断未来轨迹是否存在一个到达目标的时刻，并要求此前所有状态均处于安全区域。对固定策略 \pi 的轨迹 x_t^\pi，定义
V_{g,h}^{\pi}(x_0)=\min_{T\in\mathbb N}\max\!\left\{g(x_T^\pi),\;\max_{0\le t\le T}h(x_t^\pi)\right\}.
其中，g(x_T)\le0 表示终点进入目标集，h(x_t)\le0 表示时刻 t 安全；外层 \min_T 在未来时刻中寻找满足条件的候选到达时刻。因此
V_{g,h}^{\pi}(x_0)\le0\quad\Longleftrightarrow\quad\exists T:\ x_T^\pi\in G\ \text{且}\ x_t^\pi\notin F\ \forall t\le T.
优势。 值函数直接保留“存在到达时刻且到达前始终安全”的轨迹级语义，不需要将硬约束换算成奖励权重或期望惩罚。
局限。 该值函数只表达可达性，不记录到达前的累计成本。只要 V_{g,h}^{\pi}\le0，策略就被视为可行；值更小并不表示累计成本更低。因此它能回答“能否安全到达”，却不能回答“哪个可行策略成本最低”。
现有方法不等价性
能同时处理到达、安全和成本，并不意味着真正解决了最低成本 Reach-Avoid 问题。
判断一种方法是否与原问题等价，关键要看它是否保留了相同的可行策略集合，并且仍然按照累计执行成本从这些可行策略中选择最优者。

等价性判断标准 
把满足安全到达条件的策略记为
\Pi_{\mathrm{RA}}(x_0)=\left\{\pi\ \middle|\ \exists T^\pi:\ x_{T^\pi}^\pi\in G,\;x_t^\pi\notin F,\ \forall t\le T^\pi\right\}.
其中，T^\pi 表示策略 \pi 从初始状态出发首次进入目标集的时刻。
最低成本 Reach-Avoid 问题要求
\pi^*\in\arg\min_{\pi\in\Pi_{\mathrm{RA}}(x_0)}J_{T^\pi}^\pi(x_0).
因此，等价方法必须同时满足两个条件：
一是不能改变哪些策略属于安全可行策略；
二是不能改变可行策略之间按照累计成本进行比较的顺序。
方法
 | 实际求解对象
 | 与原问题不等价之处
 | 
Reward Shaping
 | 最大化由目标奖励、安全惩罚和成本惩罚组成的加权标量回报。
 | 到达与安全的硬约束被软化为有限权重。有限权重不能保证任何不可行策略都排在可行策略之后，因此优化结果未必属于原问题的可行策略集合。
 | 
CMDP
 | 在预先给定的成本阈值和安全阈值下优化主要回报。
 | 求解的是某个固定阈值下的约束问题，而不是寻找最低可行成本；常见的期望约束也不等同于要求每条执行轨迹在到达前始终安全。
 | 
Reach-Avoid
 | 判断策略能否在避开危险的前提下到达目标。
 | 保留了安全到达的可行性判据，但值函数中没有累计成本，因而无法比较不同可行策略的执行成本。
 | 
统一结论
三种方法的问题是它们求解的数学问题与原问题不同。
Reward Shaping 和常见 CMDP 会改变原问题的可行集合或策略优先级；
Reach-Avoid 保留了安全到达条件，却只完成了可行性判断，没有完成可行策略中的成本最小化。
前两类方法改变了问题结构，后一类方法只解决了原问题的一部分。
预算增广可达性理论
总体思路
核心思路
不直接比较所有安全到达策略的累计成本，而是给定一个候选预算和初始状态，判断是否存在能够在预算内安全到达的策略；可行性从“不可行”变为“可行”的预算边界，就对应原问题的最低累计成本。
对每个候选预算 z_0初始状态组合，判断是否存在能够在预算内安全到达的策略；可行预算集合的下边界就是最小可行预算，并且等于原问题的最优累计成本。

从成本最小化到预算可行性
传统 Reach-Avoid 能够判断一条策略是否可以安全到达目标，却无法继续比较多条可行策略中哪一条成本更低。
为保留原有的安全到达条件，同时引入成本比较，可以暂时不直接求解最小成本，而是先给定一个候选预算 z_0，询问：是否存在一条策略，能够始终避开危险、最终到达目标，并且累计成本不超过 z_0？
\exists\pi\in\Pi_{\mathrm{RA}}(x_0),\qquad J_{T^\pi}^{\pi}(x_0)\le z_0.
其中，\Pi_{\mathrm{RA}}(x_0) 仍然是原问题中的安全到达策略集合，预算 z_0 只负责进一步筛选其中成本不超过当前上限的策略。因此，这一转换既没有放宽安全要求，也没有改变累计成本的定义。
例如，假设三条安全到达策略的累计成本分别为
6,\qquad 9,\qquad 13.
当 z_0=5 时，没有策略能够在预算内完成任务；当 z_0=8 时，成本为 6 的策略已经可行；继续增加预算，只会允许更多高成本策略进入可行集合。因此，可行性第一次从“不可行”变为“可行”的位置正好是 z_0=6。
这里的预算不是预先固定的成本阈值，而是需要不断查询和搜索的变量。 沿预算轴寻找“不可行”与“可行”的分界点，就能把策略之间难以直接处理的成本最小化，转换为一系列预算条件下的可行性判断。
两阶段求解链路
第一阶段在增广状态上学习预算条件策略和可达性值函数，回答给定状态与预算下应该如何行动、任务是否仍然可行。第二阶段固定第一阶段的策略和价值评价，沿预算轴搜索当前状态下的最小可行预算。
(x_t,y_t,z_t)\xrightarrow{\text{第一阶段}}\pi_\theta,\;\tilde V\xrightarrow{\text{第二阶段}}\widehat z^*(x_t,y_t)
增广状态构建
核心作用
物理状态 x_t 只描述机器人当前所处的位置和运动状态，无法说明此前是否发生过安全违规，也无法说明初始预算已经消耗了多少，不足以支持预算可行性的判断。引入安全记忆 y_t 和剩余预算 z_t ，增广状态 \hat x_t=(x_t,y_t,z_t) 能够压缩与任务可行性有关的历史信息，后续可行性只依赖当前增广状态和当前动作。

从预算可行性到增广状态
3.1 将最低成本问题改写为预算可行性判断：给定初始状态 x_0 和候选预算 z_0，询问是否存在策略能够安全到达目标，且累计成本不超过 z_0。
这个判断依赖完整轨迹：是否可行不仅取决于当前位置，还取决于此前是否发生过安全违规、此前已经消耗多少预算，以及从当前状态继续执行后的未来结果。
但策略和价值函数在每一步通常只接收当前状态作为输入，无法自动回看完整历史。因此，3.2 需要将“历史安全”和“历史成本”压缩进当前状态，使策略和值函数仅凭当前增广状态，也能评价任务是否仍然可行。
\text{最终到达目标}\quad+\quad\text{到达前始终安全}\quad+\quad\text{累计成本不超过 }z_0.
这三个条件中，目标到达主要由当前物理状态决定，但后两个条件都依赖历史：需要知道此前是否进入过危险集，也需要知道之前已经消耗了多少成本。因此，问题从“当前状态能否继续运动”变成了“带着已有历史约束，当前任务是否仍然可行”。
例如，假设候选预算为 z_0=5，三条轨迹在当前时刻到达了相同的物理状态 x_t：
轨迹 A 从未进入危险集，累计成本为 3；
轨迹 B 曾经发生过碰撞，累计成本为 3；
轨迹 C 从未发生碰撞，但累计成本已经为 8。
三条轨迹的当前物理状态完全相同，但后续任务状态不同：
轨迹 A 仍可能在剩余预算内安全到达；
轨迹 B 已经违反了全程安全约束；
轨迹 C 已经超出候选预算。
如果策略或价值函数只读取 x_t，就无法区分这三种情况，也就无法正确回答当前预算下是否仍存在可行策略。
因此，需要在原物理状态之外增加两个历史摘要：y_t 记录截至当前是否曾经进入危险集，z_t 记录初始预算扣除历史累计成本后的剩余量。它们不保存完整轨迹，只保留预算可行性判断真正需要的历史信息。于是，新的状态写成：
\hat x_t=(x_t,y_t,z_t).
安全记忆状态：是否曾经进入危险集
为了记录轨迹是否进入过危险集，将当前状态是否属于 F 编码为一个符号指示量：
I_F(x)=\begin{cases}1,&x\in F,\\-1,&x\notin F.\end{cases}
安全记忆定义为截至当前时刻所有指示量的最大值：
y_t=\max_{0\le k\le t}I_F(x_k).
y_t=-1 表示从初始时刻到当前始终没有进入危险集；一旦某一步进入 F，y_t 就变为 1，并且不会恢复为 -1。
因此，y_t 是一个只记录“是否曾经违规”的永久安全记忆，也可以递推写成：
y_{t+1}=\max\!\left\{y_t,I_F(x_{t+1})\right\}.
预算记忆状态：还剩多少执行预算
成本历史不需要保存每一步的具体支出，只需记录初始预算扣除历史累计成本后的剩余量：
z_t=z_0-\sum_{k=0}^{t-1}c(x_k,u_k).
z_t>0 表示当前仍有剩余预算，
z_t=0 表示预算刚好用完，
z_t<0 表示累计成本已经超过候选预算。
对应的递推形式为：
z_{t+1}=z_t-c(x_t,u_t).
增广状态
两个变量都不保存完整轨迹，却保留了判断后续任务是否仍可行所需要的历史摘要：y_t 负责安全违规记忆，z_t 负责累计成本记账。
将原状态、安全记忆和剩余预算组合为新的状态：
\hat x_t=(x_t,y_t,z_t)\in\hat{\mathcal X}:=\mathcal X\times\{-1,1\}\times\mathbb R.
分量
 | 作用
 | 保留的信息
 | 
x_t
 | 物理状态
 | 位置、姿态、速度等当前动力学信息。
 | 
y_t
 | 安全记忆
 | 从轨迹开始到当前是否曾经进入危险集。
 | 
z_t
 | 剩余预算
 | 初始预算扣除当前累计成本后的剩余量。
 | 
给定初始状态 x_0 和候选预算 z_0，初始增广状态为
\hat x_0=\left(x_0,I_F(x_0),z_0\right).
增广动力学
每执行一步动作，三个状态分量同步更新：
\hat f(x_t,y_t,z_t,u_t)=\left(f(x_t,u_t),\;\max\!\left\{I_F\!\left(f(x_t,u_t)\right),y_t\right\},\;z_t-c(x_t,u_t)\right).
等价地，可以按分量写成
\begin{aligned}x_{t+1}&=f(x_t,u_t),\\y_{t+1}&=\max\!\left\{I_F(x_{t+1}),y_t\right\},\\z_{t+1}&=z_t-c(x_t,u_t).\end{aligned}
x 按原物理动力学演化；
y 通过最大值递推永久保留已经发生的安全违规；
z 在每一步扣除当前动作产生的成本。
给定当前增广状态 \hat x_t 和动作 u_t，下一增广状态由 \hat f 唯一确定，不再需要读取更早的轨迹。
因此，预算可行性问题在增广状态空间中恢复了 Markov 表达。
增广目标
最后，将“到达目标、历史安全、预算未超出”合并为一个增广目标函数：
\hat g(x,y,z)=\max\!\left\{g(x),Cy,-z\right\},\qquad C>0.
对应的增广目标集为
\hat G=\{\hat x\in\hat{\mathcal X}\mid\hat g(\hat x)\le0\}=\left\{(x,y,z)\mid x\in G,\;y=-1,\;z\ge0\right\}.
g(x)\le0 要求当前状态已经进入目标集；
Cy\le0 要求 y=-1，即此前始终安全；
-z\le0 要求 z\ge0，即累计成本没有超过初始预算。
最低预算可行性问题
核心转换
最低预算可行性问题：先给系统一个包含候选初始预算 z_0的增广状态，判断是否存在策略能够在预算内安全到达目标，再从所有可行预算中取最小值。增广目标负责统一表达“到达、安全、预算充足”，Reach value 负责消除未知终止时刻，最终得到与原问题严格等价的最低预算模型。

前两节已经完成准备：3.1 将最低成本问题改写为预算可行性判断，3.2 将判断所需的历史安全和累计成本编码进增广状态，并将三项条件合并为增广目标集 \hat G。本节沿上方四步路线，验证这种重构能否正确判断可行性，并最终恢复原问题的最小累计成本。
第一步：固定预算与到达时刻，建立局部等价
先暂时固定策略 \pi、候选初始预算 z_0 和到达时刻 T。此时不讨论哪个预算最小，也不讨论何时到达；只验证一件基础事实：原轨迹在时刻 T 满足“到达、安全、成本不超预算”，是否恰好等价于增广状态在同一时刻进入 \hat G。
例如，假设候选预算为 z_0=10。某条轨迹在第 T 步进入目标集，此前没有进入危险集，累计成本为 8。此时
z_T=10-8=2.
因为 x_T\in G、y_T=-1 且 z_T\ge0，所以增广状态进入 \hat G，说明这条轨迹在预算内安全到达。反过来，如果机器人此前发生过碰撞，则 y_T=1；如果累计成本达到 12，则 z_T=-2。这两种情况下，即使机器人当前已经到达目标，也不能进入 \hat G，因为安全约束或预算约束至少有一项没有满足。
根据增广状态的定义，原轨迹满足到达、安全和成本上界三个条件，当且仅当对应的增广轨迹在时刻 T 进入增广目标集：
\left.\begin{aligned}x_T&\in G,\\x_t&\notin F,\quad \forall t\in\{0,\ldots,T\},\\\sum_{k=0}^{T-1}c\!\left(x_k,\pi(x_k)\right)&\le z_0\end{aligned}\right\}\quad\Longleftrightarrow\quad \hat x_T^\pi\in\hat G.
原轨迹条件
 | 增广状态条件
 | 等价依据
 | 
到达目标
 | x_T\in G
 | 增广动力学保留原物理状态，第一分量仍按 f 演化。
 | 
到达前始终安全
 | y_T=-1
 | y_T=\max_{0\le t\le T}I_{\{x_t\in F\}}，只有整条历史轨迹都未进入 F 时才为 -1。
 | 
累计成本不超预算
 | z_T\ge0
 | z_T=z_0-\sum_{k=0}^{T-1}c(x_k,\pi(x_k))，因此剩余预算非负等价于累计成本不超过 z_0。
 | 
三个条件同时成立，等价于
\hat x_T^\pi\in\hat G=\left\{(x,y,z)\mid x\in G,\;y=-1,\;z\ge0\right\}.
此时 z_0 表示完成任务所允许的成本上界。它只回答给定策略能否在该预算内完成任务，还没有确定最小成本。

这里验证的是到达时刻 T 已经给定时的等价关系。
到这里，给定时刻 T 的轨迹可行性已经可以通过 \hat x_T\in\hat G 判断；但原问题并不预先给定 T，还需要把“某一个时刻成功”转换为整条轨迹上的统一判据。
第二步：固定预算、未知到达时刻，用 Reach value 判断整条轨迹
现在仍固定策略 \pi 和预算 z_0，但不再固定到达时刻。问题变为：增广轨迹是否在任意一个未来时刻进入过 \hat G？这正是 Reach value 需要回答的预算可行性判断。
因此，需要判断的不是某个固定时刻的状态，而是：沿着整条轨迹，是否至少存在一个时刻进入了增广目标集？
增广目标函数 \hat g 已经把到达、安全和预算三个条件合并在一起，并满足
\hat g(\hat x_t)\le0\quad\Longleftrightarrow\quad\hat x_t\in\hat G.
也就是说，只要某个时刻的 \hat g(\hat x_t) 小于等于零，便说明机器人在该时刻同时满足三个条件：已经到达目标、此前没有发生安全违规，并且剩余预算非负。
为了检查整条轨迹上是否出现过这样的时刻，对所有时刻的 \hat g 取最小值：
\tilde V_{\hat g}^{\pi}(\hat x_0)=\min_{t\in\mathbb N}\hat g\!\left(\hat x_t^\pi\right).
这里的 Reach value 表示策略 \pi 生成的整条增广轨迹上，目标函数 \hat g 曾经达到的最小值。
例如，一条轨迹各时刻的 \hat g 依次为
2.4,\quad 1.1,\quad 0.3,\quad -0.2,\quad 0.5.
其中第四个值为负，说明轨迹在这一时刻进入过增广目标集。虽然之后可能离开增广目标集，但整条轨迹的最小值仍为 -0.2，因此可以判断该策略曾经成功完成任务。
由此得到
\tilde V_{\hat g}^{\pi}(\hat x_0)\le0\quad\Longleftrightarrow\quad\exists T\in\mathbb N:\hat x_T^\pi\in\hat G.
左侧通过“对时间取最小值”检查整条轨迹，右侧表示“至少存在一个成功时刻”。两种表达完全等价。这样就不需要预先指定或逐个枚举终止时刻 T。
代入初始增广状态
\hat x_0=\left(x_0,I_{\{x_0\in F\}},z_0\right),
便得到固定策略 \pi 在候选预算 z_0 下的可行性判据：
\tilde V_{\hat g}^{\pi}\!\left(x_0,I_{\{x_0\in F\}},z_0\right)\le0.
因此，\tilde V_{\hat g}^{\pi}\le0 是固定“策略—预算”组合的可行性证书：值不大于零，表示策略 \pi 确实能在预算 z_0 内安全完成任务。现在已经能够判断“某个预算够不够”，下一步才将预算本身变成需要优化的变量。

第三步：将预算从给定上界变成优化变量
前两步已经建立了一个判断器：给定 (\pi,z_0)，可以判断策略 \pi 是否在预算 z_0 下可行。现在才将 z_0 从外部给定的成本上界变成需要优化的决策变量：在所有可行的“策略—预算”组合中，寻找最小的初始预算。
\begin{aligned}\min_{\pi,\,z_0}\quad &z_0\\\mathrm{s.t.}\quad &\tilde V_{\hat g}^{\pi}\!\left(x_0,I_{\{x_0\in F\}},z_0\right)\le0.\end{aligned}
直观地说，若测试得到 z_0=5 不可行、z_0=8 不可行、z_0=10 可行，那么最低预算位于“不可行”和“可行”的边界。与 CMDP 的固定阈值不同，这里不是验证某个预设预算够不够，而是主动寻找刚好够用的最小预算。该模型已经给出了可计算的最低预算问题，但还需确认：最小可行预算是否恰好等于原问题的最小累计成本，而非某种保守上界或近似代理。
第四步：双向证明最低预算与最小成本相等
前三步已经完成问题重写；本步验证这种重写没有改变最优解。证明需要覆盖两个方向：原问题的任意可行解都能构造为最低预算问题的可行解；最低预算问题的任意可行解也能还原为原问题中的安全到达轨迹。
对原问题任意一个可行解 (\pi,T)，令 z_0=\sum_{k=0}^{T-1}c(x_k,\pi(x_k))。由 Theorem 1，对应增广轨迹能够进入 \hat G，所以该“策略—预算”组合在最低预算问题中可行。因此 z^\star(x_0)\le J^\star(x_0)。
对最低预算问题任意一个可行解 (\pi,z_0)，Reach value 判据保证存在某个 T，使原轨迹安全到达目标且累计成本不超过 z_0。因此原问题存在成本不大于 z_0 的可行解，从而 J^\star(x_0)\le z^\star(x_0)。
两个方向合并得到
J^\star(x_0)=z^\star(x_0).
这说明最低预算模型不是替代原问题的启发式代理，而是原最低成本 Reach-Avoid 问题的等价重参数化：优化对象从“轨迹累计成本”变为“最小可行初始预算”，但最优值保持不变。当最优解能够取到时，最低预算对应的策略也就是原问题的最小成本策略。
若可行集合不是闭集，最优值可能只能无限逼近而不能被某个策略真正取到。此时应将公式中的 \min 严格理解为 \inf，但两种问题的最优值等价关系不变。

可达性值函数策略学习
核心职责
第一阶段先不搜索最小预算，而是在一段候选预算范围内学习“给定增广状态与预算时应怎样行动”，并用可达性值函数评价当前策略是否能够进入增广目标集。完整链路依次是：建立 Reach Bellman 递推、用折扣获得稳定的固定点、训练 critic、由优势更新 actor，最终得到覆盖不同预算的条件策略和值函数。

先学习预算条件策略 
3.3 已经给出固定“策略—预算”组合的可行性证书：只要 \tilde V_{\hat g}^{\pi}\le0，该策略就能在给定预算内安全完成任务。但真实系统既不知道应使用哪一个策略，也无法解析计算完整未来轨迹上的 Reach value。3.4 的任务是在样本交互中同时学习策略和价值函数，使这一判据能够被实际调用。
最低预算在训练前未知，因此策略不能只针对一个固定预算。动作分布以完整增广状态为条件：
u_t\sim\pi_\theta(\cdot\mid\hat x_t),\qquad \hat x_t=(x_t,y_t,z_t).
训练轨迹从候选区间采样初始预算
z_0\sim\mathcal U[z_{\min},z_{\max}].
这样，同一个策略会看到物理状态相同但预算不同的样本，并学会根据剩余预算调整行为。[z_{\min},z_{\max}] 必须覆盖可能出现的最优成本边界；区间过窄会使后续预算搜索落到训练分布之外。
到这一步，策略已经能在不同预算下产生候选动作；但还缺少一个标准来判断某个动作会让任务更可行还是更不可行。下面的 Reach value、动作价值和状态价值正是这一评价标准。
用 Reach value 评价固定策略 
对确定性策略和确定性增广动力学，Reach value 取整条未来轨迹上增广目标函数的最小值：
\tilde V_{\hat g}^{\pi}(\hat x_t)=\min_{k\ge t}\hat g\!\left(\hat x_k^{\pi}\right).
它回答的是“当前或未来是否有某个时刻进入增广目标集”。因为增广目标集是 \hat g 的零下水平集，所以 \tilde V_{\hat g}^{\pi}(\hat x_t)\le0 表示轨迹能够在某个时刻满足安全到达和预算约束。
轨迹最小值要么由当前状态取得，要么由下一状态之后的轨迹取得，因此有
\tilde V_{\hat g}^{\pi}(\hat x_t)=\min\!\left\{\hat g(\hat x_t),\tilde V_{\hat g}^{\pi}(\hat x_{t+1})\right\}.
\min
 表示“现在达到或以后达到”，当前状态已经足够好时保留当前值；否则继续向未来寻找更小的目标残差。
对固定策略，Reach value 给出“当前或未来能否完成任务”的状态级判据；固定当前动作的 \tilde Q 则评价“先走该动作后，任务会更可行还是更不可行”。对动作分布取平均得到 \tilde V。到这里，已经有了 actor 所需的动作好坏标准，但 \tilde V 和 \tilde Q 仍是未知函数，需要进一步学习。
随机策略会在同一状态选择不同动作。给定当前动作后，动作价值为
\tilde Q_{\hat g}^{\pi}(\hat x,u)=\min\!\left\{\hat g(\hat x),\tilde V_{\hat g}^{\pi}\!\left(\hat f(\hat x,u)\right)\right\},
状态价值再对当前策略的动作分布取平均：
\tilde V_{\hat g}^{\pi}(\hat x)=\mathbb E_{u\sim\pi(\cdot\mid\hat x)}\!\left[\tilde Q_{\hat g}^{\pi}(\hat x,u)\right].
引入折扣 
未折扣 Bellman 算子不会放大价值误差，但也不一定能让不同的价值估计逐渐靠拢。
假设系统执行任意动作后都会回到当前状态，即 \hat f(\hat x,u)=\hat x，并且当前增广目标残差为 \hat g(\hat x)=1。
此时未折扣递推变成
V_{\mathrm{new}}=\min\{1,V_{\mathrm{old}}\}.
如果两个初始估计分别为 0.3 和 0.4，更新后仍然是
0.3\rightarrow0.3,\qquad 0.4\rightarrow0.4.
两者始终相差 0.1。这说明未折扣递推只能把价值限制在当前残差以内，却没有机制消除初始化之间的差异。在这个例子中，所有不超过 1 的值都是固定点，最终结果可能取决于初始化和采样噪声。
引入 \gamma\in(0,1) 后，未来估计只以 \gamma 的比例传回来。取 \gamma=0.9，上面的递推变为
V_{\mathrm{new}}=0.1+0.9\min\{1,V_{\mathrm{old}}\}.
于是两个估计分别变化为
0.3\rightarrow0.37\rightarrow0.433\rightarrow\cdots,
0.4\rightarrow0.46\rightarrow0.514\rightarrow\cdots.
它们之间的差异按照下面的速度缩小：
0.1\rightarrow0.09\rightarrow0.081\rightarrow0.0729\rightarrow\cdots\rightarrow0.
因此，折扣因子可以在每次递推时压低旧估计的影响，让不同初始化逐渐收敛到同一个结果。
一般地，在固定策略 \pi 下定义折扣算子：
(\mathcal T_{\pi,\gamma}V)(\hat x)=(1-\gamma)\hat g(\hat x)+\gamma\,\mathbb E_{u\sim\pi}\!\left[\min\!\left\{\hat g(\hat x),V\!\left(\hat f(\hat x,u)\right)\right\}\right].
为区别原始轨迹最小值，下面把该算子的固定点记为 \tilde V_{\hat g,\gamma}^{\pi}。
对任意标量 a,v，有
(1-\gamma)a+\gamma\min\{a,v\}=\min\!\left\{a,(1-\gamma)a+\gamma v\right\}.
右侧第一项表示现在停止，第二项表示继续执行一步。
函数 v\mapsto\min\{a,v\} 是 1-Lipschitz 映射，取期望也不会放大最大误差。因此，对任意有界价值函数 V_1,V_2，有
\left\|\mathcal T_{\pi,\gamma}V_1-\mathcal T_{\pi,\gamma}V_2\right\|_\infty\le\gamma\left\|V_1-V_2\right\|_\infty.
这表示一次精确 Bellman 更新后，两个价值估计之间的最大差异最多只保留原来的 \gamma 倍。重复更新 k 次后，差异满足
\left\|\mathcal T_{\pi,\gamma}^{k}V_1-\mathcal T_{\pi,\gamma}^{k}V_2\right\|_\infty\le\gamma^k\left\|V_1-V_2\right\|_\infty.
因为 0<\gamma<1，\gamma^k 会趋近于零，不同初始化会被逐渐拉向同一个唯一的有界固定点。
折扣在这里首先是稳定递推、保证唯一固定点的数学工具，而不是普通累计奖励中“越远的奖励越不重要”的偏好设计。通常需要让 \gamma 足够接近 1，以尽量保留原始 Reach-Avoid 判据的含义；上述收缩结论针对固定策略和精确 Bellman 更新，实际 critic 仍会受到采样误差和函数逼近误差的影响。

保留可达性的符号 
收缩性保证了折扣递推稳定，但折扣固定点的数值不再必然等于原始轨迹上的最小残差。
特别是，目标到达前的正残差会持续进入递推，而较晚出现的负残差需要经过多步传播；如果 \gamma 太小，最终可达的轨迹也可能无法在起点保持负号。
一个直观例子，假设一条轨迹的增广目标残差依次为
1,\quad 1,\quad 1,\quad -1.
原始 Reach value 直接取整条轨迹的最小值：
\min\{1,1,1,-1\}=-1.
因此，原始判据能够判断这条轨迹最终可达。但如果取 \gamma=0.5，从终点反向递推得到
V_3=-1,\qquad V_2=0,\qquad V_1=0.5,\qquad V_0=0.75.
此时轨迹虽然最终到达目标，起点的折扣值却为正数。原因是 \gamma 太小，终点的负信号在向前传播时迅速衰减，被到达前的正残差覆盖。
为了给出统一的符号保持保证，考虑最不利情况：到达目标前每一步残差都取最大正值 G_{\max}，轨迹直到最晚的第 T_{\max} 步才到达目标，并且到达时至少有负裕量 -\epsilon。此时将折扣递推展开到起点，可得到上界
\tilde V_{\hat g,\gamma}^{\pi}(\hat x_0)\le(1-\gamma^{T_{\max}})G_{\max}-\gamma^{T_{\max}}\epsilon.
其中，(1-\gamma^{T_{\max}})G_{\max} 表示沿途正残差可能造成的最坏影响，\gamma^{T_{\max}}\epsilon 表示终点负信号传播到起点后仍保留的强度。要保证起点折扣值仍为负，需要满足
\gamma^{T_{\max}}\epsilon>(1-\gamma^{T_{\max}})G_{\max},
等价地，得到充分条件
\frac{\gamma^{T_{\max}}}{1-\gamma^{T_{\max}}}>\frac{G_{\max}}{\epsilon}.
这个条件要求：即使轨迹沿途一直处于最差的正残差状态，并且直到最晚时刻才到达目标，终点的负信号传播回起点后仍然强于沿途累积的正影响。
例如取 G_{\max}=1、\epsilon=1、T_{\max}=3。当 \gamma=0.9 时，最坏情况上界为
(1-0.9^3)\times1-0.9^3\times1=-0.458<0,
所以起点仍能保持负号；当 \gamma=0.5 时，上界为
(1-0.5^3)\times1-0.5^3\times1=0.75>0,
此时就不能保证折扣值正确反映最终可达性。
上述条件是按照“沿途残差最大、到达时间最晚、终点负裕量最小”的最坏情况得到的，因此通常比较保守。不满足它并不意味着轨迹一定不可达或折扣值一定为正；实际轨迹可能更早到达、沿途正残差更小，或者到达后的负残差更强。它只说明不能再用这一统一界限保证折扣值与原始 Reach-Avoid 判据保持同号。
折扣算子已经定义了 critic 应满足的唯一固定点；实际训练无法直接解析求解这一方程，只能从采样轨迹中构造一步 Bellman 目标，再让网络预测逐步逼近该目标。下面的自举回归就是把固定点方程转换为可执行的监督学习过程。
把折扣递推变成 critic 的监督目标 
原始 Reach Bellman 递推给出了正确的可达性语义，但它不保证价值迭代自动收敛到唯一答案。为了把“正确的定义”变成“稳定可训练的 critic 目标”，下面引入折扣递推；折扣不改变本节要评价的对象，而是让固定点学习具有收缩性。
折扣动作价值满足
\tilde Q_{\hat g,\gamma}^{\pi}(\hat x_t,u_t)=(1-\gamma)\hat g_t+\gamma\min\!\left\{\hat g_t,\tilde V_{\hat g,\gamma}^{\pi}(\hat x_{t+1})\right\},
其中 \hat g_t=\hat g(\hat x_t)。训练时真实的未来价值未知，因此从下一状态采样 u_{t+1}\sim\pi(\cdot\mid\hat x_{t+1})，用 critic 的下一状态估计构造当前样本的训练目标：
\bar Q_{t+1}=\tilde Q_\omega(\hat x_{t+1},u_{t+1}).
在本轮参数更新中，\bar Q_{t+1} 暂时视为固定数值，不随当前预测一起变化。于是 Bellman 目标为
y_t^Q=(1-\gamma)\hat g_t+\gamma\min\!\left\{\hat g_t,\bar Q_{t+1}\right\}.
critic 的损失为
\mathcal L_Q(\omega)=\frac12\,\mathbb E_t\!\left[\left(\tilde Q_\omega(\hat x_t,u_t)-y_t^Q\right)^2\right].
训练时，参数更新只负责让当前预测 \tilde Q_\omega(\hat x_t,u_t) 逐渐靠近暂时固定的目标 y_t^Q，不会在同一次更新中同时改变目标值。完成本轮更新后，再用新的 critic 重新计算下一批样本的目标。
这样可以避免“预测值改变、目标值也同步改变”的相互追逐，使每次 Bellman 更新都有明确的回归方向。
critic 训练完成后能够评价动作后果，但策略还需要知道“哪个动作比当前平均行为更好”，才能调整动作概率。优势函数将动作价值与策略平均价值相减，提供这一相对好坏信号；Reachability MDP 则仅用于说明 \min 结构下梯度会沿哪些状态继续传播。
从 critic 评价得到 actor 更新方向 
Reach Bellman 递推中的 \min 每一步都在比较“现在停止”和“继续前进”两种结果，因此梯度不一定沿整条轨迹传播。
例如，若当前残差和下一状态价值分别为
\hat g(\hat x_t)=0.5,\qquad V(\hat x_{t+1})=0.2,
继续前进后的结果更小，递推会沿下一状态继续传播。若
\hat g(\hat x_t)=-0.3,\qquad V(\hat x_{t+1})=0.2,
当前状态已经更好，递推会直接选择 -0.3，梯度在这里停止，不再依赖更远处的状态。
为了描述这种“停止或继续”的分支，理论上构造一个辅助 Reachability MDP：选择当前残差时进入吸收态，表示搜索在当前状态停止；选择未来价值时继续按照策略和增广动力学向前传播。这个辅助 MDP 只用于解释梯度如何传播，不是机器人实际执行的另一套动力学。
在该辅助 MDP 中，策略梯度可写为
\nabla_\theta\tilde V_{\hat g,\gamma}^{\pi_\theta}(\hat x)\propto\mathbb E_{\hat x'\sim d'_\pi,\,u\sim\pi_\theta}\!\left[\tilde A_{\hat g,\gamma}^{\pi_\theta}(\hat x',u)\nabla_\theta\log\pi_\theta(u\mid\hat x')\right].
其中，d'_\pi 是辅助 MDP 下的状态占用分布，表示哪些状态会参与更新；\nabla_\theta\log\pi_\theta 表示如何调整当前动作的概率；优势函数表示该动作相对于当前策略平均水平的好坏：
\tilde A_{\hat g,\gamma}^{\pi}(\hat x,u)=\tilde Q_{\hat g,\gamma}^{\pi}(\hat x,u)-\tilde V_{\hat g,\gamma}^{\pi}(\hat x).
由于目标是最小化可达性值，\tilde A<0 表示该动作更有利，应提高其概率；\tilde A>0 表示该动作更差，应降低其概率。
减去状态价值作为 baseline 不会改变梯度的期望，因为
\mathbb E_{u\sim\pi_\theta}\!\left[\nabla_\theta\log\pi_\theta(u\mid\hat x)\right]=0.
它只是把动作价值转换为“相对于平均水平的差异”，减少不同状态和动作之间的数值波动，使策略更新更加稳定。
用多步优势和 PPO 完成策略更新 
策略梯度给出了正确的改进方向，但有限 rollout 中的单步估计仍可能方差较大，且一次策略更新过猛会破坏已有行为。多步回推与 GAE 用于在偏差和方差之间折中，PPO clipping 则限制一次策略变化幅度；它们把理论更新方向转化为稳定、可执行的训练算法。
单步自举只使用下一状态的 critic 估计：
\mathcal R_t^{(1)}=(1-\gamma)\hat g_t+\gamma\min\!\left\{\hat g_t,\tilde V_{\hat g,\gamma}^{\pi}(\hat x_{t+1})\right\}.
多步 return 会先使用更多真实轨迹残差，再在末端使用 critic 估计未来。它不是把残差直接相加，而是沿着“现在停止或继续前进”的规则，从后往前逐步计算。
为了简洁表示这个反向计算过程，把 \Phi_k 理解为一个多步回推计算器：输入连续 k 步的真实残差和末端 critic 估计，输出一个最终的可达性目标。
当不再向后展开时，直接使用末端价值：
\Phi_0(v)=v.
向前回推一步时，将当前残差 a_0 与后续结果 v 进行折扣，并选择更小的结果：
\Phi_1(a_0;v)=(1-\gamma)a_0+\gamma\min\{a_0,v\}.
继续回推 k 步时，重复同样的操作：
\Phi_k(a_0,\ldots,a_{k-1};v)=(1-\gamma)a_0+\gamma\min\!\left\{a_0,\Phi_{k-1}(a_1,\ldots,a_{k-1};v)\right\},\qquad k\ge1.
例如，取 \gamma=0.9，两个连续真实残差为 a_0=0.4、a_1=0.2，末端 critic 估计为 v=0.1。先从后往前计算：
\Phi_1(0.2;0.1)=0.1\times0.2+0.9\times0.1=0.11,
再计算：
\Phi_2(0.4,0.2;0.1)=0.1\times0.4+0.9\min\{0.4,0.11\}=0.139.
这个过程表示：先判断第二步“停止还是继续”，得到 0.11；再用这个结果判断第一步“停止还是继续”，得到最终的两步目标 0.139。
因此，从时刻 t 展开 k 步时，令 a_i=\hat g_{t+i}，并令末端价值为 v=\tilde V_{\hat g,\gamma}^{\pi}(\hat x_{t+k})，即可得到
\mathcal R_t^{(k)}=\Phi_k\!\left(\hat g_t,\ldots,\hat g_{t+k-1};\tilde V_{\hat g,\gamma}^{\pi}(\hat x_{t+k})\right).
它使用 k 个真实目标残差，只在第 t+k 步使用 critic 补充未观察到的未来。展开步数越长，目标越依赖真实轨迹，通常偏差更小，但方差和计算量可能增加。
对应的 k 步优势为
\widehat A_t^{(k)}=\mathcal R_t^{(k)}-\tilde V_{\hat g,\gamma}^{\pi}(\hat x_t).
最后使用 \lambda 混合不同展开深度的优势，得到可达性 GAE：
\widehat A_t^{\mathrm{GAE}}=(1-\lambda)\sum_{k=1}^{\infty}\lambda^{k-1}\widehat A_t^{(k)},\qquad 0\le\lambda<1.
\lambda 较小时更依赖短步自举，方差较小但偏差可能较大；\lambda 较大时利用更长轨迹，偏差通常减小但方差可能增大。有限 rollout 中，求和会在片段末端或候选停止点截断，并用末端价值进行 bootstrap。
旧策略采样动作后，新旧策略概率比为
r_t(\theta)=\frac{\pi_\theta(u_t\mid\hat x_t)}{\pi_{\theta_{\mathrm{old}}}(u_t\mid\hat x_t)}.
由于优化方向是最小化可达性值，PPO 使用
\mathcal L_\pi(\theta)=\mathbb E_t\!\left[\max\!\left\{r_t(\theta)\widehat A_t^{\mathrm{GAE}},\;\operatorname{clip}\!\left(r_t(\theta),1-\varepsilon,1+\varepsilon\right)\widehat A_t^{\mathrm{GAE}}\right\}\right].
对该损失做梯度下降，会提高负优势动作的概率并降低正优势动作的概率。若直接套用普通奖励最大化 PPO 而不调整符号，策略更新方向会完全相反。
第一阶段怎样形成训练闭环 
采样初始预算并构造增广初始状态。
随机策略与增广动力学交互，收集状态、动作和目标残差。
critic 用折扣 Reach Bellman 目标评价当前策略。
actor 用多步优势和裁剪 PPO 改善动作分布。
在不同状态与预算上重复上述过程，得到预算条件策略和值函数。
第一阶段的产物不是最小预算本身，而是一族预算条件策略和对应的可达性值函数：
(x,y,z)\mapsto\pi_\theta(\cdot\mid x,y,z),\qquad (x,y,z)\mapsto\tilde V_{\hat g,\gamma}^{\pi_\theta}(x,y,z).
它们构成下一节所需的预算可行性判断器：对不同候选预算输入 critic，判断其可行与否，再沿预算轴搜索边界。因此，3.4 先学会“给定预算时怎样行动、是否可行”，3.5 才求“最低预算是多少”。
理论收敛分析要求 critic 在更快时间尺度上跟踪当前策略，而 actor 缓慢变化。若两者步长分别为 \beta_1(k) 和 \beta_2(k)，典型条件为
\sum_{k=0}^{\infty}\beta_i(k)=\infty,\qquad \sum_{k=0}^{\infty}\beta_i(k)^2<\infty,\qquad \beta_2(k)=o\!\left(\beta_1(k)\right),\quad i\in\{1,2\}.
再假设状态、动作、时域与预算范围有限或有界，策略和 critic 参数化连续可微，梯度满足 Lipschitz 条件，并把策略参数投影到紧致凸集。在这些条件下，简化的无 GAE 两时间尺度 actor-critic 可先使 critic 收敛到固定策略的唯一固定点，再使 actor 收敛到局部最优策略。
理论对象与工程双价值实现的关系 
上述推导直接围绕单一增广目标 \hat g 的折扣 Reach value 展开；预算约束和可达规避语义已经包含在 \hat g 中。第四章的工程实现则分别学习成本价值 V^c 与可达性价值 V^h，再构造
V^{\mathrm{joint}}=\max\!\left\{V^h,V^c-z\right\}
作为策略训练信号。这种拆分让两个 critic 各自拥有更直接的监督目标，但一般不能仅凭代数运算断言 V^{\mathrm{joint}} 与单一 Bellman 算子的固定点 \tilde V_{\hat g,\gamma}^{\pi} 完全相等；它是理论目标的一种工程分解与有限样本近似，需要由实验验证其有效性。
最小可行预算搜索
核心职责
第一阶段学习“给定预算时怎样行动和怎样评价”，第二阶段固定学习结果，把预算当作唯一搜索变量，寻找可行性从不满足变为满足的边界。
理论上的完整第二阶段包括策略确定化、确定性策略价值重估和预算边界搜索；实际输出首先是当前学习策略下的最小可行预算估计，只有当第一阶段策略达到相应最优性时，才能进一步解释为原问题的最优成本。

随机策略变确定动作 
训练阶段使用随机策略：
u_t\sim\pi_\theta(\cdot\mid\hat x_t),\qquad \hat x_t=(x_t,y_t,z_t).
同一个增广状态多次出现时，策略可能采样出不同动作。例如，某个状态下三个离散动作的概率为
(0.2,\ 0.6,\ 0.2).
训练时可能采样到三个不同动作，这种随机性有助于探索不同的行为。
部署时通常希望同样的输入得到稳定、可复现的控制动作，因此将随机策略确定化为动作分布的众数：
\pi^{\mathrm{det}}(\hat x)=\operatorname{mode}\!\left[\pi_\theta(\cdot\mid\hat x)\right].
对于离散动作，众数就是概率最大的动作；对于单峰高斯策略，众数等于高斯分布的均值。确定化后，策略不再随机采样，而是对每个增广状态直接输出一个确定动作。
价值函数微调 
第一阶段的 critic 评价的是随机策略，即同一个增广状态下不同动作按照原来的概率被混合执行。假设某个状态下动作 A 的概率为 0.6，能够安全到达目标，价值为 -1；动作 B 的概率为 0.4，会导致任务失败，价值为 1。随机策略的评价反映的是两种动作混合后的平均结果：
0.6\times(-1)+0.4\times1=-0.2.
但策略确定化后，每次都会选择概率更大的动作 A，实际执行的轨迹只会沿着 A 展开，其价值更接近 -1。因此，第一阶段 critic 学到的随机策略价值，不能直接代表部署时确定性策略的真实表现。
第二阶段固定确定性策略：
\pi^{\mathrm{det}}(\hat x)=\operatorname{mode}\!\left[\pi_\theta(\cdot\mid\hat x)\right],
停止更新 actor，只让 critic 按照确定性动作重新评价：
\tilde V_{\hat g,\gamma}^{\mathrm{det}}(\hat x)=(1-\gamma)\hat g(\hat x)+\gamma\min\!\left\{\hat g(\hat x),\tilde V_{\hat g,\gamma}^{\mathrm{det}}\!\left(\hat f\!\left(\hat x,\pi^{\mathrm{det}}(\hat x)\right)\right)\right\}.
这里不再对动作分布取期望，而是直接使用确定性策略输出的动作。
重新评价的目的只是校准“最终执行的策略会得到什么价值”，不会继续把 actor 优化成新的策略。只有这样，critic 的评价对象才与实际部署时的确定性执行轨迹一致，后续预算搜索得到的边界才具有对应的策略含义。
固定策略，寻找预算边界 
理论上的最小预算允许在所有可行策略中选择最优者。若记所有策略中最好的可达性值为
\tilde V_{\hat g}^{*}(x,y,z)=\inf_{\pi}\tilde V_{\hat g}^{\pi}(x,y,z),
则原问题的理论最优预算为
z^*(x,y)=\inf\!\left\{z\mid\tilde V_{\hat g}^{*}(x,y,z)\le0\right\}.
但训练结束后，系统通常只能评价一个已经确定化的学习策略。因此，第二阶段实际要回答的是：“当前这个策略至少需要多少预算才能完成任务？”对该策略定义折扣可行性函数：
\Phi_{x,y,\gamma}(z)=\tilde V_{\hat g,\gamma}^{\mathrm{det}}(x,y,z).
当 \Phi_{x,y,\gamma}(z)\le0 时，表示当前策略在预算 z 下被判定为可行。对应的策略预算边界为
\widehat z_{\pi^{\mathrm{det}},\gamma}(x,y)=\inf\!\left\{z\in[z_{\min},z_{\max}]\mid\Phi_{x,y,\gamma}(z)\le0\right\}.
例如，固定当前策略后，如果测试得到
\Phi(3)>0,\qquad \Phi(5)>0,\qquad \Phi(7)\le0,
就说明预算 3 和 5 不够，预算 7 已经可行，真正的边界位于 5 和 7 之间。这个边界描述的是当前策略和当前折扣 critic 下的最低预算，不自动等于所有策略中的理论最优预算 z^*(x,y)。
为了在预算轴上定位这个边界，先假设可行预算集合非空，并且预算越大可行性不会消失。于是只需找到一个左端不可行、右端可行的括区间：
\Phi_{x,y,\gamma}(z_L)>0,\qquad \Phi_{x,y,\gamma}(z_U)\le0,\qquad z_L<z_U.
二分搜索每轮取中点
m_k=\frac{z_L^{(k)}+z_U^{(k)}}{2}.
如果中点可行，说明可以继续尝试更小的预算，收紧上界；如果中点不可行，说明预算仍然不足，提高下界：
\left(z_L^{(k+1)},z_U^{(k+1)}\right)=\begin{cases}\left(z_L^{(k)},m_k\right),&\Phi_{x,y,\gamma}(m_k)\le0,\\\left(m_k,z_U^{(k)}\right),&\Phi_{x,y,\gamma}(m_k)>0.\end{cases}
每轮都会把搜索区间缩小一半。经过 K 轮后，区间宽度为
z_U^{(K)}-z_L^{(K)}=\frac{z_U^{(0)}-z_L^{(0)}}{2^K}.
如果希望宽度不超过 \delta_z>0，只需满足
K\ge\left\lceil\log_2\!\frac{z_U^{(0)}-z_L^{(0)}}{\delta_z}\right\rceil.
在“左端不可行、右端可行”的前提下，返回 z_U^{(K)} 可以保留当前判据下的可行性，但可能略大于真实边界；返回区间中点误差更对称，却不保证一定处于可行侧。
此外，\widehat z_{\pi^{\mathrm{det}},\gamma} 使用的是折扣 critic。只有当当前策略接近最优、critic 评价足够准确，并且 3.4 的符号保持条件成立时，它才可以近似原问题的理论最优预算 z^*(x,y)。
预算边界怎样用于控制 
预算边界可以理解为“从当前状态继续完成任务所需的最低剩余预算”。 在线控制时，系统每到一个新状态，就重新估计这条边界，再把它和当前物理状态、安全记忆一起交给策略。预算较紧时，策略会倾向于选择更节省成本的动作；预算较充足时，则可以保留更安全的绕行选择。
\widehat z_t=\inf\!\left\{z\mid\Phi_{x_t,y_t,\gamma}(z)\le0\right\},\qquad u_t=\pi^{\mathrm{det}}(x_t,y_t,\widehat z_t).
这里的 \widehat z_t 表示从当前状态出发，当前策略至少还需要多少预算。例如上一时刻估计还需 5，执行一步花费 1 后如果进入了更开阔的位置，新的边界可能降到 3；如果进入更狭窄、更难通过的区域，边界也可能升高。因此，它不是简单地把上一时刻的预算减去当前单步成本，而是根据最新状态和安全记忆重新评估得到的结果。
如果每一步都在线进行二分，计算开销可能较大。一个加速办法是：先在大量代表性状态上离线搜索预算边界，把这些结果作为监督信号，训练预算回归器 h_\psi(x,y)\approx\widehat z(x,y)。部署时直接预测预算，再将其输入策略，响应会更快。但回归器会受到训练状态覆盖不足和预测误差的影响，尤其可能低估所需预算，因此它只是工程上的加速方案，不能自动继承在线搜索返回可行上界的保证。
全部推导链条总结
整条理论链可以沿下面的顺序复核。 每一步只引入解决当前困难所需的新对象，并始终区分原问题的全局最优预算、学习策略对应的预算边界，以及双价值网络给出的工程近似结果。
原问题： 在某个尚未知晓的首次到达时刻 T，要求 x_T\in G 且到达前始终满足 x_t\notin F，并在所有满足这些硬约束的策略与到达时刻中最小化累计执行成本 \sum_{t=0}^{T-1}c(x_t,u_t)。
预算可行性： 先给定候选预算 z_0，只判断是否存在安全到达且累计成本不超过该预算的策略；使这一可行策略集合首次非空的预算下确界，才是原问题的最优值 z^*。
增广状态与动力学： 引入 \hat x=(x,y,z)。物理状态 x 按原动力学演化，安全记忆 y 保留轨迹是否曾进入危险集的信息，剩余预算 z 随每步成本递减。这样，依赖历史的安全与预算条件重新成为当前状态的一部分。
增广目标与等价性： 用 \hat g(x,y,z)=\max\{g(x),Cy,-z\} 把到达、安全和预算三项条件合成增广目标集 \hat G=\{\hat x\mid\hat g(\hat x)\le0\}。Theorem 1 表明，对固定策略、预算和时刻，原系统满足三项条件，当且仅当增广轨迹在该时刻进入 \hat G。
原始 Reach value： 定义 \tilde V_{\hat g}^{\pi}(\hat x_0)=\min_t\hat g(\hat x_t^{\pi})，用对时间的最小化吸收未知到达时刻。于是 \tilde V_{\hat g}^{\pi}(\hat x_0)\le0 等价于该策略在某个时刻满足增广目标条件。
随机策略与 SRBE： 为了训练随机策略，对动作分布取期望，得到随机可达值和动作值的 Bellman 递推。这里的值仍表示轨迹上的最小瓶颈，不是累计奖励，也不是成功概率。
折扣固定点： 引入 \gamma\in(0,1) 得到折扣值 \tilde V_{\hat g,\gamma}^{\pi} 和收缩 Bellman 算子，从而可以稳定地做固定点学习。Theorem 3 只在真实可达值具有严格负间隔且 \gamma 足够接近 1 时，保证折扣值仍保持可行性的负号判定。
策略评价： critic 用折扣 Bellman 目标逼近当前策略的可达性值，使后续每个状态—动作决策都有可学习的长期评价基线。评价误差必须先收敛到足够小，actor 的更新方向才具有理论意义。
策略更新： Reachability MDP 用吸收机制表达瓶颈递推中的梯度截断，再由多步 return、GAE 和 PPO 构造低方差更新信号。由于目标是最小化可达值，优势符号与普通“最大化奖励”PPO 的解释方向相反。
第一阶段输出： 第一阶段得到的是依赖候选预算的随机策略及其折扣价值估计。进入预算搜索前，需要将策略确定化，例如取动作分布的 mode，并在该确定性策略下重新评价价值；随机策略的 critic 不能直接当作确定性策略的精确价值。
理论第二阶段： 对重新评价后的确定性策略定义预算边界 \widehat z_{\pi^{\mathrm{det}},\gamma}=\inf\{z\mid\tilde V_{\hat g,\gamma}^{\mathrm{det}}(x,y,z)\le0\}，再在满足单调性和有效括区间的前提下做一维搜索。它描述的是当前学习策略在折扣评价下的可行边界，通常不等于对所有策略取下确界得到的 z^*。
工程分解与理论边界： 当前实现用成本价值和可达性价值构造 V^{\mathrm{joint}}=\max\{V^h,V^c-z\} 并据此训练与搜索。这是对单一增广 Reach value 的工程分解，不能仅凭代数形式断言二者固定点完全相同；同时，Theorem 4 只覆盖满足两时间尺度、投影和有界性等假设的简化 actor-critic，并提供局部而非全局收敛保证。
工程实现
工程架构
整个系统由 两大阶段、五个大组件 构成：
第一阶段：预算条件策略学习环境负责维护增广状态；
两个价值网络分别回答“还要花多少成本”和“还能否安全到达”；
策略网络利用二者共同形成的训练信号学习动作；

第二阶段：最小可行预算搜索
预算搜索则在第一阶段结果上寻找最小可行预算。

两个阶段
第一阶段解决“给定物理状态、安全历史和预算时应该怎样行动”；
第二阶段解决“为了保持任务可行，当前状态至少需要多少预算”。
\underbrace{(x,y,z)\mapsto\pi_\theta(\cdot\mid x,y,z)}_{\text{第一阶段：学习给定预算下如何行动}}\qquad\Longrightarrow\qquad\underbrace{(x,y)\mapsto\widehat z_{\pi^{\mathrm{det}},\gamma}(x,y)}_{\text{第二阶段：寻找当前确定性策略的可行边界}}
前者学习预算条件策略和值函数，后者沿预算维度寻找可行边界。

环境模块的关键任务，是把原本依赖整条轨迹的安全历史和累计成本转化为当前状态的一部分。
完成这一步之后，策略和值函数只需要读取当前增广观测，就能判断此前是否已经违规、当前还剩多少预算，以及接下来应如何行动。

安全记忆 
采用 y_t=1 表示截至当前仍然安全，采用 y_t=-1 表示历史上已经发生违规。状态一旦进入危险区域，失败标记会持续保留：
y_{t+1}=\begin{cases}-1,&x_{t+1}\in F,\\y_t,&x_{t+1}\notin F.\end{cases}
这一正负号约定与理论推导中的 shifted indicator 方向相反，但表达的逻辑相同：安全记忆一旦记录违规，后续状态不能通过离开危险区把历史违规“清除”。

剩余预算 
每执行一步动作，环境计算单步成本 c_t=c(x_t,u_t)，再从当前预算中扣除：
z_{t+1}=\operatorname{clip}\!\left(z_t-c_t,\;z_{\min},\;z_{\max}\right).
z_t 表示“还可以使用多少预算”，不是当前步的能量消耗。若忽略数值裁剪，连续递推可得到
z_t=z_0-\sum_{k=0}^{t-1}c_k.
因此，预算变量把历史累计成本压缩为当前剩余量。策略不必重新读取整条轨迹，只需读取 z_t，就能感知当前动作选择受到多大的成本约束。
最终增广观测 
策略网络和两个价值网络接收的输入由物理观测、安全记忆和剩余预算拼接得到：
\hat o_t=\operatorname{concat}\!\left(x_t,y_t,z_t\right)\in\mathbb{R}^{40+1+1}=\mathbb{R}^{42}.
其中，x_t 为 40 维原始导航状态，y_t 和 z_t 各占 1 维，策略网络和两个价值网络接收 42 维增广观测。
环境运行过程 
一次环境交互可以概括为四个动作：
初始化原始导航状态，并根据初始位置设置安全记忆、预算和可达性信号；
根据策略动作推进物理动力学，并计算当前步成本；
更新安全记忆、剩余预算和新的可达性信号；
输出新的增广观测、单步成本、终止信息和训练所需的辅助量。
成本价值评估模块
核心职责
成本价值评估模块根据当前任务的增广观测，估计在现有策略下继续运行至候选停止点还需要付出的累计执行成本。
该估计不会单独决定动作，而是先与剩余预算比较，再和可达性价值合成为策略学习所需的联合可行性信号。

输入输出
模块输入： 接收环境按任务构造的增广观测 o_t。
模块输出： 给定策略 \pi 和训练阶段为时刻 t 选出的候选停止点 \tau_t^*，估计从当前时刻运行到该停止点所需的累计执行成本：
V_{\omega}^{c}(o_t)\approx\mathbb E_{\pi}\!\left[\sum_{k=t}^{\tau_t^*-1}\gamma_c^{k-t}c_k\,\middle|\,o_t\right].
其中，c_k\ge 0 是环境定义的单步执行成本，\gamma_c 是成本折扣因子。
数值越大，表示按当前策略继续运行预计需要付出更多成本；数值越小，表示后续成本负担更轻。
成本价值网络 V_{\omega}^{c}(o_t)  不是预测“还剩多少预算”，而是预测从现在开始还会消耗多少。
z_t 记录已经扣除历史消耗后的剩余预算，二者相减才表示未来成本是否可能超出当前预算。

成本价值网络结构 
成本价值网络使用四层等宽的全连接隐藏层，将任务相关观测逐层压缩为一个实数。逐层计算为
h_t^{c,1}=\phi(W_1^c o_t+b_1^c),
h_t^{c,2}=\phi(W_2^c h_t^{c,1}+b_2^c),
h_t^{c,3}=\phi(W_3^c h_t^{c,2}+b_3^c),
h_t^{c,4}=\phi(W_4^c h_t^{c,3}+b_4^c),
V_{\omega}^{c}(o_t)=W_5^c h_t^{c,4}+b_5^c.
四个隐藏层的宽度均为 512。激活函数由训练配置选择：配置为 ReLU 时使用 ReLU，其余情况使用 \tanh，默认值为 \tanh；输出层不使用激活函数。隐藏层采用增益为 \sqrt{2} 的正交初始化，输出层采用增益为 1 的正交初始化，所有偏置初始化为零。
选择训练所用的候选停止点 
交互轨迹会一直运行到环境规定的时域结束，但 Reach-Avoid 任务只要求机器人在某个时刻安全到达目标。成本价值不能把所有时刻的成本都累加进来，而要先回答：从当前时刻 t 出发，应该把轨迹上的哪个位置当作本次评价的终点？
训练时会依次考察后面的多个候选时刻 \tau\ge t。对每个候选点，分别检查两件事：
\widehat C_{t,\tau}-z_t：从 t 运行到 \tau 的预计累计成本是否超过剩余预算；小于等于零表示预算够用。
\widehat H_{t,\tau}：到达候选点时的可达规避质量；小于等于零表示候选点满足安全到达要求。
其中，\widehat C_{t,\tau} 是候选轨迹段的累计成本，\widehat H_{t,\tau} 是候选端点的可达规避评价。
若候选位置延伸到当前采样片段之外，则使用两个价值网络在片段末端补上后续估计。

候选点的整体评价定义为
\Psi_{t,\tau}=\max\!\left\{\widehat C_{t,\tau}-z_t,\;\widehat H_{t,\tau}\right\}.
这里取最大值，是因为预算和安全到达必须同时满足：只要其中一项较差，候选点的整体评价就由这项决定。\Psi_{t,\tau} 越小越好；当它小于等于零时，说明该候选点同时满足预算和 Reach-Avoid 条件。
系统最终选择整体评价最小的候选时刻：
\tau_t^*\in\operatorname*{arg\,min}_{\tau\ge t}\Psi_{t,\tau}.
较早的候选点通常成本较低，但可能尚未到达目标；较晚的候选点可能已经到达目标，却消耗了过多预算。上式就是在这些候选点中选择综合表现最好的一个。
选定 \tau_t^* 后，训练过程把相应位置标记为停止点，并构造停止掩码 d_t\in\{0,1\}。成本价值只学习“从当前时刻运行到该停止点需要多少成本”，停止点之后的成本不再向前传播。
停止掩码表示算法从采样轨迹中选出的评价终点，不是碰撞、超时或环境结束等物理终止信号。

用 TD 和 GAE 估计到停止点的剩余成本 
停止点确定后，计算成本价值网络应该学习的目标。
用网络当前预测的剩余成本，以及“当前一步成本加上下一时刻预计成本”。二者的差就是成本 TD 残差：
\delta_t^c=\left(c_t+\gamma_c V_{\omega}^{c}(o_{t+1})(1-d_{t+1})\right)(1-d_t)-V_{\omega}^{c}(o_t).
停止掩码决定这条递推在哪里结束：
普通时刻：d_t=d_{t+1}=0，用“当前成本 + 下一时刻价值”修正当前预测。
下一时刻是停止点：d_{t+1}=1，只保留当前一步成本，不再估计停止点之后的消耗。
当前时刻就是停止点：d_t=1，从停止点继续运行的目标成本为零。
单步 TD 只向前看一步，容易受到当前价值估计误差影响。GAE 将后续多个时刻的 TD 残差反向累积，使训练目标同时利用短期成本和更长轨迹信息：
A_t^c=\delta_t^c+\gamma_c\lambda_c(1-d_t)(1-d_{t+1})A_{t+1}^c.
\lambda_c 控制使用多长的轨迹信息，默认值为 0.95；两个停止因子保证递推不会跨过选定的候选终点。最后，把成本优势加回采样时的旧价值，得到成本价值网络的监督目标：
Y_t^c=A_t^c+V_{\omega,\mathrm{old}}^c(o_t).
Y_t^c 回答“从当前时刻到候选停止点预计还要花多少成本”。这里的 A_t^c 用于训练成本价值网络，不是直接更新策略的最终优势。

裁剪价值损失限制单次更新 
监督目标由当前轨迹和旧网络共同计算，一次更新幅度过大，下一轮计算目标也会大幅变化，训练容易产生振荡。
保留采样时的旧预测 V_{t,\mathrm{old}}^c，构造一个最多只允许移动 \epsilon 的裁剪预测：
\bar V_t^c=V_{t,\mathrm{old}}^c+\operatorname{clip}\!\left(V_{\omega}^c(o_t)-V_{t,\mathrm{old}}^c,-\epsilon,\epsilon\right).
训练时分别计算新预测和裁剪预测相对于目标的误差，并使用两者中较大的一个：
\mathcal L_c=\frac{1}{2}\,\mathbb E_t\!\left[\max\!\left\{\left(V_{\omega}^c(o_t)-Y_t^c\right)^2,\left(\bar V_t^c-Y_t^c\right)^2\right\}\right].
如果新价值只做小幅修正，损失与普通平方误差基本一致；
如果新价值一步移动得过远，裁剪分支会阻止它通过大幅跳动获得看似更小的损失；
默认裁剪范围为 \epsilon=0.2，成本价值损失再乘以价值损失系数 \alpha_v=0.5。
裁剪的目的是限制一次参数更新相对于采样时旧预测的有效改进幅度，使网络通过多轮小步更新逐渐接近目标。

可达性价值评估模块
核心职责
可达性价值评估模块根据当前增广观测，判断现有策略是否仍有机会在保持安全的同时到达目标。
它输出的是连续的 Reach-Avoid 可行性评价，不是成功概率，也不是简单的成功或失败分类。

输入、输出与可达性价值含义 
模块输入：接收环境按任务构造的增广观测 o_t。
模块输出：将当前策略从该状态继续运行时，未来能够达到的最好可达规避水平压缩为一个标量：
V_{\eta}^{h}(o_t)\equiv V_{\mathrm{reach}}(o_t).
为了理解这个输出，先看环境在当前时刻给出的即时可达性残差：
h_t=g_t^{\mathrm{reach}}.
h_t 只描述“机器人此刻是否已经安全到达”；V_{\eta}^{h}(o_t) 则向前观察当前策略的未来轨迹，估计“从现在继续执行，之后能够达到怎样的可达规避状态”。二者都遵循数值越小越好的方向，但评价的时间范围不同。
数值范围
 | h_t 的即时含义
 | V_{\eta}^{h}(o_t) 的未来含义
 | 
负值
 | 当前已经安全到达目标区域。
 | 预计当前策略能够在未来安全到达。
 | 
零附近
 | 当前状态接近满足或违反条件的边界。
 | 预计未来结果接近可行性边界。
 | 
正值
 | 当前尚未到达，或者已经发生安全违规。
 | 预计未来轨迹仍未满足 Reach-Avoid 要求。
 | 
可达性价值不是成功概率。数值从 0.4 降到 0.2，只表示未来的可达规避评价得到改善，不表示成功概率从 40% 变成 20%。

可达性价值网络结构 
可达性价值网络与成本价值网络采用相同规模的四层等宽全连接隐藏层，但参数完全独立，不共享特征或输出。为避免与即时可达性残差 h_t 混淆，下面用 \xi_t^{h,\ell} 表示第 \ell 层隐藏特征。逐层计算为
\xi_t^{h,1}=\phi(W_1^h o_t+b_1^h),
\xi_t^{h,2}=\phi(W_2^h \xi_t^{h,1}+b_2^h),
\xi_t^{h,3}=\phi(W_3^h \xi_t^{h,2}+b_3^h),
\xi_t^{h,4}=\phi(W_4^h \xi_t^{h,3}+b_4^h),
V_{\eta}^{h}(o_t)=W_5^h \xi_t^{h,4}+b_5^h.
四个隐藏层的宽度均为 512。激活函数由训练配置选择：配置为 ReLU 时使用 ReLU，其余情况使用 \tanh，默认值为 \tanh；输出层不使用激活函数。隐藏层采用增益为 \sqrt{2} 的正交初始化，输出层采用增益为 1 的正交初始化，所有偏置初始化为零。

两个价值网络结构相同，只表示它们使用相同规模的函数近似器。成本价值学习加法型累计成本，可达性价值学习由当前状态与未来状态共同决定的瓶颈值，因此两者必须独立训练。

在当前结果与未来结果之间选择 
Reach-Avoid 只要求轨迹在某个时刻安全到达，因此已经发生的成功不应被之后的状态推翻。所以价值计算需要判断：应该把当前时刻作为轨迹的评价落点，还是继续向后寻找更好的可达规避状态。
例如，一条轨迹可能经历以下状态：
时刻
 | 机器人状态
 | 即时残差 h_t
 | 
t=0
 | 距离目标较远
 | 0.8
 | 
t=1
 | 已经接近目标
 | 0.3
 | 
t=2
 | 安全进入目标区域
 | -0.2
 | 
t=3
 | 随后又离开目标
 | 0.4
 | 
虽然机器人在 t=3 已经离开目标，但它在 t=2 曾经安全到达，因此这条轨迹仍应被判定为成功。递推在每一步都比较当前结果与继续一步的结果。继续一步的候选值为
D_t=(1-\gamma_h)h_t+\gamma_h V_{\eta}^{h}(o_{t+1}),
再选择数值更小、也就是更有利的一项：
R_t=\min\!\left\{h_t,D_t\right\}.
在上面的例子中，取 \gamma_h=0.9，并令 V_{\eta}^{h}(o_2)=-0.2。
从 t=1 继续一步的候选值为
D_1=0.1\times0.3+0.9\times(-0.2)=-0.15.
因为 -0.15<0.3，递推选择继续前进；
到达 t=2 后，当前残差已经为负，后续即使变差，最小值仍会保留这次成功。这样便能自动找到轨迹中最合适的评价时刻，不需要预先规定机器人必须在第几步到达。
\gamma_h 同时控制未来信息的传播和递推稳定性。训练配置从 0.999 逐步提高到 0.99999：前期收缩更强，便于稳定学习；后期更接近 1，能够更完整地保留长时域的到达信息。
最小值递推负责判断“最好结果在现在还是未来”，停止掩码 d_t 则负责确定多步训练目标真正在哪里截断。若 d_t=1，表示当前时刻已被选为本次训练的候选停止点，继续分支不再参与计算：
d_t=1\quad\Longrightarrow\quad R_t=h_t.
例如，如果上面的 t=2 被选为停止点，t=3 及其后的状态就不能再向前影响这次训练目标。这里的 d_t 是根据整段轨迹重新构造的训练掩码，不是环境返回的 episode 终止标记。
\min 决定轨迹的最好评价时刻出现在现在还是未来；d_t 决定训练信号传播到哪里为止。二者都不表示机器人在物理环境中执行停车动作。

用多步目标构造可达性 GAE 
单步目标只查看下一时刻的价值估计，当前价值网络一旦有误差，这个误差就会直接进入训练目标。为减轻这种依赖，系统从同一时刻向后展开不同步数，构造多个可达性候选目标。
先不展开真实轨迹时，直接使用采样时保存的旧价值网络作为 bootstrap：
R_{0,t}=V_{\eta,\mathrm{old}}^h(o_t),
令 R_{k,t} 表示从时刻 t 向后查看 k 步真实轨迹后得到的候选目标。每增加一步，系统都在“保留当前残差”和“继续前进”之间选择数值更小的一项：
R_{k,t}=\min\!\left\{h_t,(1-\gamma_h)h_t+\gamma_h R_{k-1,t+1}\right\},\qquad k\ge1.
例如，某条轨迹的即时残差依次为 h_0=0.8、h_1=0.6、h_2=0.4、h_3=-0.4，最后一个负值表示机器人在 t=3 安全到达目标。取 \gamma_h=0.9，并用这些数值简化表示各步的旧网络预测，则从 t=0 出发展开不同深度可得到
R_{1,0}=0.62,\qquad R_{2,0}=0.458,\qquad R_{3,0}\approx-0.125.
只展开一步时，目标还看不到后面的成功；展开到三步后，t=3 的负信号已经传回起点。多步目标的作用，就是让训练同时参考较近的网络预测和较远的真实轨迹结果。
展开得越短，目标越依赖旧 critic，通常更稳定但可能有偏差；展开得越长，目标使用更多真实轨迹，能够更早看到后面的到达信号，但也可能带来更多噪声。系统用 \lambda_h 和停止掩码生成归一化权重，默认 \lambda_h=0.95，并将不同深度的候选目标混合起来。若候选停止点在某个端点，端点之后的状态不会继续获得权重。
混合后的可达性目标、可达性优势分别为
Q_t^h=\sum_k\widetilde w_{k,t}R_{k,t},\qquad\sum_k\widetilde w_{k,t}=1.
Q_t^h 同时作为 critic 的回归目标，并与旧价值预测作差得到可达性优势：
Y_t^h=Q_t^h,\qquad A_t^h=Q_t^h-V_{\eta,\mathrm{old}}^h(o_t).
Q_t^h 不是奖励逐步相加得到的传统 return，而是多个“未来最好可达规避水平”的加权结果。Y_t^h 用来训练可达性价值网络；A_t^h 只表示可达性目标相对于旧预测的改善程度，不直接作为最终策略优势。

用裁剪价值损失稳定更新 
可达性目标依赖当前轨迹、旧价值网络和候选停止点。如果新价值在一次更新中变化过大，下一轮目标也会明显移动，容易造成训练振荡。因此，系统先基于采样时的旧预测构造裁剪值：
\bar V_t^h=V_{t,\mathrm{old}}^h+\operatorname{clip}\!\left(V_{\eta}^h(o_t)-V_{t,\mathrm{old}}^h,-\epsilon,\epsilon\right).
随后比较新预测和裁剪预测相对于目标 Y_t^h 的平方误差，并使用较大的一个：
\mathcal L_h=\frac{1}{2}\,\mathbb E_t\!\left[\max\!\left\{\left(V_{\eta}^h(o_t)-Y_t^h\right)^2,\left(\bar V_t^h-Y_t^h\right)^2\right\}\right].
默认裁剪范围为 \epsilon=0.2，价值损失系数为 \alpha_v=0.5。这与成本价值网络使用相同的稳定更新原则，但两个网络分别针对自己的监督目标计算损失并独立更新。
策略决策模块
核心职责
策略决策模块读取当前任务的增广观测，输出下一步动作分布，并从中生成实际控制动作。
它是三个学习模块中唯一直接控制环境的组件；两个价值网络负责评价，并通过训练信号改变策略参数，而不直接参与每一步动作计算。

输入、输出与策略决策含义 
模块输入：策略网络接收当前增广观测 o_t。两个价值网络的预测结果不会直接拼接到策略输入中。
模块输出：策略网络根据 o_t 生成动作分布
\pi_\theta(\cdot\mid o_t),
并从该分布中产生当前控制动作。
两个价值网络不参与每一步动作的前向计算，而是在训练阶段通过联合优势调整策略参数 \theta。因此，策略执行时只读取增广观测，价值网络影响的是策略如何学习。

策略网络结构 
策略网络先用四层全连接网络提取当前增广观测中的决策信息：
h_t^{\pi,1}=\phi(W_1^{\pi}o_t+b_1^{\pi}),
h_t^{\pi,2}=\phi(W_2^{\pi}h_t^{\pi,1}+b_2^{\pi}).
h_t^{\pi,3}=\phi(W_3^{\pi}h_t^{\pi,2}+b_3^{\pi}),
h_t^{\pi,4}=\phi(W_4^{\pi}h_t^{\pi,3}+b_4^{\pi}).
四个隐藏层的宽度均为 512。激活函数由配置选择：配置为 ReLU 时使用 ReLU，其余情况使用 \tanh，默认值为 \tanh。输出层再把隐藏表示转换为动作分布参数：
o_t[d_o]\longrightarrow\mathrm{Dense}(512)\longrightarrow\phi\longrightarrow\mathrm{Dense}(512)\longrightarrow\phi\longrightarrow\mathrm{Dense}(512)\longrightarrow\phi\longrightarrow\mathrm{Dense}(512)\longrightarrow\phi\longrightarrow\text{动作分布参数}.
隐藏层使用增益为 \sqrt{2} 的正交初始化和零偏置。动作输出层使用较小的初始化增益 0.01，使训练初期的动作偏好接近零，降低未经训练的策略立即输出大幅控制的风险。
连续动作：同时学习动作倾向和探索范围 
连续控制不能只输出一个固定动作。训练初期，策略还需要尝试同一状态下的不同控制，才能比较哪些动作更容易安全到达且不超预算。因此，网络输出的是一个高斯动作分布。
隐藏表示首先映射为动作均值：
\mu_\theta(o_t)=W_5^{\pi}h_t^{\pi,4}+b_5^{\pi}\in\mathbb R^{d_a}.
策略还维护一个与动作维度相同的可学习对数标准差，形成对角高斯分布：
\sigma_\theta=\exp(\log\sigma_\theta),\qquad \pi_\theta(\cdot\mid o_t)=\mathcal N\!\left(\mu_\theta(o_t),\operatorname{diag}(\sigma_\theta^2)\right).
\mu_\theta(o_t) 表示当前更倾向采取的动作，\sigma_\theta 表示探索范围。训练时从分布中采样原始动作：
\widetilde u_t\sim\pi_\theta(\cdot\mid o_t).
环境再通过 \tanh 将原始动作压缩到有界范围，并根据具体任务映射为实际控制量：
u_t=\tanh(\widetilde u_t).
策略分布定义在变换前的原始动作上；环境负责动作限幅和任务相关的物理缩放。训练轨迹同时保存原始动作在旧策略下的对数概率，供后续计算策略概率比

价值/策略网络联合训练
核心职责
两个价值网络分别学习“未来要花多少成本”和“未来能否安全到达”，策略网络则需要把这两类评价合成为一个动作更新方向。
联合训练不会新增第三个价值网络，而是在每批轨迹上临时构造联合瓶颈值和联合优势，再用 PPO 同步更新策略网络与两个价值网络。

同一批轨迹产生三条更新路径 
更新对象
 | 直接训练信号
 | 学习目标
 | 
成本价值网络
 | 成本目标 Y_t^c
 | 逼近候选停止点之前的累计执行成本。
 | 
可达性价值网络
 | 可达性目标 Y_t^h
 | 逼近到达与安全条件共同决定的可达性值。
 | 
策略网络
 | 联合优势 A_t^{\mathrm{joint}}
 | 提高能够同时改善预算可行性和可达规避结果的动作概率。
 | 
两个 critic 不去拟合同一个“混合标签”，actor 也不直接相加成本优势与可达性优势。三条路径共享轨迹和候选停止掩码，但各自保留清晰的训练职责。
把两类评价合成为联合瓶颈 
策略需要知道当前动作最终会被哪一项条件卡住。系统先在即时量和未来预测两个层面分别取最大值，让成本预算与可达规避中较差的一项决定联合质量：
g_t^{\mathrm{joint}}=\max\!\left\{h_t,-z_t\right\},
V_t^{\mathrm{joint}}=\max\!\left\{V_t^h,V_t^c-z_t\right\}.
h_t 是当前增广状态的可达性残差，-z_t 表示当前预算是否已经出现缺口；V_t^h 预测未来的可达规避质量，V_t^c-z_t 判断预计未来成本是否超过剩余预算。
四个量都采用“越小越好、零以下可行”的统一方向。于是，联合量小于等于零意味着两项条件都不为正；只要其中一项仍为正，最大值就会保留这项尚未解决的瓶颈。
V_t^{\mathrm{joint}} 是双价值预测和当前预算的即时组合，不是第三个网络的输出，也没有单独的参数需要训练。

从联合瓶颈构造多步策略信号 
只比较当前联合量与当前联合价值，无法判断动作对后续轨迹的影响。系统沿用 Reach Bellman 的“现在停止或继续一步”结构，从联合即时量和联合未来价值构造多步候选回报。
以零步预测作为递推边界：
Q_{t}^{\mathrm{joint},(0)}=V_t^{\mathrm{joint}}.
继续展开 k 步时，联合回报递推为
Q_t^{\mathrm{joint},(k)}=\min\!\left\{g_t^{\mathrm{joint}},\;(1-\gamma_\pi)g_t^{\mathrm{joint}}+\gamma_\pi Q_{t+1}^{\mathrm{joint},(k-1)}\right\},\qquad k\ge1.
第一项表示把当前时刻作为候选停止点，第二项表示继续一步后再评价；取最小值就是在两种选择中保留更有利的联合结果。4.6 构造的候选停止掩码 d_t 会截断被选终点之后的递推，避免把无关的更晚状态继续传回当前时刻。
不同展开深度包含的信息量不同。系统使用由 \lambda、有效时域和停止掩码共同确定的归一化权重进行混合：
\bar Q_t^{\mathrm{joint}}=\sum_{k=1}^{K_t}\widetilde w_{k,t}Q_t^{\mathrm{joint},(k)},\qquad \widetilde w_{k,t}\ge0,\qquad \sum_{k=1}^{K_t}\widetilde w_{k,t}=1.
\lambda 越小，权重越偏向短期候选；\lambda 越大，越多利用长轨迹信息。候选停止点或 rollout 末端会缩短当前位置实际可用的展开深度 K_t。
最终联合优势为
A_t^{\mathrm{joint}}=\bar Q_t^{\mathrm{joint}}-V_t^{\mathrm{joint}}.
A_t^{\mathrm{joint}}<0 表示该动作得到的联合结果优于当前基线，应提高其概率；A_t^{\mathrm{joint}}>0 表示结果更差，应降低其概率。这里优化的是需要最小化的瓶颈值，因此符号解释与普通奖励最大化 PPO 相反。
用裁剪 PPO 更新策略 
rollout 由旧策略采样。更新时重新计算当前策略对同一动作的概率，并用新旧概率比衡量策略变化：
r_t(\theta)=\exp\!\left(\log\pi_\theta(\widetilde u_t\mid o_t)-\log\pi_{\mathrm{old}}(\widetilde u_t\mid o_t)\right).
为避免同一批旧数据把策略推得过远，将概率比限制在 [1-\epsilon,1+\epsilon]：
\bar r_t(\theta)=\operatorname{clip}\!\left(r_t(\theta),1-\epsilon,1+\epsilon\right).
对 minibatch 内标准化后的联合优势 \widehat A_t^{\mathrm{joint}}，策略使用最小化方向的保守目标：
\mathcal L_{\mathrm{actor}}(\theta)=\mathbb E_t\!\left[\max\!\left\{r_t(\theta)\widehat A_t^{\mathrm{joint}},\;\bar r_t(\theta)\widehat A_t^{\mathrm{joint}}\right\}\right].
取最大值会选取对梯度下降更保守的一侧：有利动作不能被一次性大幅增权，不利动作也不能被一次性过度压低。加入熵正则后，完整策略损失为
\mathcal L_{\mathrm{policy}}=\mathcal L_{\mathrm{actor}}-\eta\,\mathcal H(\pi_\theta).
\eta 控制探索强度；启用退火时，它会随训练推进逐渐减小，使策略从早期探索过渡到后期稳定决策。
分别校正两个价值网络 
两个 critic 分别回归各自模块已经构造好的目标。对 m\in\{c,h\}，先相对采样时旧预测限制单次变化：
V_{t,\mathrm{clip}}^m=V_{t,\mathrm{old}}^m+\operatorname{clip}\!\left(V_{t,\mathrm{new}}^m-V_{t,\mathrm{old}}^m,-\epsilon,\epsilon\right).
再取未裁剪误差与裁剪误差中的较大者：
\mathcal L_m=\frac12\,\mathbb E_t\!\left[\max\!\left\{(V_{t,\mathrm{new}}^m-Y_t^m)^2,(V_{t,\mathrm{clip}}^m-Y_t^m)^2\right\}\right],\qquad m\in\{c,h\}.
价值裁剪不会改变 Y_t^c 或 Y_t^h 的含义，只限制 critic 在一批有限数据上的单次移动幅度。成本与可达性目标仍由各自模块独立负责。
一批数据怎样完成联合更新 
固定 rollout 产生目标和优势后，时间维与并行环境维被展平、随机打乱并切成 minibatch。同一批目标在多个 epoch 内重复使用；每个 minibatch 分别更新策略、成本价值和可达性价值，完成后才重新进入环境采集下一批数据。
\text{rollout}\longrightarrow\text{停止掩码与三类训练信号}\longrightarrow\text{shuffle/minibatch}\longrightarrow\text{多轮三网络更新}\longrightarrow\text{下一批 rollout}.

最小可行预算搜索
核心职责
第一阶段已经学习了“给定预算时，这个增广状态是否可行”。阶段二不再更新网络，而是固定双价值评估，在预算轴上寻找可行性刚好跨过零边界的位置。
当前工程实现的是归一化预算上的批量二分搜索辅助模块；它输出预算边界估计，但尚未构成包含策略确定化、价值重估和闭环执行的完整第二阶段系统。

预算搜索 
第二阶段把预算 z 当作唯一的查询变量，在同一个任务起点上反复询问模型：“给这么多预算，当前策略是否能够完成任务？”由此定位从不可行变为可行的临界预算。
例如，固定机器人当前位置 x 和安全记忆 y：
z=5\quad\Rightarrow\quad\text{不可行},
z=10\quad\Rightarrow\quad\text{可行}.
于是继续查询 z=7.5、6.25 等候选值，逐步逼近最小可行预算。
搜索过程中：
机器人不会在环境中重新执行轨迹；
网络不会继续训练；
系统只把不同候选预算与同一个 (x,y) 组成增广观测，再进行前向评价。
判断候选预算是否可行 
价值网络训练时读取的是归一化预算 \zeta\in[-1,1]。因此，搜索得到候选值后，需要先把 \zeta 写入增广观测 o(\zeta)，同时将它还原成实际预算：
b(\zeta)=s_z\zeta+m_z.
m_z 和 s_z 分别是预算归一化的中心与尺度。网络使用归一化预算 \zeta 进行预测，但判断预计成本是否超出预算时，需要使用还原后的实际预算 b(\zeta)。
对于一个候选预算，系统需要同时检查预计未来成本是否不超过预算，以及当前策略是否仍能安全到达目标。两项检查合并为
F(\zeta)=\max\!\left\{V^c\!\left(o(\zeta)\right)-b(\zeta),\;V^h\!\left(o(\zeta)\right)+\delta\right\}.
第一项看预算够不够，第二项看能否安全到达；\delta 是可达性判断中预留的裕量。例如，候选实际预算为 8，网络预测未来成本为 7，则成本检查为
7-8=-1,
表示预算够用。若可达性检查也得到负值，则 F(\zeta)\le0，当前预算可行；只要预计成本超过预算，或者可达性检查没有通过，就会有 F(\zeta)>0，表示还需要尝试更大的预算。
先检查搜索区间是否有效 
搜索从两个端点开始：
\zeta_L=-1,\qquad \zeta_U=1.
分别计算 F_L=F(\zeta_L) 和 F_U=F(\zeta_U)。这里只需要看正负号：F>0 表示预算不可行，F\le0 表示预算可行。
s=\begin{cases}-1,&F_L>0,\;F_U\le0,\\+1,&F_L\le0,\;F_U>0,\\0,&\text{其他情况}\end{cases}
s=-1 是通常的情况，表示低预算不可行、高预算可行。例如 F(-1)=2、F(1)=-0.1，说明可行边界被夹在两个端点之间，可以继续二分。s=+1 表示相反的穿越方向。若两个端点都可行、都不可行，或者没有形成清晰的异号区间，则 s=0；此时不能直接进行普通二分，需要扩大搜索范围或将当前状态标记为无法确定预算边界。
反复折半，逐步逼近预算边界 
每一轮都取当前预算区间的中点：
\zeta_M^{(k)}=\frac{\zeta_L^{(k)}+\zeta_U^{(k)}}{2},\qquad F_M^{(k)}=F\!\left(\zeta_M^{(k)}\right).
然后根据中点是否可行，丢掉不可能包含边界的一半区间。搜索方向 s 用来兼容 F 递增和递减两种情况：
\left(\zeta_L^{(k+1)},\zeta_U^{(k+1)}\right)=\begin{cases}\left(\zeta_L^{(k)},\zeta_M^{(k)}\right),&sF_M^{(k)}>0,\\\left(\zeta_M^{(k)},\zeta_U^{(k)}\right),&sF_M^{(k)}\le0.\end{cases}
在通常的递减情况下，s=-1，也就是预算越大越容易变为可行：如果 F_M>0，说明中点预算仍不可行，应提高下界；如果 F_M\le0，说明中点预算已经可行，可以把上界收紧到中点。
初始归一化区间宽度为 2。每次折半后，经过 K 轮，区间宽度为
\Delta\zeta_K=2^{1-K}.
搜索结束后，当前实现取最终区间中点作为预算估计：
\widehat\zeta^*=\frac{\zeta_L^{(K)}+\zeta_U^{(K)}}{2},\qquad \widehat b^*=s_z\widehat\zeta^*+m_z.
\widehat b^* 是双价值网络判断下的最小可行预算近似值。中点的误差更对称；如果部署时必须确保预算位于可行侧，则在递减方向且括区间有效时，返回最终可行上界，而不是直接返回中点。
网络交互与训练组织
核心职责
网络搭建完成后，系统通过并行环境交互得到一批固定长度的轨迹数据，再用这些数据构造训练目标并更新策略网络和两个价值网络。
本节把单步交互、数据记录、批量训练和实现边界串成一条完整链路。

一次单步交互 
在时刻 t，三个网络读取同一份增广观测，但承担不同任务：策略网络决定动作，两个价值网络保存当前状态的评价。
环境输出当前增广观测 o_t。
策略网络生成动作分布，采样原始动作 \widetilde u_t，并保存旧策略对数概率。
成本价值和可达性价值网络分别计算 V_{t,\mathrm{old}}^c 与 V_{t,\mathrm{old}}^h。
环境执行有界控制动作，推进物理动力学，并更新安全记忆、剩余预算和可达性残差。
系统保存这次转移，再用新观测 o_{t+1} 进入下一时刻。
o_t\xrightarrow{\pi_\theta}\widetilde u_t\xrightarrow{\text{环境变换与动力学}}o_{t+1}.
价值网络不会改变当前动作，只是在动作执行前保存对 o_t 的旧评价，供后续构造训练目标。

固定窗口采样与数据记录 
系统不会等待所有环境自然结束，而是让每个并行环境连续运行固定的 T 步。若同时运行 N 个环境，一次 rollout 就形成一个 T\times N 的时间批次。
每个时间位置保存一条与训练相关的数据：
\mathcal D_t=\left(o_t,\widetilde u_t,\log\pi_{\mathrm{old}}(\widetilde u_t\mid o_t),c_t,z_t,h_t,V_{t,\mathrm{old}}^c,V_{t,\mathrm{old}}^h,e_t\right).
其中，旧策略对数概率用于后续计算 PPO 概率比；成本、预算和旧成本价值用于构造成本目标；可达性残差和旧可达性价值用于构造可达性目标；e_t 记录环境是否结束。
保存旧结果很重要：同一批轨迹会被重复用于多个 epoch 的更新，但更新过程中网络参数已经变化，只有旧策略和旧价值仍保留，才能得到一致的比较基线。
末端 bootstrap 与训练停止点 
固定窗口的最后一步通常不是真正的任务终点。系统对末端观测再计算两个价值，用来估计窗口之外暂时看不到的未来：
V_T^c=V_{\mathrm{cost}}(o_T),\qquad V_T^h=V_{\mathrm{reach}}(o_T).
末端 bootstrap 表示“窗口之外的未来先由价值网络估计”，不表示机器人已经到达目标。

完整 rollout 收集完成后，系统在窗口内比较不同候选停止点。对从 t 出发的候选位置 k，同时检查累计成本和可达规避质量：
\widehat\Psi_{t,k}=\max\!\left\{\widehat C_{t,k}-z_t,\;\widehat H_{t,k}\right\}.
系统选择联合评价最小的位置，并把它写入训练停止掩码：
k_t^*\in\operatorname*{arg\,min}_{k\in\mathcal K_t}\widehat\Psi_{t,k}.
这个掩码决定价值目标反向传播到哪里。环境终止标记回答“episode 是否结束”，训练停止掩码回答“本次价值评价应该在哪个候选点截断”，两者不能互相替代。
一次完整训练迭代 
用 \Theta_k=(\theta_k,\phi_k^c,\phi_k^h) 表示第 k 轮开始时的策略、成本价值和可达性价值参数。一次外层迭代按以下顺序运行：
并行采样：固定 \Theta_k，让多个环境推进固定长度的 rollout。
构造训练信号：计算末端 bootstrap、候选停止掩码、两个价值目标和联合策略优势。
重复更新：将轨迹展平、打乱并切成 minibatch，在多个 epoch 上更新三个网络。
重新采样：得到 \Theta_{k+1} 后丢弃当前训练批，使用新策略生成下一批数据。
\Theta_k\xrightarrow{\text{固定策略并行采样}}\mathcal D_k\xrightarrow{\text{目标构造}}\left(d,Y^c,Y^h,A^{\mathrm{joint}}\right)\xrightarrow{\text{多轮小批量更新}}\Theta_{k+1}.
同一批旧数据可以在 PPO 裁剪约束下重复使用有限次数，但不能无限复用；当参数变化后，系统必须重新与环境交互，获得与新策略对应的数据。
训练规模与调度 
训练把环境维、时间维和更新维组织成规则张量，以便批量执行环境推进、价值递推和梯度更新。一批 rollout 和一个 minibatch 的样本数分别为：
B_{\mathrm{rollout}}=T\,N_{\mathrm{env}},\qquad B_{\mathrm{mb}}=\frac{T\,N_{\mathrm{env}}}{N_{\mathrm{mb}}}.
若总交互预算为 N_{\mathrm{total}}，外层更新次数近似为：
N_{\mathrm{update}}=\left\lfloor\frac{N_{\mathrm{total}}}{T\,N_{\mathrm{env}}}\right\rfloor.
当前默认设置为 N_{\mathrm{env}}=16、T=199、N_{\mathrm{mb}}=8 和 N_{\mathrm{total}}=2\times10^6。因此每批约有 3184 个时间位置，每个 minibatch 约有 398 个样本，整体约执行 628 次外层更新。
学习率和策略熵可以按训练进度退火；可达性 critic 的折扣从 0.999 逐步提高到 0.99999，先增强递推稳定性，再逐渐保留更长时域的到达信息。
实现能力与边界 
第一阶段训练链。 环境交互、候选停止构造和三网络更新已经连通，可以完整说明双价值如何共同形成策略训练信号。
理论收敛条件。 三个网络同步更新，未采用严格的两时间尺度更新和显式参数投影，因此不能直接继承理论部分的有条件收敛保证。
候选停止近似。 当前只在有限 rollout 内搜索候选停止点，并依赖末端 bootstrap，因此训练目标是对无限未来最优停止问题的有限样本近似。
第二阶段闭环。 工程中已经具备双价值预算二分搜索辅助能力，但策略确定化、价值重估和闭环执行尚未全部接通。搜索输出应理解为当前价值估计下的候选预算边界。
运行复现。 当前内容依据静态实现链路核对，结构、公式和数据流可以确认；性能、收敛速度和最终任务指标仍需通过完整运行验证。
实验验证与结果分析
本章通过仿真对比和真实机器人部署验证 HD-MCRA 的综合效果。
仿真实验在三类障碍场景中，将 HD-MCRA 与 RA、RC-PPO、Reward-shaped PPO 和 CPPO 进行比较，综合观察安全到达、碰撞、累计成本、预算违反率和最小间距。结果表明，HD-MCRA 的主要优势不是每项指标都绝对最优，而是在任务成功、安全、预算可行性和执行效率之间取得了更均衡的表现。
真实实验将策略部署到 Unitree Go2 四足机器人上，验证其在椅子、窄通道和移动障碍物环境中的安全导航能力，以及在不同可行路线之间对导航效率的考虑。
实验边界：这里验证的是包含冻结低层速度跟踪器、成本裕量 \alpha 和安全裕量 \delta 的扩展版 HD-MCRA。实验结果用于说明论文方法的验证效果，不等同于当前补充材料代码已经完整复现了四足机器人实验。

实验目标与统一设置
在三个难度逐渐增加的障碍场景中进行导航实验：中等障碍场景、狭窄通道场景和密集障碍场景。
所有方法使用相同的高层观测、相同的动作接口、相同的冻结低层跟踪器以及相同的训练和测试地图。

真实机器人部署与实验边界
 HD-MCRA 策略部署在 Unitree Go2 四足机器人上，场景包含椅子、窄通道和移动障碍物。
第一组场景的起点到目标距离约为 15\,\mathrm m，机器人完成了 30 次自主导航中的 26 次，成功率约为 86.7\%，并在代表性序列中保持稳定运动、避开目标区域附近的移动障碍物。

第二组场景把椅子密集布置在较宽的走廊中，使最短路线穿过比其他绕行路线更窄的通道。机器人选择了这条较短的可行路线并避免碰撞，说明策略确实会在局部障碍约束下考虑导航效率，而不是固定选择更宽但更长的路线。
