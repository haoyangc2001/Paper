# CCDC 2027 投稿要求与篇幅规划

核实日期：2026-10-20。适用对象：将当前 HD-MCRA 四足机器人论文改投 CCDC 2027。本文区分会议官方规定、官方模板说明与针对本稿的写作建议；后续变化以会议官网和投稿系统为准。

## 1. 正文应准备多少页

**建议按英文 IEEE 双栏全文 6 页准备。初稿最多 8 页，终稿最多 8 页；终稿第 7、8 页各加收 200 元。会议没有单独规定“正文必须几页”。**

中文官方投稿页原文 [S1]：

> 初稿每篇文章不多于8页（包括图）。
>
> 终稿超过6页的部分需交纳超版费200元/页，终稿最长不能超过8页（包括图）。

| 项目 | 核实结果 | 对我们的含义 |
| --- | --- | --- |
| 初投上限 | 每篇最多 8 页，包括图 | 8 页是初投上限，不是要求必须写满 |
| 终稿常规篇幅 | 6 页以内不产生上述超版费 | 建议优先以全文 6 页为目标 |
| 终稿最大篇幅 | 最多 8 页，包括图 | 关键验证确实放不下时，可考虑全文 7–8 页 |
| 终稿超版费 | 超过 6 页的部分，200 元/页 | 7 页加 200 元，8 页加 400 元；这是超版费，不是全部注册费 |
| 正文单独页数 | 未查到独立要求 | 先预算全文页数，再分配正文与参考文献 |
| 参考文献是否免计页数 | 已核实页面没有明确豁免 | 按参考文献计入全文总页数来写，不能理解为“6 页正文另加参考文献” |
| 最低页数、全文词数 | 已核实资料没有给出 | 不把其他 IEEE 会议的最低页数或字数套过来 |

英文投稿页 [S2] 将终稿 6 页和超过 6 页收费写在同一段，措辞不够清楚；中文页明确补充了“终稿最长不能超过 8 页”。综合两页，应理解为 **6 页常规篇幅、8 页硬上限**。

**关于计页口径的写作安排：**在未获得豁免说明前，标题、作者、摘要、关键词、正文、图表、致谢、参考文献，以及放进提交 PDF 的附录都按整份 PDF 的页数预算。这是稳妥安排；官网原文只明确写了“包括图”，没有逐项列出上述内容。

按 6 页全文预留约 0.8–1 页参考文献，其余内容约 5–5.2 页；再扣除标题、作者、摘要和关键词，Introduction 到 Conclusion 的正文及图表约 **4.6–4.9 页**。这是本稿的写作预算，不是会议硬性要求。

## 3. 投稿类型、语言和检索

来源：中文投稿页 [S1]、英文投稿页 [S2]。

| 类型 | 官方说明 | 本稿建议 |
| --- | --- | --- |
| Regular Paper | 普通全文论文；特别专题论文同样选择此类型，并在研究领域选择对应专题 | **优先选英文 Regular Paper** |
| Invited Session Paper | 邀请组论文，需要填写正确的 Session code | 只有实际加入邀请组时才使用 |
| Invited Session Proposal | 邀请组组织申请；需先向秘书处提交约 1000 字申请并获批准 | 不是我们的普通全文投稿入口 |
| Position Paper | 长摘要；英文页说明约 800–1000 词；收进论文集但不送 IEEE Xplore/EI | 不适合当前希望正式全文发表和检索的目标 |

中文官网明确说明：**中文论文只出版，无法被 IEEE/EI 收录**。我们的目标应是英文全文。

符合 IEEE Xplore 范围和质量要求的录用英文论文将被提交 IEEE Xplore。官网已在 2026-10-14 公告 CCDC 2026 符合要求的英文论文已被 EI 检索；这是上一届实际记录，不能写成本届已检索。录用、正式出版、IEEE Xplore 上线和 EI 收录是不同阶段。[S1、S3]

征稿 PDF 还提到优秀论文可被推荐扩展后投稿 Journal of Control and Decision；这是另行评审的期刊机会，不是会议录用即获期刊发表。[S4、S5]

## 4. 模板和排版

### 4.1 使用已经下载的 CCDC 官方英文模板

来源：会议官方投稿页的下载链接及原始 `.tex` 文件 [S2、S6]。

| 项目 | 模板说明或已验证状态 |
| --- | --- |
| 文档类 | `\documentclass[conference]{IEEEtran}` |
| 版式 | IEEE 会议双栏 |
| 字号与纸型 | 当前官方示例编译为 10 pt、US Letter（8.5 × 11 英寸）；这是下载模板的默认配置，不是另行检索到的会议纸型条文 |
| 页边距、栏宽、行距、字体 | 模板要求保持已有设置，不自行压缩以塞内容 |
| 摘要与关键词 | 使用 `abstract` 和 `IEEEkeywords` 环境 |
| 引文 | 数字方括号引用；不沿用 CoRL 的作者—年份样式 |
| 图表 | 图题在图下、表题在表上；大图表可跨栏；图表应在正文先引用 |
| 标题和摘要 | 模板提示不使用数学公式、脚注和特殊符号；本稿摘要可用文字描述两类裕度，将 α、δ 放到正文定义 |
| 缩略词 | 正文首次出现时定义；摘要中定义过也应在正文首次出现时说明 |
| 模板教学文字 | 正式投稿时删除示例说明、占位作者、示例文献和模板末尾红字 |

### 4.2 不要混用 CCC 模板

CCDC 使用 `cms.amss.ac.cn` 投稿，但该系统公共 Resources 页面 [S8] 标的是 **Chinese Control Conference（CCC）**，提供 `cccconf.cls`。CCC 与 CCDC 是两个会议。

因此应使用 **CCDC 官网直接提供的 `IEEEtran` 模板**，不能因为投稿系统相同，就切换为公共资源页里的 CCC 模板。

## 5. 提交材料与流程

来源：官方投稿说明 [S1、S2]。

1. 按 CCDC 模板准备完整英文论文 PDF。
2. 在 [会议论文管理系统](http://cms.amss.ac.cn/) 注册或登录，获得并使用个人 PIN。
3. 在 CCDC 2027 的“作者工作区 / Author Center”中操作，避免误入 CCC 等其他会议。
4. 按真实作者顺序填入信息；英文官网要求填写所有作者的 PIN，需提前准备。
5. 普通全文选 Regular Paper；若投特别专题，在研究领域中选择相应专题；邀请组论文另需 Session code。
6. 上传 PDF，并在系统确认稿件状态和最终版本。

已核实的初投要求明确是 PDF 全文；**没有从当前资料中确认初投必须上传 LaTeX 源码**。本地仍应保留完整 `.tex`、`.bib` 和图片，便于后续改稿及按终稿通知交付。

## 6. 我们论文的篇幅与内容分配建议

本节是根据当前 CORL 0914 稿和已确定的工程论文定位提出的建议，不是 CCDC 指定章节。

**主线：将 RC-PPO/MCRA 工程化部署到真实四足机器人，建立固定闭环接口，并用执行数据修正成本超支与轨迹偏差。**

### 6.1 优先按 6 页全文组织

以下表格合计 6 页，指排版后的近似空间。图表计入对应章节，最终根据作者信息、公式、图表和文献数量调整。

| 内容 | 预算页数 | 必须交代的内容 |
| --- | ---: | --- |
| 标题、作者、摘要、关键词 | 0.40 | 实际部署问题、固定接口、两类执行误差校准、真实验证结论 |
| Introduction 与精简 Related Work | 0.90 | 理论模型接到四足执行器后出现什么失配；贡献边界；与 RC-PPO 和安全导航工作的关系 |
| Problem Setup | 0.45 | 状态、速度指令、成本和预算、危险集合、名义/执行转移；必要的 RC-PPO 来源说明 |
| Execution-Calibrated Deployment | 1.45 | 冻结速度接口；配对执行误差测量；成本 α 与轨迹 δ；训练和部署如何使用修正 |
| Experiments 与 Failure Analysis | 1.80 | 校准与测试分离；公平基线；α/δ 消融；真机定量；不确定性及失败案例 |
| Conclusion 与简要 Limitations | 0.15 | 工程工作实际解决了什么、适用范围是什么 |
| References | 0.85 | 支撑理论来源、相关工作与基线的必要文献 |
| **合计** | **6.00** | 正文与图表约 4.75 页，另有首页信息和参考文献 |

压缩顺序：先合并重复动机与相关工作，再精简 RC-PPO 原理复述和低层 PPO 通用介绍，最后压缩非必要的超参数叙述。**成本定义、校准数据来源、α/δ 计算、基线差异和关键实验不能因省页而缺失。**

低层强化学习不是本稿核心创新。正文保留冻结跟踪器的职责、输入输出、频率与跟踪误差等必要接口信息，不展开通用 PPO 教程。RC-PPO 的增广状态与求解原则简述并引用，篇幅重点留给执行校准及其证据。

### 6.2 什么时候使用 7–8 页

若按正常版式重排后，6 页无法完整呈现校准机制、消融和真机量化结果，优先考虑 **7 页全文**；有必要时使用 8 页。它们均在官方终稿上限内，对应增加 200 或 400 元超版费。

不需要为减少少量超版费而删掉回应 CoRL 评审的关键证据，也不应为了写满 8 页继续扩展底层 RL 或继承理论的介绍。正式页数应在迁移到 IEEE 双栏后决定，不能把 CoRL 单栏页数直接折算。

当前 0914 稿的附录较多。不能假定 CCDC 允许“正文 8 页另加不限页附录”或独立补充材料；当前资料未明确这类安排。关键定义与复现信息应进入限页内，非关键长推导可精简并指向原文。

### 6.3 与征稿方向的匹配

官方征稿范围包含“机器人与无人系统的智能感知、协同决策与安全”和“智能决策系统与应用”。本稿可围绕机器人安全导航与控制应用选择研究领域。[S4、S5]

官方特别专题中，“未来机器人技术及应用”（FRTA）直接面向机器人技术和实际应用，可作为候选；“数据驱动自适应与学习系统及应用”（DALSA）也与执行数据校准相关，但具体选择应对照系统选项及专题征稿内容。它们是候选方向，不代表已加入专题或获得邀请。[S7]

当前方法的验证范围应写为校准条件下的经验鲁棒性，不将经验 α/δ 夸大为新的严格随机安全保证。
