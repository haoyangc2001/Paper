## 修正一：消融表的两个重复基准

下表顺序为 SR (%) / CR (%) / Cost / BVR (%) / MC (m)。

| 消融行 | 修正前 | 统一后 | 原因 |
| --- | --- | --- | --- |
| 完整HD-MCRA | 70.8 / 18.6 / 71.3 / 11.2 / 0.32 | **73.3 / 15.0 / 88.3 / 9.0 / 0.31** | 与主表完整方法是同一配置，采用相同参考预算 |
| w/o both | 62.9 / 29.4 / 87.6 / 25.8 / 0.16 | **70.7 / 15.7 / 91.7 / 14.0 / 0.30** | 正文已定义RC-PPO为相同冻结底层、α=δ=0；行名补为 `w/o both (RC-PPO)` |

其余三个消融行保留原假设值，没有为了营造单调提升而重造数据。与完整方法相比，去掉α的BVR为22.4%而非9.0%；去掉δ的CR为26.3%而非15.0%，MC为0.19而非0.31m。

但单裕度行的某些指标比“两个裕度都去掉”更差，说明这组假设不能支撑“每个模块单独加入都改善所有指标”。正文已明确效果可能相互影响；单裕度行成本更低也不能单独解释为效率更高，因为其失败率更高、终止时间可能更早。要验证模块作用，仍须做控制变量、相同场景和预算的真实消融。

## 修正二：预算扫描与主表对齐

当前草稿采用一个明确的比较约定：同一场景的各方法共用参考预算，主表与消融表对应 `z0/z_ref=1.00`。这是本轮为假设数据采用的约定，绝对参考预算尚待确定，不是恢复出的实验配置。

以下显示到主表精度；源码和工作簿保留未四舍五入的均值。

| 方法 | 1.00处原 SR / CR / BVR / Cost | 对齐后 |
| --- | --- | --- |
| HD-MCRA | 71.3 / 15.8 / 9.5 / 87.8 | **73.3 / 15.0 / 9.0 / 88.3** |
| RC-PPO | 65.5 / 18.0 / 12.8 / 90.3 | **70.7 / 15.7 / 14.0 / 91.7** |
| RA | 60.4 / 13.7 / 20.0 / 104.0 | **60.0 / 13.0 / 20.0 / 104.0** |

为延续原扫描设定的平缓改善示意，单独调整了RC-PPO的四个相邻假设值：

| 预算比 | 指标 | 原值 | 新假设值 | 逐点处理原因 |
| --- | --- | ---: | ---: | --- |
| 1.05 | SR (%) | 68.5 | 71.6 | 参考点已为70.7%，留出小幅改善，并保持低于同处HD-MCRA的73.6% |
| 1.12 | SR (%) | 71.0 | 72.5 | 位于1.05的71.6%与1.20的73.5%之间，避免局部回落 |
| 1.05 | CR (%) | 16.8 | 15.2 | 参考点为15.7%，保持小幅下降，并略高于同处HD-MCRA的14.9% |
| 1.12 | CR (%) | 15.4 | 14.8 | 连接1.05的15.2%与1.20的14.2%，保持原扫描的改善方向 |

上述四点是人工修订的示意假设，不是从理论唯一推出的数，也不是要求真实预算响应必须单调。其余非参考点的RC-PPO、HD-MCRA数据保留。

RA不接收预算条件。草稿统一为对同一组RA轨迹重新施加不同预算阈值：SR固定60.0%，CR固定13.0%，Cost固定104.0；只有BVR改变。评估时预算超限不提前终止，才能保持这些轨迹不变。

验收条件为 SR≥60%、CR≤20%、BVR≤15%，从数组计算得到：

| 方法 | 最小通过的测试预算比 | SR (%) | CR (%) | BVR (%) | Cost |
| --- | ---: | ---: | ---: | ---: | ---: |
| HD-MCRA | 0.90 | 66.8 | 17.6 | 14.7 | 84.7 |
| RC-PPO | 0.96 | 62.9 | 18.8 | 14.9 | 89.2 |
| RA | 1.12 | 60.0 | 13.0 | 14.4 | 104.0 |

RA旧的60.5%/13.7%已同步修正。三个预算比未变。它们只是候选网格的可行阈值；选定策略之后仍须用独立数据做最终评估，不能称为连续最优成本。

## 修正三：指标与论述口径

| 项目 | 统一后的定义/处理 |
| --- | --- |
| SR与CR | SR是到达目标且无物理碰撞；CR按统一物理碰撞标准统计，不按各方法δ膨胀后的规划区域统计。场景中心值均满足SR+CR≤100%。 |
| BVR | 实际执行成本超过初始预算的比例，可与成功或碰撞事件重叠，不能把SR、CR、BVR相加当成互斥类别。 |
| Cost | 草稿采用全部试验从起点计到目标、物理碰撞或超时的平均执行成本；不是只统计成功试验。函数、单位、权重仍待核实。 |
| MC | 各试验最小物理机器人轮廓间隙的均值，同样采用全部试验；不能混成膨胀规划区域的间隙。 |
| 主表汇总 | 三场景等权。样本量不等时，不自动等于把所有试验合并后的比例。 |
| 新图横线 | 人工逐点指定的假设范围，绝非SD、SE或95%CI；不平均区间端点构造总体区间，也不由区间重叠推断显著性。 |
| 动作模型 | 原“差速模型”改为“平面机体速度模型”，与已有非零侧向速度指令 `vx, vy, ωz` 一致。具体仿真配置仍待核实。 |
| 终止与学习 | 评估中预算超限不结束轨迹；训练的终止边界和bootstrap规则单列为待实现核实，不能混用。 |
| 裕度扫描 | 未找到α/δ扫描逐设置结果，原“观察到下降趋势”的表述改为计划验证的假设；保留拟用参数集合。 |
| 试验数 | 3个训练seed、300次评估明确为计划规模；不拿它们反推假设均值的整数成功数或置信区间。 |

RA主表BVR在本轮之前已由22.0%纠正为20.0%，本轮复核仍与12%、20%、28%的场景值一致。
