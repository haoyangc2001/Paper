分析日期：2026-10-20。对象：`CCDC/latex/1020/main.tex`、当前三张图，以及 CoRL 原评审意见。参考原文和图页见 [绘图参考阅读集](../references/figure_review_20261020/README.md)。

## 1. 核心判断

现在最需要加强的是一条可检查的工程证据链：固定执行接口，测出名义与执行失配，从数据得到 alpha、delta，在独立测试中验证两种修正，最后在真机上看到相应改善。

当前架构图包含这些名词，但核心校准流程不突出；结果图以平均柱状图和预算扫描为主，没有把上述链条画出来。单纯改颜色和提高分辨率，无法补上这个问题。

本稿数值仍是作者要求保留的假设数据，真机成本、预算违规等仍为 TBD。因此，下文判断的是“当前稿面缺少哪些可审查证据”，不据此断言实验没有做过，也不将占位值作为真实结果评价优劣。新图也应保持示意和测量结果的区分，不能从已有均值反推置信区间或伪造逐试验散点。

本轮已阅读六篇完整本地原文的相关图页与实验段落。联网检索及重新下载因自动审批服务 503 未执行；阅读集已经归档本地原始 PDF、来源哈希和原图截取。没有核实这些预印本是否为网上最新版本，也不宣称覆盖全部相关研究。

## 3. 当前三张图的具体问题

### 3.1 架构图：重点与空间分配不匹配

当前 `framework_overview_final.png` 的大部分空间在解释高层、低层、观测和神经网络。真正要贡献的配对失配测量及 alpha/delta 校准挤在右侧窄栏。多个边框、渐变、图标、公式和图例竞争注意力，缩到 IEEE 单栏后难读。

校准数据应清楚显示“相同初态/地图/命令 → 名义 rollout 与执行 rollout → 配对误差”。目前的执行集合图片不能替代这层关系。成本修正箭头应准确指向 running cost / budget update，安全修正应指向 unsafe set；不要让读者以为 alpha 直接改写速度命令。

建议改为上下两条简洁流程：上方是离线校准和学习，下方是在线闭环。RC-PPO 与冻结跟踪器用浅灰，本文配对数据、alpha、delta 用两种强调色。低层内部 PPO 训练保留一句说明，不展开网络装饰。

### 3.2 场景柱状图：数据很多，原因很少

当前图在三个场景、多个方法和四个指标之间反复切换，图例和标签很小，且与主表重复。没有误差条或试验分布，读者无法判断差距是否稳定。平均成本与成功率的关系也没有展示。

建议完整方法比较放主表；图中只留下回答特定问题所需的少量方法。优先腾出空间画校准分布、同场景轨迹和真机结果。若保留汇总图，使用水平点图与区间，方法名称直接排在纵轴，避免每个面板重复七项图例。

### 3.3 预算扫描图：轴标签和正文网格不一致

当前 `figure_budget_sweep_v3.pdf` 的横轴是 0.8–1.2 一类归一化预算，但轴下写成了 Success Rate、Collision Rate、Budget Violation Rate、Average Cost。这些应是纵轴指标或面板标题，横轴应写清 `Initial budget / reference budget` 及 reference budget 的定义。

图中可见预算标签包含 0.95、1.10，正文候选网格是 0.96、1.12。这可能是旧图或不同采样设计，需从源数据核实，不能直接假设图文使用了同一网格。RA 是否接受预算输入、如何获得其跨预算曲线，也应说明。

预算图应标出预先定义的可接受范围和选中候选值，读者才看得出“为什么选这个预算”。验收阈值、预算选择数据与最终评价集应分开，避免用测试集调优后再报告测试成绩。

## 5. 建议正式稿保留的五组图

### 图 1：部署问题与校准闭环总览

**要回答：我们的工程工作到底是什么？**

左侧用一个小地图示意名义路径与实际偏移，旁边画名义/执行累计成本差异；右侧用上下两行展示离线校准与在线闭环。配对数据生成 alpha、delta，再作用到 RC-PPO 的成本和危险集合。明确冻结跟踪器贯穿数据采集、高层学习与部署。

这是一张方法示意图，可以先做，不依赖真实统计数据。示意轨迹应标为 schematic，不能看起来像测得的真机结果。推荐矢量绘制并跨双栏，不修改论文模板边距。

### 图 2：失配分布及独立校准检验

**要回答：两个边界凭什么取这个值？**

建议双面板 ECDF：左为相对成本超支，右为单条 rollout 的最大路径偏差。分别画校准集与独立测试集的阶梯曲线、所选分位点及 alpha/delta 阈值线，图注给配对 rollout 数量、来源与单位。需要时增加一个很小的平面轨迹示意解释偏差定义。

ECDF 比单独直方图更直接地显示“多少试验落在阈值内”，也不依赖随意选择的直方图箱宽。横轴单位不同应分面，不能放一个混合坐标。

统计单位是 rollout，不能把同一轨迹的数千帧当作数千次独立试验。校准集上恰好达到所选分位数接近定义本身，重点应看独立集覆盖。成本和路径分别采用 90% 分位数不意味着联合成功率为 90%，更不能写成全局安全保证。

需要：paired rollout ID、划分标记、环境条件、名义/实际累计成本、时间对齐的平面位置。CI 和分位数估计不确定性从原始记录计算。

### 图 3：模块作用与扰动下的代价

**要回答：alpha 和 delta 是否各司其职，代价是什么？**

主面板用四组一致设置：无修正、仅 alpha、仅 delta、两者都有。画 SR、CR、BVR 及实际成本的点和区间，而不只截取有利的两个指标。可以把完整汇总数保留在表里，图突出相对未校准 RC-PPO 的变化。

旁边用两三个小面板画延迟或其他一个有物理意义的扰动参数与 CR/BVR/SR 的关系，标出校准区间。空间不足时先保留独立消融，扰动扫描移至附加材料或正文简表；不要把未验证的补充材料豁免当成 CCDC 既定规则。

如果增加 alpha/delta 二维热图，需要实际测过每个网格点，并注明每组是否重新训练。不能用四个角点插值得到一张看似完整的实验热图。

需要：相同地图与起终点的逐试验结果、训练 seed、配置 ID、成本和预算口径。相同评价场景可用配对差异提高解释性；跨 seed 的不确定性应保留层级，不能只把所有回合混在一起。

### 图 4：代表轨迹与同一回合的三条时间曲线

**要回答：具体怎样避免一次碰撞或预算违规？**

左边是一张有米制比例尺、起点、终点及机器人轮廓的俯视地图；分清障碍、机器人足迹膨胀和额外 delta。对照未校准与校准系统，分别用虚线/实线表示名义和实际路线。曲线多时拆成两个相同视角面板，保持坐标范围一致。

右边共享时间轴：第一条是实际间隙，第二条是实际累计成本与初始预算，第三条是指令与实际速度或跟踪误差。标注转弯、打滑、近障、预算耗尽等实际发生的 A–D 时刻。定性案例与汇总统计配合，说明选例规则。

当前 alpha/delta 是预先标定的固定量，不要画成在线自适应变化。内部修正预算、名义成本及实际执行成本也要分别命名，不能混成一条看起来守住预算的曲线。

这是最值得优先制作的结果图。它直接连接失配、修正和结果，比另一张七方法柱状图更能支撑工程贡献。

### 图 5：真机部署及失败边界

**要回答：真实机器人是否重复实现了同样的改善，在哪些地方仍失败？**

上排放真实场景全景或俯视图，标注测得的尺度和路线。下排放有时间戳的 3–4 帧关键动作，和实际记录的轨迹或预算/间隙曲线对应。配套独立真机表，按场景报告方法、试验数、成功/碰撞/预算违规、执行成本、最小间隙和超时。

优先选与动机直接相关的条件：窄通道转向、不同摩擦表面、可控延迟等。选择实际可稳定开展的少量场景即可，不必复制别人雪地、楼梯、跳跃等与本工作无关的展示。动态障碍只有在感知与任务定义确实支持时才作为主要证据。

保留典型失败：薄障碍漏检、定位偏移、过度保守而超时等；分类由真实日志和视频确认。不能使用合成图片充当实验现场，也不能把占位失败比例画成正式统计图。

## 6. 另外两种有用但不必全放的图

**成本—可靠性权衡图。** 参考 ABS 的二维散点，以执行成本为横轴，以 CR 或 BVR 为纵轴；每个点是实际测试的余量/预算/权重设置。只有满足预先规定 SR 的设置才讨论效率，其他点显式标记不可行。若只画有限设置，称“已测试设置的权衡”，不要宣称理论 Pareto 最优。成本是成功条件均值还是全回合成本应说明，早失败不能获得效率优势。

**接口验证小图。** 三行分别展示 vx、vy、yaw rate 的指令与实测，或分开报告线速度/角速度 RMSE。共享时间轴，明确定义相同初始化下的重复执行离散度。不要把 m/s 与 rad/s 未归一化相加成一个“速度 RMSE”。由于低层是系统依赖，控制在一个小面板或实现表内。

## 7. 绘图前先修正的逻辑风险

1. **主表与消融表口径。** 完整方法在两表的假设 SR 为 73.3% 和 70.8%，未校准 RC-PPO 与 w/o both 也不同。可以来自不同测试批次，但不能未经说明当作同一批直接比较。定稿时按配置、地图、seed 和 rollout ID 核查对应关系。
2. **成本/预算定义。** 明确 c 的单位、时间步与失败计费，实际 J_exec 与内部修正预算分别记录。若方法各自选择更大初始预算，BVR 的横向降低不能独立说明校准更好；给共同预算曲线或完整权衡。
3. **固定序列校准到闭环部署的差距。** 回放相同命令能隔离执行失配，但线上会因观测变化而重新决策。应在独立闭环导航任务中再次检验，不能仅用开环回放覆盖率证明最终导航鲁棒。
4. **名义模型。** 方法允许横向速度，实验却称 differential-drive abstraction。需核实这是实际模型限制还是术语误用，保持控制变量、轨迹生成和误差归因一致。
5. **几何约定。** 区分机器人中心线距离、机身外缘间隙、足迹膨胀和额外 delta。通道名义可行但膨胀后封闭，应如实报告为保守性边界。
6. **扰动来源。** 摩擦和延迟改变执行，LiDAR 扰动改变观测与策略决策；两者可以分别测，避免全放入一个“执行误差”分布。
7. **统计口径。** 每图注明 n、seed 数、误差条是 SD/SE/CI，成功与碰撞是否互斥，终止/超时/预算违规如何计数。真机小样本给区间，不把一个成功比例直接视为稳定能力。
8. **量化与照片匹配。** 代表轨迹、视频截图与时间曲线要能回溯到同一个 trial ID；展示不同回合时清楚分面，不拼接成一次完整成功。

## 8. 统一视觉规范

- 先按最终印刷尺寸设计。单栏约 88.9 mm，跨栏约 184.2 mm，使用当前 IEEEtran 默认栏宽；这是匹配模板的出图尺寸，不是修改模板布局。
- 坐标和图例在最终尺寸下以约 8–9 pt 为目标；跨栏图缩小后检查。图内小段落改到图注，关键线条约 1–1.3 pt，避免装饰性阴影、渐变和过多边框。
- 同一方法全篇同色。建议本文完整系统用蓝 `#0072B2`，未校准 RC-PPO 用橙 `#D55E00`，其他基线灰色或低饱和度。模块图可让 alpha 用橙、delta 用蓝，并在图例中明确它们表示模块，避免与方法编码混淆。
- 颜色与线型/点形一起编码：名义虚线、实际实线；障碍灰、足迹层浅灰、额外安全余量低透明蓝。保证灰度打印可分辨。
- 2D 轨迹等比例坐标并标米制单位；折线图保留真实离散采样点，不强行平滑；ECDF 用阶梯线；不同实验条件的小面板尽量共享范围。
- 柱状图从零开始；需要放大差异时改为点图并明确范围，避免截断柱体误导。误差带不是装饰，必须来自对应原始样本。
- 曲线旁可直接标方法；多子图共享一个图例。标出 (a)–(d)，图注说明各面板和统计口径。
- 统计图和结构图优先导出矢量 PDF，并保留可编辑源文件；照片保持真实原图，按最终尺寸输出足够分辨率。不要把截图再放大充当矢量图。
- 正式稿中无需把每个数值拆成两行；但只要仍是假设值，就要保留显著的假设标记。改用真实数据后再同步更新所有表、图与文字，不能先隐去标记。
