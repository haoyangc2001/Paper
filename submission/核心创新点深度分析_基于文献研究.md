## 一、文献调研关键发现

### 1.1 保守裕度的新颖性分析

#### **α（成本裕度）：真正新颖 ✅**

**文献中的现有做法**：
- **CPO (2017)**：加法式成本塑形 `C+ = C + Δ`，其中 Δ 是概率前瞻缓冲
- **RCPO (2019)**：成本阈值 `J_C ≤ δ`，手动调参
- **RC-PPO (2024)**：上界优化 `min z_0 s.t. Ṽ ≤ 0`，外生图形式

**你们的方法**：
```python
α = Q_{p_c}(ε_c)  # 成本超支的经验分位数
c̃ = (1 + α) · c   # 乘法膨胀
```

**为什么新颖**：
- ✅ 没有论文使用**乘法式**成本裕度作为设计参数
- ✅ 系统化的经验分位数方法
- CPO 的 Δ 是概率加法，不是裕度因子

#### **δ（安全裕度）：部分新颖 ⚠️**

**文献中的现有做法**：
- **CMDP 论文**：δ 作为约束阈值（`J_C ≤ δ`），不是裕度乘子
- **RESPO/ABS**：固定切换阈值 `V_threshold = -0.05`，补偿学习误差
- **可达性论文**：几何距离函数，不是保守缓冲

**你们的方法**：
```python
δ = Q_{p_d}(ε_d)  # 轨迹偏差的经验分位数
F_δ = {x | d(x,F) ≤ δ}  # 扩大不安全集
```

**为什么部分新颖**：
- ✅ 乘法式/膨胀式安全裕度（不是阈值）
- ⚠️ 但固定安全间隙在轨迹规划中有先例
- ✅ **系统化的分位数框架**是新的

#### **关键区别**

| 现有方法 | 你们的方法 |
|---------|-----------|
| 阈值用于约束满足 | 裕度缩放成本/约束函数本身 |
| 固定切换阈值 | 数据驱动的分位数裕度 |
| 手动调参 | 系统化的经验估计框架 |

**结论**：**α 是真正新颖的，δ 的系统化框架也是新颖的**

### 1.2 分层架构的新颖性分析

#### **冻结低层 + 学习高层：标准做法 ❌**

**文献证据（10+ 篇论文都用这个架构）**：

1. **RMA (Kumar et al., 2021)**
   - 两阶段训练：基础策略冻结 → 适应模块学习
   - 最接近的先例

2. **ANYmal Parkour (Hoeller et al., 2024)**
   - 冻结技能库（walk/jump/climb/crouch）
   - 高层技能选择和排序

3. **PRELUDE (2022)**
   - 冻结低层步态生成 + 学习高层导航

4. **Hierarchical RL for Quadruped (Jain et al., 2019)**
   - 高层潜在命令 + 低层执行器

5. **Learning multiple gaits (2021-2023)**
   - 冻结步态库 + 高层步态选择器

**文献结论**：
> "冻结低层 + 学习高层是现代四足导航的**标准架构**，几乎出现在所有主要近期工作中。"

#### **闭环抽象的新颖性：形式化是新的 ⚠️**

**你们的贡献**：
- 明确形式化为"集中的闭环抽象" $\bar{f}_{cl}$
- **假设 1**：量化偏差界限用于可达-避障规划
- 这个**形式化**是相对新颖的

**但是**：
- 使用低层控制器作为接口是常见的
- "黑盒控制器"模型、"名义动力学"概念都有先例

**结论**：分层结构本身不新，但**为随机 MCRA 形式化闭环抽象**有一定新颖性

### 1.3 MCRA 理论的贡献分析

#### **RC-PPO 的理论来源**

增广状态公式 $(x, y, z)$ **完全来自** RC-PPO (So et al. 2024)：
- 安全指示器 $y$
- 预算变量 $z$
- 增广目标 $\hat{g}(x,y,z) = \max\{g(x), Cy, -z\}$

**你们的论文明确承认**（第 77-78 行）：
> "RC-PPO 将 MCRA 问题重新表述为增广状态空间上的可达性问题。这个构造是为确定性离散时间动力学开发的。"

#### **HD-MCRA 的理论贡献：几乎没有 ❌**

**论文自己承认**（Section 5）：
> "我们的方法基于**名义闭环抽象和经验分位数修正**，而不是严格的随机 MCRA 保证。"

**事实**：
- 随机 MCRA 公式（方程 2-5）**立即回退**到 RC-PPO 的确定性增广状态公式
- 没有随机可达性的理论扩展
- 通过工程近似（集中闭环抽象、经验裕度）处理随机动力学

**结论**：**这主要是工程工作，不是理论创新**

## 二、重新定位：你们到底做了什么？

### 2.1 真实的创新分类

#### **真正新颖（3项）**

1. **数据驱动的分位数保守裕度（α, δ）**

   - 补偿闭环跟踪误差
   - 用于可达-避障规划

2. **两阶段求解器**
   - 第一阶段：随机策略训练（可达性 critic）
   - 第二阶段：转确定性 + 最小预算搜索
   - 为 MCRA 提供实用的训练流程

3. **集中闭环抽象的形式化**
   - 假设 1：量化偏差界限
   - 专门为随机 MCRA 与冻结控制器设计

#### **新颖组合（3项）**

1. **MCRA 应用于四足导航**
   - 首次将最小代价可达-避障用于这个领域

2. **分层 MCRA 框架**
   - 冻结低层 + 高层可达-避障规划器 + 预算条件化

3. **领域随机化 + 裕度估计的集成**
   - 创建集中闭环核 + 数据驱动裕度

1. 分层架构（冻结低层 + 学习高层）
2. 领域随机化
3. 速度指令作为接口

1. 通过名义闭环抽象将 RC-PPO 确定性理论应用于随机四足
2. 将随机 MCRA 转换为确定性增广状态公式

## 三、重写策略

### 3.1 摘要重构

#### **当前版本的问题**
- 过度声称"制定"（MCRA 已存在）
- 低估工程贡献（数据驱动裕度、两阶段求解器）

#### **建议版本**

```markdown
Quadruped navigation in cluttered environments requires safe goal-reaching 
with minimum cost, but applying minimum-cost reach-avoid (MCRA) planning to 
stochastic legged robots is challenging. We introduce HD-MCRA, a hierarchical 
framework that makes MCRA practical for quadrupeds by bridging deterministic 
planning theory with stochastic locomotion execution. 

Our approach combines:
(1) a frozen domain-randomized low-level controller that concentrates 
closed-loop behavior, 
(2) data-driven conservative margins (α, δ) derived from empirical trajectory 
distributions to compensate for tracking errors, and 
(3) a two-phase solver that trains stochastic policies then converts them 
for minimum-budget search. 

Real-world experiments on a Unitree Go2 robot demonstrate 87% success rate 
(26/30 trials) in cluttered environments with 0.3m-wide passages and moving 
obstacles, reducing the minimum feasible budget by 10% compared to RC-PPO 
while maintaining safety. Ablation studies confirm that both the hierarchical 
decomposition and conservative margins are essential: removing either causes 
>20% performance degradation.
```

**关键变化**：
- "makes MCRA practical" 而非 "formulate MCRA"
- 突出三个工程创新
- 定量真机结果
- 消融验证

```markdown
fundamental to real-world deployment in inspection, search-and-rescue, and

theoretical solution, recasting MCRA as reachability on an augmented state

However, RC-PPO assumes deterministic discrete-time dynamics and has only 
been validated on low-dimensional systems (2-6 action dimensions) in 
simulation. Real quadruped deployment faces three critical challenges:
```

**段落 2：RC-PPO 的具体局限（用表格）**

| Challenge | RC-PPO Assumption | Quadruped Reality | Gap |
|-----------|-------------------|-------------------|-----|
| Dynamics | Deterministic x_{t+1}=f(x_t,u_t) | Stochastic execution: contact, actuator delays, noise | Budget overruns, safety violations |
| Action Space | 2-6 dimensions (Pendulum, PointGoal) | 12-D joint torques | Intractable learning |
| Validation | Simulation only | Physical hardware required | Sim-to-real gap |

```markdown
These gaps prevent direct application of RC-PPO to quadruped navigation. 
While the augmented-state formulation is theoretically sound, making it work

```

**段落 3：我们的解决方案（一对一映射）**
```markdown
We present HD-MCRA, a system that makes MCRA practical for quadruped robots 
by addressing each challenge:

**Challenge 1: High-dimensional stochastic dynamics**
→ Hierarchical decomposition: A frozen low-level velocity tracker (trained 
with PPO and domain randomization) induces a concentrated closed-loop 
abstraction, reducing the high-level action space from 12-D joint commands 
to 3-D velocity commands while stabilizing the dynamics.

**Challenge 2: Budget overruns from execution uncertainty**
→ Cost margin α: Derived from empirical cost-overrun quantiles, inflates 
running cost as c̃ = (1+α)·c to reserve budget headroom. If α=0.15, the 
policy plans as if each action costs 15% more, ensuring actual costs stay 
within budget.

**Challenge 3: Trajectory deviations threatening safety**
→ Safety margin δ: Derived from trajectory-deviation quantiles, enlarges 
the unsafe set by δ to maintain clearance. If δ=0.2m, the policy avoids 
obstacles by an extra 0.2m, absorbing path deviations from terrain 
uncertainty.

Additionally, we introduce a two-phase solver: Phase I trains a stochastic 
policy with a reachability critic; Phase II converts to deterministic form 
and searches for the minimum feasible budget. This bridges stochastic 
training with deterministic deployment.
```

**段落 4：贡献和结果**
```markdown
Our main contributions are:
1. Data-driven quantile-based conservative margins (α, δ) derived from 
   empirical trajectory distributions to compensate for closed-loop tracking 
   errors in MCRA planning
2. A two-phase solver that bridges stochastic policy training with 
   deterministic minimum-budget search
3. Formalization of concentrated closed-loop abstraction with quantified 
   deviation bounds for stochastic MCRA

Real-world experiments on a Unitree Go2 robot achieve 87% success rate (26/30

minimum feasible budget by 10% (z₀*/z_ref = 0.90 vs 0.96) while maintaining 
comparable safety. Ablation studies confirm that both the hierarchical 
decomposition and conservative margins are essential: removing the hierarchy 
drops success rate from 70.8% to 47.9%, and removing either margin increases 
failure rates by >7%.
```

### 3.3 与 RC-PPO 的定位

#### **当前问题**
- 论文将 RC-PPO 作为"要击败的基线"
- 应该将其作为"我们适配的理论基础"

#### **建议定位**

**在方法章节引入时**：
```markdown
## 2 Background: RC-PPO for Deterministic MCRA

RC-PPO [So et al. 2024] introduced the MCRA formulation and the augmented-
state construction for deterministic discrete-time systems. Given dynamics 
x_{t+1} = f(x_t, u_t), RC-PPO defines an augmented state (x, y, z) where:
- y ∈ {-1, 1} is a safety indicator (y=1 if entered unsafe set F)
- z ∈ ℝ is the remaining budget
- Augmented goal: ĝ(x,y,z) = max{g(x), Cy, -z}

This transforms the MCRA problem into:
  min z_0  s.t.  Ṽ^π_ĝ(x_0, I_{x_0∈F}, z_0) ≤ 0

RC-PPO proved convergence guarantees under exact deterministic dynamics and 
achieved 57% cost reduction on MuJoCo benchmarks.

**However**, quadruped locomotion involves stochastic closed-loop dynamics 
with:
- Velocity tracking errors (Δv ≈ 0.1-0.3 m/s)
- Ground contact uncertainty
- Perception noise (LiDAR ±0.05m)
- High-dimensional action space (12-D joint torques)

Our work extends RC-PPO's framework to this stochastic, high-dimensional 
setting through three adaptations described in Section 3.
```

**在实验章节对比时**：
```markdown
We compare against RC-PPO [So et al. 2024] to validate our adaptations. 
Since RC-PPO was developed for deterministic systems, we adapt it for 
quadruped deployment by using the same hierarchical interface (frozen 
low-level tracker, velocity commands) but without conservative margins 
(α=0, δ=0). This isolates the contribution of data-driven margins.

Results show HD-MCRA's margins improve robustness:
- Minimum feasible budget: 0.90 vs 0.96 (RC-PPO)
- Budget violation rate: 10% vs 27% (RC-PPO)
- Success rate: 73% vs 60% (RC-PPO)

These improvements validate that α and δ effectively compensate for 
residual tracking errors beyond what the hierarchical abstraction provides.
```

**关键原则**：
- 引用 RC-PPO 时承认它是理论基础
- 对比 RC-PPO 时展示我们的适配改进了鲁棒性
- 不要"击败" RC-PPO，而是**扩展**它
