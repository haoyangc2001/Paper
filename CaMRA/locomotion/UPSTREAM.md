## 引入方式

从上述提交导出完整 Git 源码快照，最初并入工作区的 `locomotion/` 目录，随后与校准和导航模块一起迁入 `CaMRA/`。当前路径为 `CaMRA/locomotion/`，由工作区统一进行 Git 管理，不建立嵌套仓库或子模块。目录迁移未改动训练和部署代码。

上游 161 个受版本控制文件全部保留；唯一的路径调整是将上游 `README.md` 保存为 `README.upstream.md`。本地 `README.md` 用于说明 CaMRA 模块定位、来源及后续接入方式，另新增本来源记录。训练配置、Python 包、部署代码、第三方库、示例文件及许可证未作内容修改。

导入时调整了 `.vscode/.gitignore` 的规则顺序，将通用 JSON 忽略规则放在共享模板的放行规则之前，确保原仓库已跟踪的编辑器模板也能由当前工作区正常跟踪。其余 160 个上游文件（含改名的 README）与引入提交逐文件 SHA-256 核对一致。

引入快照不包含外部 Isaac Lab / Isaac Sim 安装、机器人资产、Unitree SDK2 或上游 Git 历史。上游附带的其他机器人示例策略也不代表本项目已经获得可用的 Go2 策略。

## 后续维护

本模块是可继续开发的实现基础，与工作区中冻结的 `RC-PPO/` 参考仓库用途不同。后续 Go2 适配和训练修改在本模块内进行，并通过 Git 记录。更新上游时应以本文件记录的提交为基准核对差异，保留本地适配及来源信息。
