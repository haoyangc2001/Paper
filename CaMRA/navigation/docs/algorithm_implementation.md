### 1. 算法是什么

三层，缺一层都不成立：

| 层 | 干什么 | 频率 | 是否训练 |
|---|---|---|---|
| 上层策略 | obs-v2（41 维）→ 归一化动作 a ∈ R³ → applied 命令 (vx, vy, wz) | 10 Hz | **是** |
| 两个评价网络 | V_c：剩余归一化成本；V_h：min 型可达性残差 | 10 Hz（只前向） | **是** |
| 底层 v2 策略 | 命令 → 12 关节目标 | 50 Hz | 否，冻结 |

训练目标不是"跑得快"，是**在能量预算内安全到达**。所以策略的输出要同时被两个评价网络
和一个预算状态约束，而这个约束的形式就是下面的残差。

### 2. 五个语义要点

| 量 | 定义 | 单位 | 谁用 |
|---|---|---|---|
| 成本 `c_t` | `(1+α)·P_nom(u_t)·dt / Z_REF`，α=0 时即名义功率积分 | 无量纲（J/Z_REF） | 预算、成本目标 |
| 预算 `z` | `z_J = z0 − Σc_model`，`z_ratio = clip(z_J/Z_REF, −1, 1)` | 无量纲 | 观测第 40 维、残差 |
| 安全历史 `y` | 进入膨胀危险集后置 1，不可逆 | 0/1 | 观测、`h = max(g_norm, C·y)` |
| 残差 `W(t,τ)` | `max( h(τ), spent(t,τ) + [τ=T]·V_c(T) − z_ratio(t) )` | 无量纲 | 可行性、停止时刻、policy 优势 |
| 停止 `τ*` | 逐时刻在尾段取首个 argmin；两 critic 共用同一个 τ* | 索引 | 训练分段 |

判据：`W <= −β`（β=0）为可行；`V_h <= 0` 表示可安全到达。

**三条容易写错的语义**（都已在 `tests/` 里用反例钉住）：

1. `W` 的 max 必须在**同一个停止时刻**上取。分开取会给出 `W=−0.1`（误判可行），正确值是 `+0.5`。
2. `h = max(g_norm, C·y)` 里最后那个 `max(·, 0)` 会把"目标内部"的 `G_INSIDE=−0.001` 抹平，
   所以干净到达的残差恰好是 **0**，判据必须写成 `<=`，写成 `<` 会把完美到达判成不可行。
3. γ_c=1 时 `spent` 对 t 可加，于是 `W(t,τ)` 与 t 无关、每步重取得到同一个 τ*。
   改成 γ=0.9 就不再是这个结构——所以 γ_c 钉死在 1 不是随手取的超参。

分类：**工程近似**（不改评分语义，已在任务内证明）、**语义偏离**（改变学习目标，
需有理由或待对照）、**缺陷修正**（参考实现本身的问题）。

| # | 类 | 参考实现 | 本实现 | 依据 / 状态 |
|---|---|---|---|---|
| D1 | 工程近似 | JAX/Flax + optax | PyTorch + 三个独立 Adam | NAV-008 冻结框架；numpy 转写交叉核对逐位一致 |
| D2 | 工程近似 | 一个 rollout 自动复位，env done 与停止分段共用一个 `done` | `terminated`/`truncated` 分开，一回合一个 chunk | 共用 `done` 会让跨 reset 的样本成为旧回合的后续；NAV-032 用"恢复 vs 连续"逐位相同证明 |
| D3 | **语义偏离** | policy 优势 = 对 stop-now 残差做 λ 平滑 GAE | `adv = W_sel − V_total` | `W_sel` 已含整条尾段，λ 平滑会把 τ* 之后的步混进来。**未做对照，见 OI-3** |
| D4 | 语义偏离（有理由） | reach 目标用 critic 的 `last_val_h` 当尾部 | 用实测 `h_T = max(g_norm(x_T), C·y)` | 不用被训练的同一网络给自己造目标；与参考的 `reach_append` 用法一致 |
| D5 | 工程近似 | 动作映射含 tanh 压缩 | 仿射 `clip(a,−1,1)×(1,0.4,1)` | tanh(1)=0.7616 会系统性压低指令，而低速段必须精确可达 |
| D6 | 缺陷修正 | `calculate_indexs3` 逐行转写会返回越界索引 | 按契约 argmin 语义重写 | 参考的 argmin 依赖内部 roll/反转，不能直接当 τ 用；NAV-030 记录、未改参考副本 |
| D7 | **结构性差异（未处理）** | 多 epoch、多 minibatch，PPO 比例裁剪生效 | 每回合一次全批更新 → ratio 恒 1，`clip_eps` 实际未被使用 | 等于带基线的策略梯度。是否改多 epoch 属训练配置，不在本轮门禁范围 |
| D8 | 契约内部不一致 | `sign_conventions[5]`：A>0 表示动作更好（成本更低） | A = 目标成本 − V，A>0 更贵 | 与同一契约的 max 形式损失代数冲突（dL/dlogp ∝ A）。按代数落地，契约措辞待升版 |
| D9 | **语义问题（待裁定）** | 残差用未截断的累计能量 | 残差用 `z_ratio`（±1 截断） | z0 > Z_REF 时成本项退化为 min(z0, Z_REF)，而全部场景的参考能量都 > Z_REF。**见 OI-2** |

### 6. 尚未证明的事

明确列出来，避免被当成已经证过：

1. **连续动作域的最优性**：可枚举对照只在 4 个离散动作的受限问题上成立，二者最优值之间没有可比性。

   参数位移恒为 lr×0.5，优化器无法退火。长训前须把 `max_grad_norm` 提到 2.5（OI-4）。
3. **学习候选的执行适用性**：候选的指令变化率是规则控制器的 22.4 倍、`|wz|` 均值 16.6 倍、

4. **物理闭环的可恢复性**：中断-恢复的逐位相同只在名义环境上验过。
5. **GAE 的偏差-方差**：λ=0.95 是参考取值，本项目没做敏感性分析。

## NAV-062：样本时序、预算与终止接口（2026-11-12）

本项把 NAV-061 登记的三项待裁定落地，并把 M1/M2/M3/M8 的判定从"疑似"变成有数值依据的结论。证据：`tests/test_training_semantics.py`（24 项，PASS）与 `reports/training_semantics_v2.json`。

### 一、样本时序：两侧显式命名

每条转移按 `(x_t, y_t, z_t, u_t, c_t, x_{t+1}, y_{t+1}, z_{t+1})` 存全，命名规则固定为**无后缀 = t，`*_next` = t+1**：

| 时刻 | 字段 |
|---|---|
| t | `obs`, `value_cost`, `value_reach`, `z_j`, `z_norm`, `z_ratio`, `safety_y`, `goal_distance_m` |
| 转移 | `cost_norm`（由 applied 命令产生）, `action_raw`, `action_applied`, `log_prob` |
| t+1 | `next_obs`, `z_norm_next`, `z_ratio_next`, `safety_y_next`, `goal_distance_m_next` |

修正前的实现（storage `acc0a1fe`）用**步后**的 `goal_distance_m` 与 `safety_y` 组装 `h_t`，再在末尾重复补一次 `h[-1]`：等于把 `h_{t+1}` 配给 `V(x_t)`，且终点安全代价被算了两遍。现改为 `h_t` 由 t 侧字段直接算、`h_T` 由 `*_next` 的末元素算且**只补一次**；两步手算用例逐项对比 `h_t`、`h_T`、`obj_spent`、`W`，并做单侧变异（只改 `z_norm_next` 时任何派生量都不许动，只改 `z_norm` 时 `W` 必须动）。

缓冲区 schema 升为 `camra-navigation-rollout-v2`：缺配对字段的 v1 chunk 直接被拒绝（报错文案点名缺哪几个），不做静默重解释。旧 chunk 与旧报告按 v1 语义保留。

### 二、预算：抽样、未裁剪、不终止

- 每回合 `k ~ U(0.6, 1.3)`、`z0 = k · E_ref(map)`，逐 env 独立 `Generator`；状态随 checkpoint 保存，同 seed 与"中断-恢复"都得到同一序列（已用 40 抽样的前缀/续接对比验证）。参考实现每回合 `uniform(min_energy, max_energy)`；旧实现固定单档 `k_train`，与评测扫 0.7–1.3 不匹配。
- `z0` 上限是**观测编码上限** `z_ratio_clip · Z_REF_J = 825 J`，不是任务预算。`z_ratio` 从 ±1.0 放宽到 ±1.5（obs-v3，导航契约 1.5.0）：1.3 × 489.4 J 的比值是 1.158，旧上限会把"还有预算"编码成"耗尽"。obs-v2 仍可按 `version=` 逐位重建。
- 目标 `W` 用**未裁剪**的 `z_J / Z_REF_J`（`z_norm`）；观测里的裁剪值只是编码。两者混用会让 `W` 在饱和处不可加——这是 M2 的实质，不是尺度问题。
- `z_J <= 0` 不再终止回合、不再产生标签（M3）。回合只跑到到达/碰撞/越界/停滞/30 s。参考实现的 `is_terminal` 只看时限，能量是成本项；旧设置让 82–91% 的失败步停在"油没了"，训练从未见过低预算后半程。
- "预算内到达"改为独立字段：`within_budget`、`arrived_within_budget`、`over_budget_J`。评估与预算选择的判据同步改为 `label == goal_reached AND z_J_end >= 0`；`run_budget_selection.feasible_from_label` 现在缺 `within_budget` 会直接抛错，不会退化成只看标签。

### 三、三项待裁定的落定

1. **停滞归类**：按 `terminal_and_truncation` 表判为**截断**（`h_T` 实测、成本尾项加 `V_c(x_T)`）。理由：停滞不是物理失败（没有接触、没有越界），但也绝不能当成功；`bootstrap` 让 critic 学会"从这里还能走到哪"。
2. **z_ratio 裁剪上限**：放宽到 ±1.5，**升 navigation 契约到 1.5.0** 并保留 `clip_by_version`；`observation.py`、`costs.SignedBudget.z_ratio`、`targets.z_ratio_from_budget`、`budget/search.py` 的换算全部改读同一个 `z_ratio_clip()`，不再各处硬编码 1.0。
3. **动作顶格**：保留参考实现的有界裁剪映射 `u = clip(a, ±1)·COMMAND_MAX`，不改分布族。量化登记（实测，64 个顶格样本）：
   - 所有 `|a|>1` 的样本 `applied` 顶格，`vx` 上只有极少数不同取值——多个 raw 动作映到同一命令，可辨识性下降；
   - **似然比梯度不受影响**：策略参数梯度非零，且一步 SGD 后均值被推离这些"更贵"的动作（`mean_vx` 下降）；路径梯度 `dapplied/draw` 在裁剪区为 0，这正是不能要求环境路径处处可导的原因；
   - 若循环训练后顶格比例仍高，改动作参数化属新契约版本（v2），不在本项静默替换。

## NAV-063：共同停止与三套估计器（2026-11-12）

本项把"记录停止时刻"变成"停止时刻控制三套目标"，并把 M5/M6/M7/M11/M12 的裁定落到生产调用链。证据：`tests/test_rcppo_alignment.py`（22 项，PASS）、`reports/rcppo_alignment.json`、`reports/gate_G3_alignment_v2.json`（预登记 sha `7693cf1f…`，PASS）。

### 一、为什么原来的三套估计器不是同一目标

NAV-063 之前：成本目标取**整回合** suffix、reach 目标取**未掩码**的 min 型 Bellman 值、policy 优势用 `W_sel − V_total` 一次性差。三者各自隐含一个终点，停止点只被记录、没有约束任何目标。参考实现（`RC-PPO/rl/EC-EFPPO.py:64-76`）不是这样：`calculate_indexs3` 产出一个 `done`，`calculate_gae2`、`calculate_gae_reach4`、以及 `g=max(reach,−energy)` 上的 `calculate_gae_reach4` 全部共用它。

现在 CaMRA 的定义（γ_c=1，故 `spent(t,τ) − z_t = −z_τ`）：

| 量 | 定义 | 实现 |
|---|---|---|
| 共同停止 | `τ*(t)=argmin_{τ≥t} W(t,τ)`，`W=max(h_τ, spent(t,τ)+[τ=T]V_c(x_T)−z_t)` | `targets.select_stop` |
| 停止掩码 | `done[t]=1[τ*(t)=t]`；λ-return 的 `done_ext` 末项固定为 1 | `storage.compute_objectives` |
| ① 成本 | `Σ_{s=t}^{τ*(t)−1} c_s + 1[τ*=T]·V_c(x_T)` | `targets.cost_to_stop` |
| ② reach | min 型 DP 值序列上的 `λ-return`（γ_h 退火） | `targets.lambda_return` |
| ③ 联合策略 | `g_τ=max(h_τ,−z_τ)` 上的 `λ-return`，减 `V_total=max(V_h,V_c−z)` | 同上 |

`λ-return` 的递推 `G_t=(1−λ)v_t+λG_{t+1}`（`done_t=1` 时 `G_t=v_t`）与 `(1−λ)Σ_{k<n}λ^k v_{t+k} + λ^n v_{τ*}` 恒等；`γ_c=1` 下 `τ*(t)` 随 t 单调不减，所以递推里 `G_{t+1}` 的停止点就是 `τ*(t)`，递归合法。

### 二、三处有意偏离（都量化登记）

1. **联合 λ-return 的 γ = 1.0**（参考 `GAMMA_REACH_INIT=0.999`）。理由是契约：目标是未折扣 J，`W` 也定义在未折扣量上；用 0.999 等于给后发生的成本打折。30 步常值 `g` 上两种口径的差 `ΔG=0.0148`。若将来要贴参考，必须连同"成本目标是否也打折"一起改，不能只改一处。
2. **失败回合强制 `τ*=T`**。参考只做 argmin；但失败是吸收态，agent 不能"提前声明停止"来回避它。不强制时，预算宽松的失败样本会把停止点选在失败之前，前序联合目标里根本没有那 1.0 的惩罚——契约明确要求失败惩罚传播到全部相关目标。
3. **reach 的尾部用实测 `h_T=max(g_norm(x_T),C·y_T)`**（参考的环境 reach 无独立 y）。这是 M4 的不可逆安全历史，`danger_then_arrival` 用例把它钉住。

### 三、验收覆盖

- 生产调用链：`compute_objectives` 内部对 `cost_to_stop`/`lambda_return`（两次）/`joint_sequence` 的调用被计数，且两次 λ-return 的 `done` 逐元素相同；`done` 必须等于 `1[τ*=t]`；λ 必须来自契约。
- 手算：`τ*=t`（成本 0、联合 `g_t`）与 `τ*=T`（段内成本+bootstrap、嵌套 λ-return）；同总 J 不同时刻成本目标相同、而 γ=0.99 时会不同。
- 冲突与污染：两个 critic 偏好不同终点时三套目标服从同一 `τ*`；停止之后把成本改成 5.0 不影响 `τ*` 及之前的目标（逐位相等）。
- 边界：失败惩罚逐步传播（手算 λ-return）、危险后到达不可行、负预算即正成本、λ/γ_h 变化确实改变生产目标、切片+正确 bootstrap 的成本目标等于完整轨迹。
- PPO：A± 与 ratio 高低四格的裁剪值（1.6 / 0.8 / −1.2 / −0.5）、熵符号、多 epoch 固定 `old_log_prob`（更新次数 = 3×4，ratio 不为 1）。
- 真实产物：`train_nominal` 跑一个回合，逐 chunk 由原始字段重算全部派生目标，逐位一致。
