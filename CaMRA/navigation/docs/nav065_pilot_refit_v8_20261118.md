## 候选改动与原理对齐

参考论文《Solving Minimum-Cost Reach Avoid using Reinforcement Learning》§4.2先固定确定性actor、重估价值、再求预算根；RC-PPO/rl/root_finding.py用联合值正负做二分。当前仍修第二步，不提前执行NAV-066。共同停止、cost/reach标签、W=max(V_h,V_c−z/Z_REF)、beta=0、原train/G4都保持。

隔离入口[scripts/refit_nav065_pilot.py](../scripts/refit_nav065_pilot.py)直接复用原分层回归、符号目标及完整train_gate。先纯数值拟合，未达到旧/新增各自的MAE≤35%、必要Pearson≥0.70时，停止并保留失败，不因数值段额度用完强行切换。

若数值检查通过，边界阶段保留回归梯度r，仅去除符号梯度s中反对回归下降的分量；纠错范数最多为0.25||r||，系数最多1，不把微小符号梯度放大。边界用无动量SGD，避免Adam改变所检查方向；原始标签、网络和损失的零误差解不变。该方向在精确一阶计算中满足r·d≥||r||²，但这只涉及当批MSE，不保证有限步MAE、相关性、全部符号、开发表现或收敛。

每步实际调用原v5完整train_gate并记录全部起点/误放行/误拒绝变化，首次完整通过即停。边界每10步检查原数值门槛，退化则停止，不回退挑模型或自动重试。未用阶段额度不转移；非有限值停止留证。阶段及末次模型独立保存、CPU重载核验；其他五模型全部张量与六actor保持原样。
