## 本轮针对的问题

[v10结果](nav065_head_probe_v10_review_20261118.md)证明固定v8来源的25个起点能被原float32网络拟合，但全量162起点错误放行仍为13次，错误拒绝1→58，主预算18个实际可行起点正确识别18→2。actor没有改变，原18/18实际可行记录保留。该诊断只约束25点，完整轨迹在求解后检查；两个原输出层的精确插值改变量约42.47/552.04。

v11检验一个更窄的问题：把原轨迹、已有临界预算和沿途状态共同放入同一次数值拟合，并限制相对源输出层的调整，能否兼顾纠错与全量稳定。不能仅凭局部可拟合就改架构、保证全量成功或反复增加迭代。

## 已实现入口与拟合定义

[probe_nav065_ridge.py](../scripts/probe_nav065_ridge.py)区分只读`--diagnose`与持有独立批准登记的`--registration`。只读预检计算当前全量表现、固定设计和理论改变量界，不求解候选参数。正式入口仅在深拷贝中对两个原输出层各求解一次，转回原float32生产前向，CPU重载并核验只允许四个head张量变化。

四组数据各占1/4权重：原90条全部时刻、已有新增72条全部时刻、全部162起点、原v5门禁选定的起点及沿途边界行。每组中到达目标为正/非正的非空分层均分权重，层内逐行均匀。所有原始时刻保留；起点与边界在不同组重复出现是明确的额外权重，不是新增回合或重复分母。

每个critic用原body特征加偏置组成A，在float64中求解下式：

```text
min_delta sum_i p_i * ((A_i*delta - (y_i-A_i*w0))/target_rms)^2
          + 0.01 * ||delta||^2 / head_scale^2
target_rms = max(sqrt(sum_i p_i*y_i^2), 1e-6)
head_scale = max(||w0||, 1)
```

偏置包含在参数向量和惩罚中。使用增广最小二乘，不构造正规方程；`rcond=1e-12`，特征按2048行分批计算。0.01是此次小验证预先固定的工作正则强度：目标先按RMS归一化，参数移动一个head_scale的罚值为0.01，移动十个时为1。它是可审阅的工程选择，不是论文给出的最优常数；本轮不扫描、回退或按开发结果挑选。

以源参数为零改变量比较点，可以得到“正则目标不高于源”条件下的改变量上界`sqrt(source_objective/ridge_coefficient)`。该界只约束整体二次目标，不保证每个状态或正负判断不退化。正式结果仍必须逐组披露原始误差、分量/联合符号、全部起点及原全量train_gate，不能把加权损失下降当作通过。
