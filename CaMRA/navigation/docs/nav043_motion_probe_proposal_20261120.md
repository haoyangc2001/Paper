# NAV-043：先补实测覆盖，再决定运动模型

计划1.5.0仍为55/67历史完成，NAV-043=false、G5未过。本次只完成数据盘点和下一阶段的具体范围，不新增物理或训练，也不将协议检查当作模型验收。

旧18条轨迹只能说明前向指令约0.228～0.463m/s这一窄范围内的表现。仿射模型明显改善了保存轨迹误差，但其零指令预测是范围外的代数外推，不能解释为机器人真的在倒退，更不能拿截距直接做补偿。

现有材料已核对：原v2功率训练的240条命令模板含9056个静止区间和17401个前向绝对值低于0.1m/s区间，模板散列逐条一致；这些是指令，不是实测状态。清单声明的原始路径目前不存在，不能据此断言其它位置也没有备份。NAV-059的51次旧尝试只有汇总指标，无法补出连续200Hz位姿或warmup前一端点。报告见[数据可用性](../reports/nav043_motion_data_availability_v1.json)。没有借用HiRA执行数据，也未查看heldout/final。

推荐只做一次有限受控采集，机器协议为[PROPOSED范围](../config/nav043_motion_probe_proposal_v1.json)。命令单位依次为m/s、m/s、rad/s；每行只执行一次，依次复位。

| 工况 | 指令(vx,vy,wz) | 目的 |
| --- | --- | --- |
| M01 | (0,0,0) | 实测静止指令下的运动 |
| M02–M04 | (0.1,0,0)、(0.2,0,0)、(0.4,0,0) | 低速及当前常见前向速度 |
| M05–M06 | (1,0,0)、(-1,0,0) | 已冻结前向域两端的短时响应 |
| M07–M08 | (0,0.4,0)、(0,-0.4,0) | 横向正负响应 |
| M09–M10 | (0,0,1)、(0,0,-1) | 正负原地转向 |
| M11–M12 | (0.4,0.1,0.4)、(0.4,-0.1,-0.4) | 两种联合指令的初步检查 |

每工况1秒零指令warmup，再10秒恒定指令，完整保存200Hz实测位姿、瞬时速度、力矩/关节速度和命令证据；用真实warmup第180/200tick构造首个已完成0.1秒q，warmup和测量机械功分开。没有运动期间的位姿重置，没有上层actor/critic、预算W查询或导航目标。

拟定额度为tiger11/tmux、固定v2、物理GPU6、单应用单环境、最多12个短物理工况及累计2小时。正常warmup加测量26400环境tick；初始化/复位预留5600次显式物理step调用，总上限32000，不得把预留转成新工况。应用构建前计数显式step，原生初始化中不可观测的内部步数必须如实区分。首个跌倒、证据缺失或运行错误保存停下，不自动重试；静止漂移或跟踪差是需保留的结果。一次采集没有重复性统计，200Hz数据不能当作独立重复试验。

本次申请只采集和审阅保存数据，拟合、上层训练、名义或物理导航回合、校准均为0。12个点并不覆盖联合动作域，更不证明90秒残余、旧δ适用或G5通过。采集完成后再根据实测情况形成有界的模型拟合/验证方案，然后接参考程序/J成本、90秒独立残余协议和受影响门禁。
