# 上层最小成本到达避障导航器

本目录用于实现四足机器人的上层最小成本到达避障导航器。导航器根据环境观测、目标和预算生成速度指令，由冻结的底层控制器执行。

当前仅在仿真中训练与评估。上层通过机身坐标系的 `[vx, vy, yaw_rate]` 接口驱动现成且固定的底层控制器，使用与该控制器及执行条件匹配的校准结果完成对比和消融实验。底层策略复用优先，本阶段不开展真机通信和部署。

后续在此实现导航环境、策略网络、两个评价网络，以及训练和评估流程。成本裕度 α 和几何裕度 δ 将用于修正预算扣减和障碍物安全边界；原算法参考代码保留在工作区根目录的 [RC-PPO](../../RC-PPO/README.md)。

当前仅建立目录及用途说明，尚未添加代码。
