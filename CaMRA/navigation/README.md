# 上层最小成本到达避障导航器

本模块根据机器人状态、环境观测、目标和剩余预算生成机身坐标系速度 `[vx, vy, yaw_rate]`，由冻结的底层控制器执行，完成安全到达并尽量降低累计导航成本。

## 当前状态

目前仅有本说明，导航环境、网络、训练与评估代码尚未实现。下一步先完成相邻 [calibration](../calibration/README.md) 模块，再接入经独立检验的裕度。本阶段在仿真中复现方法。

底层沿用已接受其已知局限的 `camra_go2_velocity_it2999_v2`，模型与控制配置保持固定；低速死区需在导航指令和任务评估中显式考虑，不能假定校准已将它消除。

## 输入、输出与方法

| 接口 | 内容 |
| --- | --- |
| 导航输入 | 系统状态/观测、目标、危险区域、剩余预算及安全历史状态 |
| 校准输入 | 与同一冻结控制器和执行条件匹配的 α、δ 及配置记录 |
| 策略输出 | 机身速度 `[vx, vy, yaw_rate]`；范围与时序遵循冻结契约 |
| 评估输出 | 轨迹、成功/碰撞、累计成本、预算违反、净空距离及对应配置 |

方法采用增广状态：`y` 记录危险区域访问历史，`z` 记录剩余成本预算；策略网络与两个评价网络分别承担决策、到达/安全评价和成本评价。成本裕度按 `(1+α)c` 修正预算扣减，几何裕度将危险集合额外膨胀 δ，再进行初始预算选择与导航评估。

## 后续实现入口

- 实现确定性名义导航模型、地图/目标/危险集合、成本函数及终止处理。
- 实现策略、双评价网络和预算选择，核对最小化目标、优势符号与停止分段。
- 接入冻结底层与校准结果，开展方法对比、消融和预算扫描，保存实际配置与原始轨迹。

[RC-PPO](../../RC-PPO/README.md) 提供原算法参考；其中 PPO 的最小化符号及重新构造的停止标志不能直接照搬为普通奖励最大化或环境终止。[HiRA](../../HiRA/README.md) 提供分层速度接口与导航流程参考，当前不实现 CaMRA 的双裕度与预算条件双评价结构。两个参考项目保持只读。

统一时序与模块关系见 [CaMRA 系统说明](../README.md)。实现后在本页补充运行入口；当前没有可运行的上层训练命令。
