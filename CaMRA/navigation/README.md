# 上层最小成本到达避障导航器

本模块根据机器人状态、环境观测、目标和剩余预算生成机身坐标系速度 `[vx, vy, yaw_rate]`，由冻结的底层控制器执行，完成安全到达并尽量降低累计导航成本。

## 当前状态

目前仅有本说明，导航环境、网络、训练与评估代码尚未实现。用户已于2026-11-09明确后续固定使用 **`camra_go2_velocity_it2999_v2`**，作为硬性约束；相邻 [calibration](../calibration/README.md) 提供 v2 配套工具与结果。本次仅更新说明，不启动导航实现或训练。

实施入口为 [60项上层导航计划](../../doc/plan/20261109_camra_navigation_implementation.json)，版本 **1.2.0**，当前 **0/60项完成**，首项 **NAV-001**。执行时先完整学习背景及原算法/分层代码，再配置 tiger11（192.168.20.11）环境；服务器任务全程使用tmux。计划覆盖名义环境、提前接通v2、算法数值验证、名义训练、独立预算选择与clean闭环、固定策略扰动检验及交付，详细约束与逐项证据在计划维护。

新增 NAV-055–060 按前置依赖插入原任务，执行以计划 `tasks` 数组为准，不按编号排序。速度域冲突、能量/价值尺度与折扣、姿态足迹及共同/自选预算规则先确定；低速省能动作与闭环裕度适用性在上层学习前验证并通过 G2A。短训练策略与最终部署策略分别在 NAV-034/043 复查，NAV-048 保留最终审计。成功终止、观测编码、框架和计算配额在既有任务中填定；旧校准文件、v2和论文保持只读。

全程遵守计划 `upstream_correction_policy`：既定范围内可回修前置问题，主体记录追加到发现问题的当前任务，保留旧记录及产物；受影响的验收与门禁重验后才能继续。该规则不改变冻结系统或扩大任务范围。

历史 [40项 HiRA 计划](../../doc/plan/20261105_camra_hira_policy_calibration.json)已记录40/40项完成，其初态、名义轨迹起点、全体分母和交付问题保留在[复核记录](../calibration/docs/controller_comparison_status_20261109.md)。这些 HiRA 独立待办不默认成为 v2 导航的前置任务；共享代码按其对 v2 的实际影响核查。

后续导航实现、训练和评估必须绑定 v2 的模型、资产、执行契约、功率模型、足迹、α/δ和数据锁；HiRA 仅保留为历史参考/对照。未经用户明确授权，不切换控制器或 checkpoint，不重新训练替换 v2；缺少资源时获取并核验 v2 包，不能用 HiRA 顶替。正式训练前核验 v2 接口及裕度与地图尺度的适用性，保留其低速/停滞局限和历史验收结论；完整约束见[根 AGENTS](../../AGENTS.md)。

## 输入、输出与方法

| 接口 | 内容 |
| --- | --- |
| 导航输入 | 仿真真值平面状态、地图/目标、剩余预算、安全历史及剩余时间；字段编码按前置任务冻结 |
| 校准输入 | 与同一冻结控制器和执行条件匹配的名义功率模型、α、δ、能量单位、占地轮廓及配置记录 |
| 策略输出 | 机身速度 `[vx, vy, yaw_rate]`；范围与时序遵循冻结契约 |
| 评估输出 | 轨迹、成功/碰撞、累计成本、预算违反、净空距离及对应配置 |

方法采用增广状态：`y` 记录危险区域访问历史，`z` 记录剩余成本预算；策略网络与两个评价网络分别承担决策、到达/安全评价和成本评价。成本裕度按 `(1+α)c` 修正预算扣减，几何裕度将危险集合额外膨胀 δ，再进行初始预算选择与导航评估。

后续成本接口与当前校准版本保持一致：由冻结名义功率模型计算每0.1秒的能量步成本，再按 `(1+α)c` 扣减预算；若功率模型依赖历史指令，导航状态须包含相应信息。能量指标以校准交付为准，能量预算需重新确定，不能直接沿用旧稿的 a.u. 数值。

## 后续实现入口

1. 学习背景、核验 tiger11 环境与 v2 资源，冻结接口、成本、安全和终止契约。
2. 建立宽通道地图及确定性名义环境，验证加入足迹和δ后仍可通行并按时完成。
3. 提前接通 v2，验证10/50/200 Hz时序、复位、机械功计量及旧裕度适用性。
4. 完成算法数值与短训练检查，再正式训练无校准和完整方法，冻结部署策略及对应评价网络。
5. 在独立选择集确定预算规则，完成 clean 物理闭环与正式对照。
6. 固定策略、预算和裕度完成扰动检验、独立复算及交付；首轮不默认随机再训练或新增大规模消融。

[RC-PPO](../../RC-PPO/README.md) 提供原算法参考；其中 PPO 的最小化符号及重新构造的停止标志不能直接照搬为普通奖励最大化或环境终止。[HiRA](../../HiRA/README.md) 提供分层速度接口与导航流程参考，当前不实现 CaMRA 的双裕度与预算条件双评价结构。两个参考项目保持只读。

统一时序与模块关系见 [CaMRA 系统说明](../README.md)。实现后在本页补充运行入口；当前没有可运行的上层训练命令。
