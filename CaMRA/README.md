# CaMRA

面向 Unitree Go2 四足机器人的分层最小成本到达避障系统。底层学习速度跟踪及稳定运动，冻结后采集剩余执行误差，校准成本裕度 α 和几何裕度 δ；上层结合校准结果，根据观测、目标和预算生成导航速度指令。

## 模块划分

```text
CaMRA/
├── README.md
├── locomotion/       # 底层速度跟踪训练、评估、导出及部署
├── calibration/      # 执行误差采集、裕度校准与独立检验
└── navigation/       # 上层导航环境、网络、训练与评估
```

| 模块 | 职责 | 主要输入与产物 | 当前状态 |
| --- | --- | --- | --- |
| [locomotion](locomotion/README.md) | 学习速度跟踪，承担平衡、步态协调和动作平滑 | 目标速度与本体状态 → 关节控制；产出冻结的策略及执行配置 | 已引入官方框架，尚未在本项目中训练或运行验证 |
| [calibration](calibration/README.md) | 测量剩余执行误差，校准并独立检验两类裕度 | 冻结控制器、配对的名义与执行轨迹 → α、δ 及对应配置记录 | 目录和用途说明已建立，代码待实现 |
| [navigation](navigation/README.md) | 学习满足安全与预算要求的到达决策 | 环境观测、目标、预算及校准结果 → 三维速度指令 | 目录和用途说明已建立，代码待实现 |

## 模块配合与开发顺序

1. **训练底层。** 在 `locomotion/` 中准备 Go2 资产及仿真环境，训练和评估速度跟踪策略；验证停车、低速转向与连续变速后，冻结策略及配套观测、动作和控制配置。
2. **执行校准。** 在 `calibration/` 中运行冻结控制器，采集并配对名义轨迹和实际执行轨迹，计算成本裕度 α 和几何裕度 δ，再用独立数据检验。结果与底层模型版本及采样条件一同保存。
3. **训练上层。** 在 `navigation/` 中实现导航环境、策略网络和两个评价网络，接入裕度及冻结控制器，再完成训练和评估。

运行时，上层将机身坐标系下的目标速度 `[vx, vy, yaw_rate]` 发送给冻结的底层控制器，底层结合本体状态输出关节控制。上层负责目标、地图及预算；校准模块用于离线确定执行裕度。模块接口尚待实现，速度范围、控制频率及动作映射需要在训练、校准和导航阶段保持一致。

## 安装与运行入口

底层框架的环境要求、安装和 Go2 训练命令见 [locomotion/README.md](locomotion/README.md)。从工作区根目录进入底层模块后执行这些命令：

```bash
cd CaMRA/locomotion
```

上游 VS Code 配置也以 `locomotion/` 为工作目录；使用这些配置时，将该模块目录作为编辑器工作区打开。上层和校准模块的运行入口将在实现后补充。
