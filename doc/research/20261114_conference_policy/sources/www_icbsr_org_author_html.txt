Paper Submission
All manuscripts must be submitted electronically in PDF format before the deadline via
https://cms.amss.ac.cn/
. Only English manuscript is acceptable.
Each English paper is limited to 8-10 pages and cannot exceed 12 pages. Each page in excess of 10 will incur an extra charge ($80 per page).
All papers must be written using the style given in
English Template
.
Declaration on Paper submissions
To promote academic exchanges among domestic and abroad scholars, the official languages of ICBSR 2026 is English, namely, the on-site exchanges and papers included in the proceedings of ICBSR 2026 can be presented or written in English. Hereby, ICBSR 2026 declares as follow:
The languages for on-site exchanges and papers included in the proceedings of ICBSR 2026 is English;
The Author(s) is required to submit a written statement that the author(s) doesn't engage in academic misconduct with the submitted final paper(s);
All the papers must be edited in Template;
The conference will recommend some best papers in English to SCl journals for possible publication, but the final decision is concluded by the SCl journals.
ICBSR 2026 will eliminate 'No Shows'. At least one author of the accepted paper MUST attend the conference to present the paper, lf none of the authors could attend, please ensure that someone else will present the paper on your behalf.

Submission Types
Regular Paper
If you are not sure please choose submission type "regular paper" to submit your manuscript. Each English paper is limited to 8-10 pages and cannot exceed 12 pages. Each page in excess of 10 will incur an extra charge ($80 per page).
Extended Abstract
You only need to submit a long summary and include it in the collection of essays, but not in Springer-Nature in Lecture Notes in Mechanical Engineering and other Journals. Published results can also be submitted. The format is the same as that of Regular Paper. Each Extended Abstract is limited to 2 pages.
Call for Invited Session
Invited Session Proposal
The invited/special session organizers should submit a proposal (choose "Invited Session Proposal" in the submission) first, then a session code will be assigned to the session, and all the corresponding authors of the papers involved in the session should be informed of the
session code
by the session organizers. A session commonly consists of six papers. You can download the Templates for
lnvited Session Proposal
here.
Invited Session Paper
An invited/special session paper must be submitted in the submission type "Invited Session Paper" with the correct
session code
. Please note that all the invited special session papers must be submitted before the indicated first submission deadline, and go through the review process with the regular papers.
Submission Procedure
The organizer should submit an invited session proposal including the session title, session chair(s), a brief session description, and the list of papers (title, authors, and affiliation). In this description it should be specified whether the session is proposed as a podium or interactive invited session. Submissions have to be made electronically within the Conference Manuscript Management System.
Soon after the submission of the proposal, the organizer will receive a Session Code by e-mail. This code is automatically issued by the system. The organizer should then distribute the Session Code to the authors of the invited session papers.
Individual authors of the invited session papers should submit their papers through the “Invited Session Paper” link at the submission system using the appropriate Session Code they received from the organizer.
