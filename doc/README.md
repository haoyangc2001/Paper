## 当前任务：HiRA 策略接入与独立校准

[20261105_camra_hira_policy_calibration.json](plan/20261105_camra_hira_policy_calibration.json) 包含40项新任务，当前0项完成，从 HIRA-001 开始。本次仅创建计划，尚未接入模型或启动实验；原 v2 控制器与其历史结果继续保留。

前20项先完成背景学习、设备配置、来源模型与资产核验、观测和动作适配、数值对照、闭环与能量计量验证，通过接入门禁后才允许采集。后20项复用现有校准流程，独立完成20条pilot、400条功率基线、800条校准、400条独立检验及200条近障检查，再审计、比较和交付。

新上下文先读 [AGENTS.md](../AGENTS.md) 和计划全文，再从HIRA-001开始学习与核验；当前说明整理不改变任务状态。HIRA-020接入门禁通过前不采pilot/功率基线，HIRA-029正式锁通过后才采校准，HIRA-031冻结α/δ后才采检验及近障。本轮不自动继续旧底层训练或启动导航。

## 原 v2 校准实施计划

[20261103_camra_calibration_implementation.json](plan/20261103_camra_calibration_implementation.json) 保存原 v2 的仿真能量与位置误差校准过程，共32项任务，当前均记录为完成。任务状态不等于所有科学指标均已通过；具体结果、限制及补采记录见 [校准交接笔记](../CaMRA/calibration/docs/implementation_handoff.md)。旧任务和结论不因新增 HiRA 实验而改写。

| 任务范围 | 目标 |
| --- | --- |
| CAL-001–004 | 新上下文详细学习论文、项目源码与历史证据，核对理解并列出设备配置清单 |
| CAL-005–007 | 按新设备安装配置环境，获取v2和资产，验证最小闭环及能量信号 |

## 原 v2 阶段的范围与决策

2026-11-03 用户接受冻结v2的已知低速局限，随后完成了 [原校准链路](../CaMRA/calibration/README.md)，不再把底层调参作为默认前置条件。此决定不修改旧协议、旧失败结论或任务状态；历史文档中的等待修复/裁决安排按其生成时的上下文理解。

校准模块已实现，现有工具作为新增 HiRA 实验的复用基础。原 v2 已采用固定30秒测量窗口、正关节机械功与独立名义功率模型；相关协议、数据和散列保留。新候选需要自己的功率基线及800/400/200条正式数据，旧论文的代理成本与预算不能直接当成能量结果使用。

执行或更新 JSON 计划时使用 `create-plan-worklog` 技能，保留依赖、验收证据和追加式工作记录。执行主机上的终端任务统一使用 tmux，首次建立 tmux 所需的最小引导命令、本地计划维护与结构校验除外。
