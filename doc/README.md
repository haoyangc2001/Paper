## 当前计划：固定 v2 的上层导航实现

每项均列出依赖、参考代码、约束、拟产物与验收标准。计划提前限定tmux、固定v2、J成本、10/50/200 Hz、宽通道与膨胀后通路、数据隔离和论文只读；资源配额及评分细则在正式训练前登记。当前仅创建计划，不表示开始或完成任何实验。

本次审查修订新增 NAV-055–060，分别核实速度域冲突、价值/折扣/共同停止目标、姿态足迹、两种预算比较口径、低速实际可执行性及旧裕度对闭环/提前终止的适用性。原任务编号保留，新增项按依赖插入；执行以 `tasks` 数组顺序为准。既有事件判据、框架/观测/资源任务同步补强，八类问题的任务对应见 `alignment_review`。

G2A 的训练前 pilot、NAV-034 的短训练策略复查、NAV-043 的部署策略复查和 NAV-048 的最终审计分别保留。早期规则控制的结果不替未来学习策略背书；参数、评分或科学范围需改变时先记录并询问，不默认改旧裕度。

全程回修规则见计划 `upstream_correction_policy`：发现前置实现有问题时可在既定范围纠正，主体记录追加到发现问题的当前任务；原工作记录、失败和产物保留，受影响的验收与门禁重验后再继续。当前60项任务的编号、依赖和状态不因补充规则而改变。
