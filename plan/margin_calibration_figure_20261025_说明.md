## 目标与图形

本图解释两个问题：为什么在当前假设稿中选择成本裕度α＝0.18、空间裕度δ＝0.12m；固定这些值后，另一批未参与选值的记录有多少落在裕度内。

先逐组建立800组校准假设记录，检查并冻结记录、算法和裕度，再逐组建立400组留出假设记录。留出覆盖率由数据计算，不预定为90%。本次不运行仿真或真实机器人；假设留出组只预览检验流程，不提供真实独立实验结论。

```text

        (a) 成本超支累计分布       (b) 最大轨迹偏差累计分布
纵轴    不超过横轴数值的比例       相同：0—100%
横轴    成本超支比例（%）          最大轨迹偏差（m）
标记    90%、α=18%、检验覆盖率     90%、δ=0.12m、检验覆盖率
```

整图单栏宽88.9mm，初始高48–55mm。校准蓝色实线、留出橙色虚线，顶部共享图例；轻网格、细参考线、准确的ECDF阶梯，在阈值交点突出实际覆盖率。实际字号至少6.5pt。完整显示负超支与超限尾部，不叠加直方图、局部放大框、机器人照片或无依据置信带。

参考资料在 `CCDC/references/calibration_review_20261025/`：rliable Fig.7借鉴曲线排版，Safe Planning Fig.2借鉴误差与阈值，KnowNo Fig.3借鉴目标与实际值的区分。参考论文的共形预测保证不转移到本文普通经验分位数方法。

## 逐组推演和检查方法

每组同时保存两项误差及关联条件。推演依据包含当前条件、前面多批记录、同组另一误差及已有图的适用语义，不局限于上一条记录。至少保留1200条具体审查，两个误差分别说明判断；发现早先值不合理时，追加原值、新值、原因和影响，重新计算相关统计。

每20组做一次小回顾，每批结束核对本批及前序关联记录；每200组另设完整阶段关卡。关卡有未闭环问题时，不执行后续依赖。

禁止用同一公式、随机分布、统一加噪、插值或复制旧数组替代逐组推演。脚本负责定义公式验算、排序、分位数、ECDF、覆盖统计及绘图。比如按已判断的成本超支计算执行成本是允许的，但不可以用一个规则自动生成全部超支。

重点检查：

- 成本超支保留符号，最大位置偏差非负；两者可以相关，但不能强制同比变化。
- 条件、时长和成本单位先定义，假设控制器与扰动范围不冒充真实恢复设置；本轮不编造完整时序日志。
- α只修正成本计费、δ只提供额外几何裕度，不直接消除跟踪误差。
- 单次案例不代表总体分布；独立示例成本尺度不与主表Cost强行等同。
- 成本与空间分别90%覆盖，不代表同时90%覆盖；覆盖率不等于SR，也不能直接推算CR/BVR。
- 留出记录不复制校准记录，不根据累计覆盖率的欠额安排下一条误差；偏离90%本身不是错误。

## 数据契约

最终入口为 `data/paired_rollouts.csv`，每行是一组名义/执行配对运行的假设汇总量。最少保存：

| 字段 | 含义 |
| --- | --- |
| pair_id、split | 唯一ID及校准/留出分组 |
| scenario_id、command_id、controller_id | 假设场景、指令索引及同一冻结控制器标识 |
| perturbation_profile_id、duration_s | 预设条件及时间窗口 |
| J_nom、J_exec | 同一示例成本单位的名义、执行累计成本 |
| cost_overrun | `(J_exec-J_nom)/J_nom`，要求J_nom＞0 |
| max_deviation_m | 同命令配对、时间对齐下的最大平面位置偏差汇总量 |
| data_status | 所有新记录为hypothetical |

成本与空间的90%分位数采用经验逆CDF：排序后取第 `ceil(n×0.9)` 个值，次序从1开始。800组对应第720个值；不添加共形有限样本修正。偶数样本中位数取两个中央值的平均，单独记录，不能混用算法。

ECDF和覆盖率均按“误差≤阈值”的准确计数计算。400组留出覆盖率的步长为0.25个百分点；保留分子、分母和全精度值，再做显示舍入。默认不添加误差棒或置信带。
